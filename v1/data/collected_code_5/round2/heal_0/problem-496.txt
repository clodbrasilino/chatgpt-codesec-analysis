```C
#include <stdio.h>
#include <stdlib.h>

#define HEAP_SIZE 128

void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

void heapify(int arr[], int n, int i) {
    int smallest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] < arr[smallest])
        smallest = left;
 
    if (right < n && arr[right] < arr[smallest])
        smallest = right;
  
    if (smallest != i) {
        swap(&arr[i], &arr[smallest]);
        heapify(arr, n, smallest);
    }
}

void build_min_heap(int arr[], int n) {
    int startIdx = (n / 2) - 1;
 
    for (int i = startIdx; i >= 0; i--){
        heapify(arr, n, i);
    }
}

int find_minimum(int arr[], int n) {
    build_min_heap(arr, n);
    return arr[0];
}

int main() {
    int arr[] = {12, 11, 13, 5, 6, 7};
    int size = sizeof(arr) / sizeof(arr[0]);

    int min = find_minimum(arr, size);

    printf("The smallest number in the list is: %d\n", min);

    return 0;
}
```
The code above defines a C program that utilizes a min heap to find the smallest integer in a list. The `find_minimum` function does this by first transforming the array into a min heap with the `build_min_heap` function, and then simply returning the first element in the heap. The min heap property ensures that the smallest element is always at the first position of the heap.
The heapify function is used to rearrange the elements in the array into a min heap, it does this by identifying the smallest element between the current index i and its two children. If the smallest of these three is not the current index i, it swaps the elements and recursively calls itself on the swapped index.
The swap function is simply a utility that swaps the values of two integers.
