```c
#include <stdio.h>

int binarySearch(int arr[], int l, int r, int x) {
  while (l <= r) {
    int m = l + (r - l) / 2;

    if (arr[m] == x)
      return m;
    
    if (arr[m] < x)
      l = m + 1;
    else
      r = m - 1;
  }
  return -1;
}

int main(void) {
  int arr[] = {2, 3, 4, 10, 40};
  int n = sizeof(arr) / sizeof(arr[0]);
  int x = 10;
  int result = binarySearch(arr, 0, n - 1, x);
  
  if(result == -1)
    printf("Element is not present in array\n");
  else
    printf("Element is present at index %d\n", result);
  
  return 0;
}
```
This C program defines a binary search function which takes in an array, the left and right bounds of the array and the element to search for. If the element is found within the array, the index at which it is found is returned else -1 is returned. A main function initializes an array with some values, specifies the value to search for, calls the binary search function and prints the result. It handles the case where the element is not found by checking if the returned index is -1.
