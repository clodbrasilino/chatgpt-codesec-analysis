2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1] = '\0'` is a defensive belt-and-suspenders measure (technically redundant since `fgets` always null-terminates, but harmless).

4. **Correct allocation size** — `malloc(len / 2 + 1)` is exactly right: for `len` characters, there are `len / 2` odd-indexed characters, plus one byte for the terminator. No off-by-one.
