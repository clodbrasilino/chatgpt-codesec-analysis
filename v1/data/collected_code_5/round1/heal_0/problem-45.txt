```c
#include <stdio.h>
#include <stdlib.h>

int gcd(int a, int b) {
    if (b == 0)
        return a;
    else
        return gcd(b, a % b);
}

int findGcd(int arr[], int n) {
    int result = arr[0];
    for (int i = 1; i < n; i++) {
        result = gcd(result, arr[i]);
        if(result == 1) {
           return 1;
        }
    }
    return result;
}

int main() {
    int n = 5;
    int arr[] = {2, 3, 4, 5, 6};
    printf("The GCD of the array elements is: %d\n", findGcd(arr, n));
    return 0;
}
```
In the above code, `gcd` is a function to compute the gcd of two integers using the Euclidean algorithm, where `b != 0`. `findGcd` is the function that iterates over the array calling `gcd` for every pair of elements.
Ensure that when `result == 1` in the `findGcd` function, you interrupt the loop, because 1 is the lowest gcd you can find, you can't find a lower gcd and the algorithm can't shorten by doing this condition.
The `main` function initializes an array and calls `findGcd` on it, then prints the result.
