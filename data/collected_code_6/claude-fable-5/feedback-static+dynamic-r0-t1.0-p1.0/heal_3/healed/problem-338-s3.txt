```c
#include <stdio.h>
#include <string.h>
#include <limits.h>
#include <stddef.h>

#define MAX_INPUT_SIZE 1024

long long countSubstrings(const char *str, size_t max_len)
{
    long long counts[UCHAR_MAX + 1] = {0};
    long long result = 0;
    size_t i;
    size_t len;

    if (str == NULL) {
        return 0;
    }

    len = strnlen(str, max_len);

    for (i = 0; i < len; i++) {
        counts[(unsigned char)str[i]]++;
    }

    for (i = 0; i <= UCHAR_MAX; i++) {
        result += (counts[i] * (counts[i] + 1)) / 2;
    }

    return result;
}

int main(void)
{
    char buffer[MAX_INPUT_SIZE];
    long long result;

    memset(buffer, 0, sizeof(buffer));

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    result = countSubstrings(buffer, sizeof(buffer));

    if (printf("%lld\n", result) < 0) {
        return 1;
    }

    return 0;
}
```

**Analysis of the identified weakness (CWE-119/CWE-120):**

The Flawfinder warning on the statically-sized `char buffer[MAX_INPUT_SIZE]` is a heuristic flag rather than an actual vulnerability in this code. The original source already mitigates it correctly, and the rewrite preserves those mitigations:

1. **Bounded input reading** — `fgets(buffer, (int)sizeof(buffer), stdin)` limits input to the buffer size, writing at most `sizeof(buffer) - 1` characters plus a null terminator. This prevents the classic `gets()`-style overflow.

2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1] = '\0'` is defensive; `fgets` already null-terminates, but this guards against any edge case.

3. **Bounded string measurement** — `countSubstrings` uses `strnlen(str, max_len)` instead of `strlen`, so even a non-terminated buffer could not cause an out-of-bounds read.

4. **Safe indexing** — the cast `(unsigned char)str[i]` prevents negative array indices on platforms where `char` is signed, which would otherwise be undefined behavior when indexing `counts[]`.

5. **Newline stripping via `strcspn`** — safe even if no newline exists, since `strcspn` returns the index of the terminating null in that case, which is a valid writable position.

6. **Checked I/O return values** — both `fgets` and `printf` results are verified.

One remaining theoretical consideration: `counts[i] * (counts[i] + 1)` could overflow `long long` only if a single character appeared ~4.3 billion times, which is impossible given the 1024-byte buffer, so no fix is required.
