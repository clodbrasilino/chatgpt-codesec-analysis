```c
#include <stdio.h>
#include <stdlib.h>

#define SIZE 100

void find_single_elements(int *arr, int n) {
    int frequency[SIZE] = {0};
    int i;

    for(i = 0; i < n; i++) {
        frequency[arr[i]]++;
    }

    printf("Single elements are: ");
    for(i = 0; i < SIZE; i++) {
        if(frequency[i] == 1) {
            printf("%d ", i);
        }
    }
    printf("\n");
}

int main() {
    int arr[] = {9, 7, 2, 5, 5, 2, 6, 7, 19, 30};
    int n = sizeof(arr) / sizeof(arr[0]);

    find_single_elements(arr, n);

    return 0;
}
```
This C code works for integers. The function find_single_elements() receives an array and its size, builds a frequency array and then checks for elements that only occur once. If such elements exist, they are printed to the console in the ascending order.

Note: This solution assumes that the numbers in the array are in the range of 0 to SIZE-1, where SIZE is a constant and can be adjusted according to requirements. If the range of numbers is not known or is too large, a different approach such as using a hash map may be more appropriate. However, the handling of such cases goes beyond the scope of your question.
