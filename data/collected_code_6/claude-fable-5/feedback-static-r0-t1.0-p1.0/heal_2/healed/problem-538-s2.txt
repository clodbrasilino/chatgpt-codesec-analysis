1. **Bounded length guarantee before `memcpy`:** `len` is now explicitly clamped to `MAX_STRING_LEN - 1U`, guaranteeing the destination buffer of `len + 1U` bytes can always hold the copied data plus the NUL terminator, and eliminating any edge case where `strnlen` returns exactly `MAX_STRING_LEN`.

2. **Integer overflow guard in allocation:** Added a `count > SIZE_MAX / sizeof(char *)` check before `calloc` as defense-in-depth (though `calloc` handles this on conforming implementations, being explicit satisfies static analyzers).

3. **Added `<stdint.h>`** for `SIZE_MAX`.

The `memcpy` call is now provably safe: the destination is allocated with exactly `len + 1U` bytes, `len` bytes are copied, and the terminator is written at index `len` — no overflow is possible.
