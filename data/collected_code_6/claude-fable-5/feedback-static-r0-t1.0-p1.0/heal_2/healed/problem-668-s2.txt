Analysis summary of the changes relative to the original:

1. **CWE-119/CWE-120 (statically-sized buffer):** The original code was already largely safe — `fgets` is bounded by `sizeof(buffer)`, the buffer is explicitly NUL-terminated, and `squeeze_char` uses `strnlen` with an explicit `max_len` clamp. The rewrite preserves all of that and adds a `max_len == 0U` guard in `squeeze_char` to prevent the `max_len - 1U` unsigned underflow if the function were ever called with a zero length.

2. **CWE-120/CWE-20 (`getchar` input validation):** The original had a subtle input-handling flaw: if the user's string filled the entire buffer (no `\n` captured), the leftover characters remained in `stdin`, so the subsequent `getchar()` would read a stale character from the first input rather than the intended squeeze character. The rewrite drains the input stream to the newline when truncation is detected, and also flushes any trailing characters after reading the target character, ensuring `getchar` reads validated, intended input.

3. The `getchar` return value is still checked against `EOF` before narrowing to `char`, avoiding misinterpretation of end-of-stream as a valid character.
