```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

bool is_even(int number)
{
    return (number & 1) == 0;
}

int main(void)
{
    int number;

    printf("Enter an integer: ");

    if (scanf("%d", &number) != 1) {
        fprintf(stderr, "Error: invalid input.\n");
        return EXIT_FAILURE;
    }

    if (is_even(number)) {
        printf("%d is even.\n", number);
    } else {
        printf("%d is odd.\n", number);
    }

    return EXIT_SUCCESS;
}
```

Key points about this implementation:

- **Bitwise check**: `(number & 1) == 0` tests the least significant bit; if it's 0, the number is even. This works correctly for negative numbers too, since two's complement representation preserves the LSB parity.
- **CWE-703 avoidance**: The return value of `scanf` is checked to ensure valid input was actually read before using the variable.
- **CWE-710 avoidance**: Uses `int main(void)`, explicit `bool` return type, `EXIT_SUCCESS`/`EXIT_FAILURE` constants, and braces on all control structures.
- **CWE-664 avoidance**: No dynamically allocated resources or file handles are used, so there are no lifetime management issues; the variable is never read before being validly initialized.
