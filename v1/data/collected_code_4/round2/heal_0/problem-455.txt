```C
#include <stdio.h>
#include <stdbool.h>

bool has31Days(int month) {
    if(month < 1 || month > 12) {
        printf("Error: Invalid month number. It should be between 1 and 12.\n");
        return false;
    }

    if(month == 1 || month == 3 || month == 5 || month == 7 || month == 8 
       || month == 10 || month == 12){
        return true;
    }

    return false;
}

int main() {
    int month;
    printf("Enter the month number: ");
    scanf("%d", &month);

    if(has31Days(month)){
        printf("Month %d contains 31 days\n", month);
    } else {
        if(month >= 1 && month <= 12){
            printf("Month %d does not contain 31 days\n", month);
        }
    }

    return 0;
}
```

This code first checks if the provided month number is valid or not (i.e., between 1 and 12). It makes use of the `bool` type from the `stdbool.h` library to return `true` or `false`. `Has31Days()` checks if the given month contains 31 days or not. If the month is invalid, it returns a message stating that the month number provided is invalid. The `main()` function then uses this function to print whether a given month has 31 days or not.
