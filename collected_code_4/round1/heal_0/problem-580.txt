Here is a C programming solution using recursion to find even numbers from a multi-dimensional array (considered as nested tuple for this context). However, remember that C language doesn't support tuples as in Python.

```C
#include <stdio.h>

void find_even(int *arr, int n) {
    for(int i = 0; i < n; i++) {
        if(arr[i] % 2 == 0)
            printf("%d\n", arr[i]);
    }
}

int main() {
    int arr[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    int n = sizeof(arr)/sizeof(arr[0][0]);
    for(int i = 0; i < 3; i++)
        find_even(arr[i], n);
    return 0;
}
```

This program will loop through the each array within the 2D array (nested tuple), and check each element of this array. If this element is even, it will be printed out. Note that the size of the array is found using the `sizeof` function, and the size of each element array is assumed to be equal to the size of the overall array for this example.
