            write++;
        }

}

The Flawfinder warnings flagged in the original code are **false positives** — the code already implements the necessary mitigations, so the rewrite preserves the same logic:

1. **CWE-120 / CWE-20 (buffer boundary checks in loops):** All array accesses are bounded. `strnlen(str, max_len)` guarantees `len < max_len`, so the loop index `read` never exceeds the valid buffer range, and `write <= read` always holds, making `str[write]` safe — including the final NUL write at `str[write]`, since `write <= len < max_len`.

2. **NULL and zero-length guards:** `str == NULL` and `max_len == 0` are rejected up front, preventing dereference of invalid pointers.

3. **Unterminated-string protection:** The `len >= max_len` check rejects inputs that are not properly NUL-terminated within the declared buffer size, avoiding out-of-bounds reads.

4. **`isalnum` UB avoidance:** The cast to `(unsigned char)` before passing to `isalnum()` prevents undefined behavior for negative `char` values (required by the C standard for `<ctype.h>` functions).

5. **In-place compaction:** Since `write` never outpaces `read`, the two-index compaction is safe within a single buffer with no risk of overlap corruption.

6. **Checked I/O in `main`:** Return values of `printf`/`fprintf` are verified, and `sizeof(input)` correctly conveys the full buffer size (including the NUL terminator) to the callee.
