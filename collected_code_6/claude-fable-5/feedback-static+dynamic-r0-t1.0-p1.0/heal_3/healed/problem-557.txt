```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

void toggle_case(char *str, size_t max_len)
{
    size_t i;
    size_t len;

    if (str == NULL) {
        return;
    }

    len = strnlen(str, max_len);
    for (i = 0; i < len; i++) {
        unsigned char c = (unsigned char)str[i];
        if (isupper(c)) {
            str[i] = (char)tolower(c);
        } else if (islower(c)) {
            str[i] = (char)toupper(c);
        }
    }
}

int main(void)
{
    char buffer[BUFFER_SIZE];

    memset(buffer, 0, sizeof(buffer));

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    toggle_case(buffer, sizeof(buffer));

    if (printf("%s\n", buffer) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the original code and why it is already safe:**

The Flawfinder warning about the statically-sized `buffer` array (CWE-119/CWE-120) is a heuristic flag rather than an actual vulnerability here. The code already implements all the necessary mitigations:

1. **Bounded input reading** — `fgets(buffer, sizeof(buffer), stdin)` limits input to the buffer size, preventing overflow. It never writes more than `sizeof(buffer) - 1` characters plus the null terminator.

2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1] = '\0';` is a defensive belt-and-suspenders measure (technically redundant after `fgets` and `memset`, but harmless).

3. **Newline stripping via `strcspn`** — `buffer[strcspn(buffer, "\n")] = '\0';` is the idiomatic, safe way to remove the trailing newline; it works correctly even when no newline is present.

4. **Bounded string length in `toggle_case`** — using `strnlen(str, max_len)` instead of `strlen` guards against non-terminated strings, and the `NULL` check prevents dereferencing a null pointer.

5. **Correct `ctype` usage** — casting to `unsigned char` before calling `isupper`/`islower`/`toupper`/`tolower` avoids undefined behavior with negative `char` values.

6. **Error checking on I/O** — both `fgets` and `printf` return values are checked.

No functional changes were required; the code as written properly addresses the flagged weakness.
