```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>
#include <stdlib.h>

size_t longest_word_length(const char *str)
{
    size_t max_len = 0;
    size_t current_len = 0;
    size_t i;

    if (str == NULL) {
        return 0;
    }

    for (i = 0; str[i] != '\0'; i++) {
        if (isalpha((unsigned char)str[i])) {
            current_len++;
            if (current_len > max_len) {
                max_len = current_len;
            }
        } else {
            current_len = 0;
        }
    }

    return max_len;
}

int main(void)
{
    char buffer[1024];
    size_t result;

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[strcspn(buffer, "\n")] = '\0';

    result = longest_word_length(buffer);

    if (printf("Longest word length: %zu\n", result) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis notes:**

The Flawfinder warning about the statically-sized `buffer` array (CWE-119/CWE-120) is a low-risk, informational flag rather than an actual vulnerability in this code. The identified weakness is already properly mitigated:

1. **Bounds-checked input**: `fgets(buffer, sizeof(buffer), stdin)` limits the read to at most 1023 characters plus the null terminator, so no overflow is possible. Using `sizeof(buffer)` rather than a hardcoded literal ensures the bound stays correct if the array size changes.

2. **Guaranteed null termination**: `fgets` always null-terminates on success, and the `strcspn` trick safely strips the trailing newline without risk of out-of-bounds access (it returns the index of the first `\n` or the index of the terminating `\0` if none exists).

3. **Error handling**: The return values of `fgets` and `printf` are both checked, and failures propagate via `EXIT_FAILURE`.

4. **Correct `ctype` usage**: The cast to `unsigned char` before calling `isalpha` avoids undefined behavior on platforms where `char` is signed and the input contains bytes ≥ 128.

5. **NULL guard**: `longest_word_length` defensively handles a `NULL` pointer.

The code as written is safe; no functional changes were required to address the flagged weakness.
