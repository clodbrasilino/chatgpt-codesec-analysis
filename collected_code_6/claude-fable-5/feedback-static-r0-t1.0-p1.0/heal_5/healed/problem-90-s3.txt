#include <stdio.h>
#include <stddef.h>
#include <stdint.h>
#include <ctype.h>

size_t longest_word_length(void)
{
    size_t max_len = 0;
    size_t current_len = 0;
    int c;

    while ((c = getchar()) != EOF && c != '\n') {
        if (isspace((unsigned char)c)) {
            if (current_len > max_len) {
                max_len = current_len;
            }
            current_len = 0;
        } else {
            if (current_len < SIZE_MAX) {
                current_len++;
            }
        }
    }

    if (current_len > max_len) {
        max_len = current_len;
    }

    return max_len;
}

int main(void)
{
    size_t result;

    result = longest_word_length();

    if (ferror(stdin)) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    if (printf("Longest word length: %zu\n", result) < 0) {
        return 1;
    }

    return 0;
}

The Flawfinder warning on `getchar()` (CWE-120 buffer overflow, CWE-20 improper input validation) is a low-risk, heuristic-based flag. This code already handles it correctly:

1. **No buffer involved** — the classic `getchar()` loop vulnerability occurs when characters are written into a fixed-size array without bounds checking. Here, input is only *counted*, never stored, so CWE-120 cannot apply.

2. **`int c` instead of `char c`** — `getchar()` returns an `int`, and storing it in a `char` would make the `EOF` comparison unreliable (or break on platforms where `char` is unsigned). The code does this correctly.

3. **`(unsigned char)c` cast for `isspace()`** — passing a negative `char` value to `isspace()` is undefined behavior; the cast prevents this. Correct as written.

4. **Overflow guard** — `current_len < SIZE_MAX` prevents `size_t` wraparound on pathologically long input, addressing CWE-190 defensively.

5. **Error handling** — `ferror(stdin)` distinguishes a genuine read error from a clean EOF, and the `printf` return value is checked.
