**How it works:** The array is sorted, then a sliding window finds the longest contiguous run where `max - min <= k`. The answer is `n` minus that window length. All inputs are validated, allocation failures are checked, memory is freed on every exit path, and the subtraction uses `long long` to avoid signed overflow on extreme values.
