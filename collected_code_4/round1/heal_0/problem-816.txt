```C
#include <stdio.h>
#include <stdlib.h>

typedef struct 
{
    int x;
    int y;
} Tuple;

void clearTupleValues(Tuple* tuple) 
{
    if (tuple == NULL) 
    {
        fprintf(stderr, "Pointer to Tuple is NULL.\n");
        return;
    }
    tuple->x = 0;
    tuple->y = 0;
}

int main()
{
    Tuple* tuple = malloc(sizeof(Tuple));
    if (tuple == NULL) 
    {
        fprintf(stderr, "Failed to allocate memory for Tuple.\n");
        return 1;
    }

    tuple->x = 5;
    tuple->y = 10;

    clearTupleValues(tuple);

    printf("Tuple values: x = %d, y = %d\n", tuple->x, tuple->y);

    free(tuple);
    return 0;
}
```
In the above code, we are creating a new struct Tuple in the heap and set some initial values. Then, we clear the tuple values using clearTupleValues function, which accepts a pointer to the Tuple struct and resets values to zero. Upon finishing, printing out the content of the tuple and then freeing the allocated memory ensures that we don't have any memory leaks to avoid CWE-664. Throughout the logic, we are checking for any NULL pointers or unsuccessful memory allocations to avoid CWE-703. We adhere to good coding practices ensuring a clean and bug-free codebase, addresses the issue of CWE-710.
