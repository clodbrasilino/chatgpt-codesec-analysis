```C
#include <stdio.h>
#include <math.h>

int evenOddDivisor(int n) {
    int count = 0;
    for (int i = 1; i <= sqrt(n); i++) {
        if (n % i == 0) {
            if (n / i == i)
                count++;
            else 
                count += 2;
        }
    }
    if (count % 2 == 0)
        return 2;
    else 
        return 1; 
}

int main() {
    int num;
    printf("Enter a number: ");
    scanf("%d", &num);

    int result = evenOddDivisor(num);
    if (result == 2)
        printf("Even number of divisors\n");
    else
        printf("Odd number of divisors\n");

    return 0;
}
```
In this code, we are first calculating the count of divisors by running a loop that goes from 1 to sqrt(n) and checks if each number i divides the entered number n. If it does, we then check if dividing n by i gives i itself. If it does, it means the divisor is repeated (as n is a perfect square), and so we only increment the count of divisors by 1. If not, we increment it by 2.

Once we have the count, we simply check if it's even or odd by checking if dividing it by 2 gives a remainder. If it does, we know that the number of divisors is odd and we print out an appropriate message to the console. If not, we do the same thing for even number of divisors.
