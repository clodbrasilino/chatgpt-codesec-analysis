```c
#include <stdio.h>

void multiply_adjacent(int arr[], int size) {
    int i;
    for(i = 0; i < size - 1; i++) {
        printf("%d ", arr[i] * arr[i+1]);
    }
    printf("\n");
}

int main() {
    int arr[] = {1, 2, 3, 4, 5};
    int size = sizeof(arr)/sizeof(arr[0]);
    multiply_adjacent(arr, size);
    return 0; 
}
```
This piece of code starts by initializing an array `arr` with five integers `{1, 2, 3, 4, 5}` and calculates the number of elements in the array with `int size = sizeof(arr)/sizeof(arr[0])`. Then, it calls the function `multiply_adjacent(arr, size)`, which goes through each element in the array (excluding the last one) and prints the multiplication of the current element with its next adjacent element. The result is displayed on the console.
