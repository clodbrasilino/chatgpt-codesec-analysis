C language doesn't support regular expressions out of the box and requires using libraries like PCRE (Perl Compatible Regular Expressions) to handle them. But as you requested, I would rather implement this task without regular expressions and depend only on C libraries. 

Here is the implementation:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char* convert_date_format(const char* date) {
    char* new_date = (char*) malloc(sizeof(char) * 11);
    if(!new_date) {
        printf("Error allocating memory.\n");
        exit(1);
    }
    
    strncpy(new_date, date + 8, 2);
    new_date[2] = '-';
    strncpy(new_date + 3, date + 5, 2);
    new_date[5] = '-';
    strncpy(new_date + 6, date, 4);
    new_date[10] = '\0';
    
    return new_date;
}

int main() {
    char* old_format = "2022-01-01";
    char* new_format = NULL;

    new_format = convert_date_format(old_format);
    
    if(new_format) {
        printf("The date in dd-mm-yyyy format is: %s\n", new_format);
        free(new_format);
    }
    
    return 0;
}
```

This program takes a date in `yyyy-mm-dd` format, converts it to `dd-mm-yyyy` format and prints the result. Please note that success of `malloc` is checked to avoid possible null pointer dereference error (CWE-690). Moreover, calling `free` after using the dynamically allocated memory helps prevent memory leaks, closing potential vulnerability linked with CWE-664. Observe that the code avoids CWE-703: It checks whether memory allocation for the new date format was successful before operating on it. Finally, the implementation adheres with C standard requirements (CWE-710) like error handling, correct usage of library functions etc.
