```c
#include <stdio.h>
#include <stdlib.h>

int findPeakElement(const int *arr, size_t n)
{
    size_t low = 0;
    size_t high = n - 1;

    while (low < high) {
        size_t mid = low + (high - low) / 2;
        if (arr[mid] < arr[mid + 1]) {
            low = mid + 1;
        } else {
            high = mid;
        }
    }
    return (int)low;
}

int main(void)
{
    int arr[] = {1, 3, 20, 4, 1, 0};
    size_t n = sizeof(arr) / sizeof(arr[0]);

    if (n == 0) {
        fprintf(stderr, "Array is empty\n");
        return EXIT_FAILURE;
    }

    int peakIndex = findPeakElement(arr, n);

    if (printf("Peak element is %d at index %d\n", arr[peakIndex], peakIndex) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

This implementation uses a binary search approach with O(log n) time complexity. Key safety considerations addressed:

- **CWE-664**: No dynamic memory allocation is used, so there are no resource lifetime issues. The array is stack-allocated with a fixed lifetime scoped to `main`.
- **CWE-703**: The empty-array case is checked before calling `findPeakElement` (which would otherwise underflow `n - 1`), and the return value of `printf` is verified.
- **CWE-710**: The code adheres to standards by using `size_t` for sizes/indices, `const` correctness on the array parameter, `int main(void)` signature, explicit casts, and `EXIT_SUCCESS`/`EXIT_FAILURE` return codes.
