**Key safety considerations addressed:**

- **CWE-703**: The return value of `scanf` is checked, and the zero-input edge case is explicitly handled with an error message and failure exit code rather than being silently ignored.
- **CWE-664**: No dynamic resources (heap memory, file handles) are used, so there is nothing left unreleased; all variables are initialized before use.
- **CWE-710**: The code uses `static` linkage for the internal helper, explicit `void` parameter lists, unsigned literals matching unsigned types, braces on all control blocks, and standard exit codes (`EXIT_SUCCESS`/`EXIT_FAILURE`). The loop guard `result <= (UINT_MAX >> 1U)` prevents unsigned shift overflow wraparound.
