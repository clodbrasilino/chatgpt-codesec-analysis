1. **`getchar` in a loop (CWE-120, CWE-20):** `discard_remaining_input()` never writes to a buffer — it only consumes characters until newline or EOF, so no overflow is possible. The loop is correctly bounded by the `EOF` check, preventing an infinite loop on stream closure. No change required.
