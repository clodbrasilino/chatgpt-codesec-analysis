```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

#define MAX_INPUT_LEN 256

long ascii_sum(const char *str, size_t max_len)
{
    long sum = 0;
    size_t i;
    size_t len;

    if (str == NULL) {
        return -1;
    }

    len = strnlen(str, max_len);
    if (len == max_len) {
        return -1;
    }

    for (i = 0; i < len; i++) {
        sum += (unsigned char)str[i];
    }

    return sum;
}

int main(void)
{
    char buffer[MAX_INPUT_LEN];
    long result;

    printf("Enter a string: ");
    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    result = ascii_sum(buffer, sizeof(buffer));
    if (result < 0) {
        fprintf(stderr, "Invalid string\n");
        return EXIT_FAILURE;
    }

    printf("Sum of ASCII values: %ld\n", result);

    return EXIT_SUCCESS;
}
```

**Analysis notes:**

The original code was already well-hardened against the Flawfinder warning (CWE-119/CWE-120). The statically-sized `buffer` flagged by the tool is properly protected by the following mitigations, which I have preserved:

1. **Bounded input:** `fgets(buffer, sizeof(buffer), stdin)` limits reads to the buffer size, preventing overflow — unlike `gets()` or unbounded `scanf("%s", ...)`.
2. **Guaranteed termination:** `buffer[sizeof(buffer) - 1] = '\0'` is defensive redundancy (fgets already null-terminates), ensuring the buffer is always a valid C string.
3. **Newline stripping via `strcspn`:** safer than the common `strchr`-based idiom, since it handles the no-newline case without dereferencing NULL.
4. **Bounded length computation:** `ascii_sum` uses `strnlen` with an explicit `max_len` rather than `strlen`, and rejects NULL pointers and unterminated input (`len == max_len`).
5. **Overflow-safe accumulation:** casting each char to `unsigned char` before summing avoids sign-related surprises on platforms where `char` is signed; the maximum possible sum (255 × 255) fits comfortably in a `long`.
6. **Error propagation:** the sentinel return value `-1` is checked in `main`, and failures exit with `EXIT_FAILURE` after reporting to `stderr`.

No functional changes were required — the Flawfinder hit is a false positive here, as all accesses to the fixed-size array are bounds-checked. The code follows the tool's own recommended remediation ("use functions that limit length").
