```C
#include <stdio.h>
#include <math.h>

double findDigits(int n) {
    if (n < 0)
        return 0;
    if (n <= 1)
        return 1;
    double digits = 0;
    for (int i=2; i<=n; i++)
        digits += log10(i);
    return floor(digits) + 1;
}

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    printf("Number of digits in factorial of %d is %0.lf\n", n, findDigits(n));
    return 0;
}
```
As asked, here is the function in C programming language that counts the number of digits in the factorial of a given number. 

Please note this is an optimized solution using logarithms to calculate the number of digits instead of first finding factorial which can be a very big number for relatively small input number and then finding number of digits in it.

The main function takes a number as input, and uses another function findDigits to find the number of digits in the factorial of the input number.
