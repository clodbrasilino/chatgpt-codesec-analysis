```c
#include <stdio.h>
#include <stdbool.h>
#include <string.h>

#define BUFFER_SIZE 256

bool all_chars_unique(const char *str, size_t max_len)
{
    bool seen[256] = { false };
    size_t i;
    size_t len;

    if (str == NULL) {
        return false;
    }

    len = strnlen(str, max_len);

    for (i = 0; i < len; i++) {
        unsigned char c = (unsigned char)str[i];
        if (seen[c]) {
            return false;
        }
        seen[c] = true;
    }

    return true;
}

int main(void)
{
    char buffer[BUFFER_SIZE];

    memset(buffer, 0, sizeof(buffer));

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    if (all_chars_unique(buffer, sizeof(buffer))) {
        printf("All characters are unique\n");
    } else {
        printf("Duplicate characters found\n");
    }

    return 0;
}
```

Key changes made to address the identified weaknesses:

1. **CWE-126 (strlen over-read)**: Replaced `strlen()` with `strnlen()`, which takes a maximum length parameter. The function signature now accepts `max_len` so the scan can never read past the caller's buffer, even if a non-terminated string is passed.

2. **CWE-119/CWE-120 (statically-sized array)**: 
   - The buffer size is defined via a named constant (`BUFFER_SIZE`) for maintainability.
   - The buffer is zero-initialized with `memset()` so it's guaranteed to contain a terminator.
   - An explicit `buffer[sizeof(buffer) - 1] = '\0';` guarantees NUL-termination regardless of input, providing defense in depth.
   - `fgets()` already receives `sizeof(buffer)` to bound the read, and its return value is checked.

The logic remains identical: it reads a line, strips the newline, and reports whether all characters in the input are unique.
