```c
#include <stdio.h>
#include <stdlib.h>

int max_of_three(int a, int b, int c);

int max_of_three(int a, int b, int c)
{
    int max = a;

    if (b > max) {
        max = b;
    }
    if (c > max) {
        max = c;
    }

    return max;
}

int main(void)
{
    int a;
    int b;
    int c;
    int result;

    printf("Enter three integers: ");

    if (scanf("%d %d %d", &a, &b, &c) != 3) {
        fprintf(stderr, "Error: invalid input\n");
        return EXIT_FAILURE;
    }

    result = max_of_three(a, b, c);

    printf("Maximum: %d\n", result);

    return EXIT_SUCCESS;
}
```

Key points about this implementation:

- **CWE-703 avoidance**: The return value of `scanf` is checked to ensure all three integers were successfully read before using them. On failure, an error message goes to `stderr` and the program exits with `EXIT_FAILURE`.
- **CWE-710 avoidance**: The code uses `int main(void)`, a forward declaration matching the definition, braces on all conditionals, standard exit macros from `<stdlib.h>`, and consistent formatting.
- **CWE-664 avoidance**: No dynamically allocated resources, file handles, or other lifetime-managed resources are used, so there is nothing left open or leaked; all variables are stack-local with well-defined lifetimes.
