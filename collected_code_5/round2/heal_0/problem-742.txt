```C
#include <math.h>
#include <stdio.h>

double calculateTetrahedronArea(double edge) {
    if(edge <= 0) {
        printf("Error: Edge length of tetrahedron should be positive.\n");
        return -1.0;
    }
    return sqrt(3) * pow(edge, 2);
}

int main() {
    double edge;
    printf("Enter the edge length of the tetrahedron: ");
    if(scanf("%lf", &edge) != 1) {
        printf("Error reading the edge length.\n");
        return 1;
    }
    double area = calculateTetrahedronArea(edge);
    if(area != -1.0) {
        printf("The area of the tetrahedron with edge length %.2lf is: %.2lf\n", edge, area);
    }
    return 0;
}
```
This function calculates the surface area of a regular tetrahedron with a given edge length. If an improper edge length (such as a negative number or a non-numeric character) is given, the function handles this exceptional condition and terminates gracefully with an error message. There is also proper handling of resources such as the edge length entered by the user and the area calculation.
