#include <ctype.h>
#include <string.h>
#include <stdlib.h>

char *remove_non_alnum(char *str, size_t max_len);

char *remove_non_alnum(char *str, size_t max_len)
{
    size_t read;
    size_t write;
    size_t len;

    if (str == NULL || max_len == 0) {
        return NULL;
    }

    len = strnlen(str, max_len);
    if (len >= max_len) {
        return NULL;
    }

    write = 0;
    for (read = 0; read < len; read++) {
        if (isalnum((unsigned char)str[read])) {
            if (write < max_len - 1) {
                str[write] = str[read];
                write++;
            } else {
                break;
            }
        }
    }

    if (write >= max_len) {
        return NULL;
    }
    str[write] = '\0';

    return str;
}

int main(void)
{
    char input[] = "Hello, World! 123 #$%^ test_case-42";
    char *result;

    result = remove_non_alnum(input, sizeof(input));
    if (result == NULL) {
        fprintf(stderr, "Error: invalid input string\n");
        return EXIT_FAILURE;
    }

    if (printf("Result: %s\n", result) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}

**Analysis of the original code and the fixes applied:**

The original code was already largely defensive against the Flawfinder warnings, which are risk-level-1 informational hits rather than confirmed vulnerabilities. Here's the reasoning behind the rewritten version:

1. **NULL and zero-length guards** — Retained. `str == NULL || max_len == 0` prevents dereferencing invalid pointers and guarantees `max_len - 1` never underflows later.

2. **Bounded length measurement** — `strnlen(str, max_len)` never reads past the buffer, and rejecting `len >= max_len` guarantees the input is properly NUL-terminated within bounds. This addresses CWE-120/CWE-20 concerns about unbounded reads.

3. **Read loop bound simplified** — The original condition `read < len && read < max_len` was redundant: after the `len >= max_len` check, `len < max_len` is an invariant, so `read < len` alone is sufficient and equally safe. Redundant checks can obscure the actual invariant, so I removed it.

4. **Write bound** — `write < max_len - 1` reserves space for the terminating NUL, so `str[write] = str[read]` can never overflow. Since `write <= read < len < max_len`, the write index is provably in bounds.

5. **Final NUL termination** — The `write >= max_len` check before `str[write] = '\0'` is technically unreachable (the loop guarantees `write <= max_len - 1`), but it's harmless defense-in-depth and satisfies static analyzers, so it stays.

6. **`isalnum` cast** — The `(unsigned char)` cast is preserved; passing a plain `char` that might be negative is undefined behavior per the C standard.

7. **`main`** — Checks the return values of both `remove_non_alnum` and `printf`, returning `EXIT_FAILURE`/`EXIT_SUCCESS` appropriately.
