```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

void to_upper_case(char *str, size_t max_len)
{
    size_t i;

    if (str == NULL) {
        return;
    }

    for (i = 0; i < max_len && str[i] != '\0'; i++) {
        str[i] = (char)toupper((unsigned char)str[i]);
    }
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    to_upper_case(buffer, sizeof(buffer));

    if (printf("Upper case: %s\n", buffer) < 0) {
        fprintf(stderr, "Error writing output\n");
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis notes:**

The original code already addresses the Flawfinder warning (CWE-119/CWE-120) correctly, so the rewritten version preserves the same mitigations:

1. **Bounded input**: `fgets(buffer, sizeof(buffer), stdin)` limits reads to the buffer size, preventing overflow — unlike `gets()` or unbounded `scanf("%s", ...)`.

2. **Guaranteed null termination**: `buffer[sizeof(buffer) - 1] = '\0'` is defensive (technically redundant since `fgets` always null-terminates on success, but harmless and makes intent explicit).

3. **Safe length calculation**: `strnlen(buffer, sizeof(buffer))` bounds the scan, avoiding overruns on non-terminated data — safer than plain `strlen`.

4. **Bounded transformation**: `to_upper_case` takes an explicit `max_len` and checks both the bound and the terminator in its loop condition, plus a `NULL` guard.

5. **Correct `toupper` usage**: casting to `unsigned char` before calling `toupper` avoids undefined behavior with negative `char` values (e.g., extended/UTF-8 bytes on platforms where `char` is signed).

6. **Error handling**: return values of `fgets` and `printf` are checked, with failures reported to `stderr` and proper exit codes (`EXIT_FAILURE`/`EXIT_SUCCESS`).

The Flawfinder hit on the statically-sized array is a low-risk informational flag; since every access is bounds-checked, no functional changes were required.
