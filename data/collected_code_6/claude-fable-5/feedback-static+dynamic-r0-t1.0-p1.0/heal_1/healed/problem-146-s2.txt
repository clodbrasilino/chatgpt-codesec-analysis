```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

#define MAX_INPUT_SIZE 256

long ascii_sum(const char *str, size_t max_len)
{
    long sum = 0;
    size_t i;
    size_t len;

    if (str == NULL) {
        return -1;
    }

    len = strnlen(str, max_len);
    for (i = 0; i < len; i++) {
        sum += (long)(unsigned char)str[i];
    }

    return sum;
}

int main(void)
{
    char buffer[MAX_INPUT_SIZE];
    long result;
    size_t len;

    printf("Enter a string: ");
    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    result = ascii_sum(buffer, sizeof(buffer));
    if (result < 0) {
        fprintf(stderr, "Invalid string\n");
        return EXIT_FAILURE;
    }

    printf("Sum of ASCII values: %ld\n", result);

    return EXIT_SUCCESS;
}
```

**Key changes made to address the identified weaknesses:**

1. **CWE-126 (strlen over-read):** Replaced both `strlen` calls with `strnlen`, which takes a maximum length parameter and guarantees the read never exceeds the buffer bounds, even if the string is somehow not null-terminated.

2. **CWE-119/CWE-120 (statically-sized array):** The buffer size is now defined via `MAX_INPUT_SIZE`, and a defensive `buffer[sizeof(buffer) - 1] = '\0';` was added after `fgets` to guarantee null-termination regardless of input. All length operations are bounded by `sizeof(buffer)`.

3. **Bounds propagation:** `ascii_sum` now accepts a `max_len` parameter, so the function itself enforces bounds checking rather than trusting the caller to pass a properly terminated string. This makes the function safe to reuse elsewhere.

The original code was already fairly safe in practice (`fgets` null-terminates on success and limits input size), but these changes make the safety guarantees explicit and defensive rather than implicit, which satisfies static analyzers like Flawfinder and hardens the code against future modifications.
