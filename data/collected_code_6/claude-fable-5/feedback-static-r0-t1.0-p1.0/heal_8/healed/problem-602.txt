```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

#define BUFFER_SIZE 256

int first_repeated_char(const char *str)
{
    bool seen[256] = { false };
    size_t i;

    if (str == NULL) {
        return -1;
    }

    for (i = 0; str[i] != '\0'; i++) {
        unsigned char c = (unsigned char)str[i];
        if (seen[c]) {
            return (int)c;
        }
        seen[c] = true;
    }

    return -1;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    int result;

    printf("Enter a string: ");
    fflush(stdout);

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    result = first_repeated_char(buffer);

    if (result == -1) {
        printf("No repeated character found\n");
    } else {
        printf("First repeated character: %c\n", (char)result);
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the flagged weakness (CWE-119/CWE-120):**

The Flawfinder warning on the statically-sized `char buffer[BUFFER_SIZE]` is a low-risk, informational finding. The original code already mitigates the potential overflow correctly, and the rewritten version preserves those mitigations:

1. **Bounded input:** `fgets(buffer, sizeof(buffer), stdin)` limits reads to at most `BUFFER_SIZE - 1` characters plus the null terminator, preventing buffer overflow. Using `sizeof(buffer)` rather than a hardcoded constant keeps the bound correct even if `BUFFER_SIZE` changes.

2. **Guaranteed termination:** `buffer[sizeof(buffer) - 1] = '\0';` is a defensive belt-and-suspenders measure — `fgets` already null-terminates on success, but this guards against any misuse or future refactoring.

3. **Return value checked:** The `NULL` return from `fgets` is handled, avoiding operations on uninitialized buffer contents on EOF or read error.

4. **Safe newline stripping:** `strcspn(buffer, "\n")` always returns an index within the string bounds (at worst the index of the terminating null), so the assignment can never write out of bounds — unlike the common unsafe idiom `buffer[strlen(buffer) - 1] = '\0'`, which underflows on an empty string.

5. **Safe lookup table indexing:** In `first_repeated_char`, the cast to `unsigned char` before indexing `seen[256]` prevents negative indices on platforms where `char` is signed, and the `NULL` check guards against invalid pointers.

No functional changes were required; the code as written already satisfies the bounds-checking recommendations associated with the CWE-119/CWE-120 finding.
