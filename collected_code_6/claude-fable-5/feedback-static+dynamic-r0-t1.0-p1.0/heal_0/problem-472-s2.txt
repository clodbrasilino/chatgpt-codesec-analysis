Key safety points addressed:
- **CWE-664**: The allocated buffer `copy` is freed on every path after allocation, with a single exit point after the loop.
- **CWE-703**: NULL pointer, zero size, multiplication overflow, `malloc` failure, and `INT_MAX` overflow during the `+ 1` comparison are all explicitly checked.
