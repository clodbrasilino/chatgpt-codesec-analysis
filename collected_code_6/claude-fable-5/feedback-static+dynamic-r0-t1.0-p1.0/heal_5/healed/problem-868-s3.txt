```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

#define MAX_INPUT_LEN 4096U

size_t length_of_last_word(const char *s)
{
    size_t len;
    size_t end;
    size_t count;

    if (s == NULL) {
        return 0U;
    }

    len = 0U;
    while (len < MAX_INPUT_LEN && s[len] != '\0') {
        len++;
    }

    if (len == 0U) {
        return 0U;
    }

    end = len;
    while (end > 0U && isspace((unsigned char)s[end - 1U])) {
        end--;
    }

    count = 0U;
    while (end > 0U && !isspace((unsigned char)s[end - 1U])) {
        count++;
        end--;
    }

    return count;
}

int main(void)
{
    char buffer[MAX_INPUT_LEN];
    size_t result;
    size_t len;

    memset(buffer, 0, sizeof(buffer));

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        buffer[0] = '\0';
    }

    buffer[sizeof(buffer) - 1U] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0U && buffer[len - 1U] == '\n') {
        buffer[len - 1U] = '\0';
    }

    result = length_of_last_word(buffer);

    if (printf("%lu\n", (unsigned long)result) < 0) {
        return 1;
    }

    if (fflush(stdout) != 0) {
        return 1;
    }

    return 0;
}
```

Key changes made to address the identified weaknesses:

1. **Missing output (test cases 0, 1, 2 failing with "no output")** — the most likely culprit is unflushed or non-portable output. I added an explicit `fflush(stdout)` check to guarantee the result is written before exit, and replaced `%zu` with `%lu` plus a cast to `unsigned long`, since `%zu` is unsupported on some older/non-C99-conformant runtimes (e.g., legacy MSVC), which silently produces no or garbage output.

2. **Trailing newline handling** — `fgets` retains the `'\n'`, which was previously handled only implicitly by the `isspace` trimming; I now strip it explicitly using a bounded `strnlen`, keeping the parsing logic independent of input framing.

3. **CWE-119/CWE-120 (buffer bounds)** — retained the defensive measures: `fgets` bounded by `sizeof(buffer)`, forced NUL termination at `buffer[sizeof(buffer) - 1U]`, `memset` initialization, and bounded scanning in `length_of_last_word` via `MAX_INPUT_LEN` and `strnlen` instead of `strlen`.

4. **NULL and empty-input safety** — the `NULL` guard and zero-length early return in `length_of_last_word` are preserved, and a failed `fgets` degrades gracefully to an empty string, printing `0` rather than producing no output.
