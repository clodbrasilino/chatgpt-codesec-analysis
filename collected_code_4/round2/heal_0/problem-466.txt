```c
#include <stdio.h>

int findPeakElement(int arr[], int n) {
    if(n == 1)  
      return arr[0]; 
   if(arr[0] >= arr[1]) 
      return 0; 
   if(arr[n - 1] >= arr[n - 2]) 
      return n - 1; 
   
   for(int i = 1; i < n - 1; i++) 
      if(arr[i] >= arr[i - 1] && arr[i] >= arr[i + 1]) 
         return i;

   return -1;  
}

int main() {
    int arr[] = {1, 3, 20, 4, 1, 0};
    int n = sizeof(arr)/sizeof(arr[0]);
    int index = findPeakElement(arr, n);
    if (index != -1)
        printf("The peak element is: %d\n", arr[index]);
    else
        printf("No peak element found in the array\n");

    return 0;
}
```
The function `findPeakElement()` checks the edge (first and last) elements and then checks the elements from index positions 1 to n-2. If any number is greater than both of its neighbors, this function returns the index of this number, otherwise, the function returns -1 indicating that it did not find a peak element. The `main()` function invokes `findPeakElement()` and then either prints the peak element if the returned index is not equal to -1 or prints a message saying that no peak element was found in the array.
