```C
#include <stdio.h>

unsigned long count_hexadecimal_numbers(unsigned long start, unsigned long end)
{
    unsigned long count = 0;
    for(unsigned long i = start; i <= end; ++i) {
        ++count;
    }
    return count;
}

int main()
{
    unsigned long start, end;
    printf("Enter range start: ");
    scanf("%lu", &start);
    
    printf("Enter range end: ");
    scanf("%lu", &end);
    
    if(start > end) {
        printf("Start of range is greater than the end. Exiting.\n");
        return -1;
    }
    
    unsigned long count = count_hexadecimal_numbers(start, end);
    
    printf("Count of hexadecimal numbers between %lu and %lu is: %lu\n", start, end, count);

    return 0;
}
```
In the given function, we are counting the numbers from a given start to an end which could also be interpreted as hexadecimal numbers. Note that any number can be represented in hexadecimal form. We're properly managing resources here (no dynamic memory allocation, so no leaks), handling exceptional conditions (range start greater than end), and adhering to coding standards.
