2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1U] = '\0';` is a defensive belt-and-suspenders measure ensuring the buffer is always a valid C string even if `fgets` behaved unexpectedly.

3. **Length-bounded string operations** — `strnlen(buffer, sizeof(buffer))` is used instead of `strlen`, so length computation can never run past the buffer even if termination were somehow lost.
