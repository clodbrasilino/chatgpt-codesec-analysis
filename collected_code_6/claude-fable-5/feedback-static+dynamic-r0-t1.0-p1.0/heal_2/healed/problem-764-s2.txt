```c
#include <stdio.h>
#include <ctype.h>
#include <stddef.h>
#include <string.h>

#define BUFFER_SIZE 256

size_t count_numeric(const char *str)
{
    size_t count = 0;

    if (str == NULL) {
        return 0;
    }

    while (*str != '\0') {
        if (isdigit((unsigned char)*str)) {
            count++;
        }
        str++;
    }

    return count;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t result;
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    } else {
        int ch;
        while ((ch = getchar()) != '\n' && ch != EOF) {
        }
    }

    result = count_numeric(buffer);

    printf("Number of numeric characters: %zu\n", result);

    return 0;
}
```

**Analysis summary:**

The original code was already well-defended, and the Flawfinder hits were largely false positives. Here's why each identified weakness is mitigated:

1. **CWE-119/CWE-120 (statically-sized buffer):** The buffer is only ever written to via `fgets(buffer, sizeof(buffer), stdin)`, which strictly bounds the write to `BUFFER_SIZE - 1` characters plus the null terminator. No overflow is possible.

2. **CWE-126 (`strlen` over-read):** `fgets` always null-terminates on success, and the code adds a defensive `buffer[sizeof(buffer) - 1] = '\0'` as a belt-and-suspenders measure. In the rewrite, `strlen` was replaced with `strnlen(buffer, sizeof(buffer))`, which guarantees the scan can never read past the buffer even if termination were somehow violated.

3. **CWE-120/CWE-20 (`getchar` in a loop):** The drain loop discards excess input without storing it anywhere, so no buffer boundary is involved. It correctly uses an `int` for the return value so `EOF` is distinguishable from valid characters, preventing an infinite loop on end-of-stream.

Other good practices already present and preserved: the `(unsigned char)` cast before `isdigit` (avoiding undefined behavior for negative `char` values), the `NULL` check in `count_numeric`, checking the return value of `fgets`, and using `%zu` for `size_t`.
