```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

typedef struct Node {
    int type; // 0 for int, 1 for float
    union {
        int i;
        float f;
    } data;
    struct Node* next;
} Node;

float findMin(Node* head) {
    if(head == NULL) {
        printf("Error: List is empty");
        exit(1);
    }
  
    float min = INT_MAX;
    Node* temp = head;
  
    while(temp != NULL) {
        float val;
        if(temp->type == 0) val = (float) temp->data.i;
        else val = temp->data.f;
        
        if (val < min) min = val;
        temp = temp->next;
    }
    return min;
}

int main() {
    Node node3 = {0, {.i = 3}, NULL};
    Node node2 = {0, {.i = 2}, &node3};
    Node node1 = {1, {.f = 0.5}, &node2};
    
    printf("Minimum value: %f", findMin(&node1));
  
    return 0;
}
```

In this program, we use a linked list to simulate a heterogeneous list. Each Node in the list contains a variable `type` to indicate its data type (0 for int, 1 for float), and a union `data` to store the actual data. While finding the minimum value, we convert int to float for a fair comparison. The `findMin` function terminates the process with an error message if the list is empty. This approach ensures proper handling of the resource and exception, and avoids the programming mistakes such as CWE-664 (Improper Control of a Resource Through its Lifetime), CWE-703 (Improper Check or Handling of Exceptional Conditions), and CWE-710 (Improper Adherence to Coding Standards).
