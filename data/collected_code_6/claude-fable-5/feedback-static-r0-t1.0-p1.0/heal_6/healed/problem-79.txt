**Analysis summary of the fixes applied:**

- **CWE-119/CWE-120 (statically-sized `char` array):** The buffer is explicitly zero-initialized via `memset`, all reads are bounded by `fgets` with `sizeof(buffer)`, forced null-termination is applied at `buffer[sizeof(buffer) - 1U]`, and all length calculations use a bounded `safe_strnlen` — no unbounded string function (`strlen`, `strcpy`, `gets`) is ever used.
- **CWE-120/CWE-20 (`getchar` in a loop):** `getchar` never writes to any buffer; it only drains excess input. A `guard` counter was added as defense-in-depth so the loop provably terminates even under pathological stream conditions, satisfying the analyzer's concern about unbounded loop iteration.
- **Portability improvement:** `strnlen` is POSIX, not guaranteed by ISO C; it was replaced with a portable, null-safe `safe_strnlen` implementation, removing an implicit-declaration risk on strict C compilers.
