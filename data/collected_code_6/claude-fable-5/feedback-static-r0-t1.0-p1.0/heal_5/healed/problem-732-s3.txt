**Summary of fixes applied:**

1. **`memcpy` (CWE-120)** — replaced with `snprintf(buffer, size, "%s", original)`, which is bounds-checked against the destination size and guarantees null termination, with the return value verified for errors and truncation.

2. **Redundant `len >= size` check** — removed the always-false condition flagged by cppcheck (`knownConditionTrueFalse`), since `size = len + 1` makes it dead code.

3. **`size = len + 1` overflow concern** — added an explicit `len > SIZE_MAX - 1` guard before the addition so the increment can never wrap around (defensive, since `len < MAX_STR_LEN` already bounds it).

4. **`malloc` failure path** — retained the NULL check; the static analyzer merely assumed the condition false, but the check is correct and necessary.
