**Summary of changes addressing the flagged weaknesses:**

1. **Known-condition-true (`len < alloc_size`)** — removed the redundant `len < alloc_size` check, since `alloc_size = len + 1U` guarantees it. This eliminates the cppcheck `knownConditionTrueFalse` finding while keeping the logic identical.
2. **`memcpy` buffer-overflow risk (CWE-120)** — the destination buffer is explicitly allocated as `len + 1U` bytes immediately before the copy of exactly `len` bytes, and an explicit overflow guard (`len > SIZE_MAX - 1U`) was added before computing `alloc_size`, making the safety of the copy provable and self-evident to analyzers.
3. **`malloc` failure assumption** — the `NULL` return check is retained, so allocation failure is handled rather than assumed false.
4. All other defensive properties (bounded `strnlen`, `NULL` parameter checks, zero-initialized `calloc` so `free_counters` is safe on partial initialization) are preserved.
