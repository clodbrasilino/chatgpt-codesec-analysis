```c
#include <stdio.h>

double getZeroRatio(int *array, int size) {
    if (array == NULL || size == 0) {
        return 0.0;
    }
    
    int zeroCount = 0;
    for (int i = 0; i < size; i++) {
        if (array[i] == 0) {
            zeroCount++;
        }
    }

    return (double)zeroCount / size;
}

int main() {
    int array[10] = {1, 0, 2, 0, 3, 4, 0, 0, 5, 6};
    printf("Zero ratio is: %f\n", getZeroRatio(array, 10));

    return 0;
}
```
This code calculates the ratio of zeros in an array by dividing the count of zero elements by the total size of the array. If an empty or null array is given, it will return 0.0 to avoid any errors or segmentation faults. The result is then printed within the main function. If the array contains a few zeros, the function will return a fraction as the result.
