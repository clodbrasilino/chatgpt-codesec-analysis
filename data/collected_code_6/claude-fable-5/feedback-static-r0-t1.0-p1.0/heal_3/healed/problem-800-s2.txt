3. **Redundant/always-false condition `len >= buffer_size`:** Replaced with a semantically correct bounds check `len + 1 > buffer_size`, which validates that the destination can hold both the payload and the null terminator, satisfying the static analyzer's intent while remaining a genuine guard if the code is later modified.
