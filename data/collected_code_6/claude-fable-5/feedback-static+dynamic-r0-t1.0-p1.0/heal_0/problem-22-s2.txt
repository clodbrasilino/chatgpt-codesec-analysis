```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

bool find_first_duplicate(const int *arr, size_t size, int *result)
{
    if (arr == NULL || result == NULL || size < 2U) {
        return false;
    }

    for (size_t i = 1U; i < size; i++) {
        for (size_t j = 0U; j < i; j++) {
            if (arr[i] == arr[j]) {
                *result = arr[i];
                return true;
            }
        }
    }

    return false;
}

int main(void)
{
    int numbers[] = { 2, 5, 1, 2, 3, 5, 1, 2, 4 };
    size_t count = sizeof(numbers) / sizeof(numbers[0]);
    int duplicate = 0;

    if (find_first_duplicate(numbers, count, &duplicate)) {
        if (printf("First duplicate: %d\n", duplicate) < 0) {
            return EXIT_FAILURE;
        }
    } else {
        if (printf("No duplicate found\n") < 0) {
            return EXIT_FAILURE;
        }
    }

    return EXIT_SUCCESS;
}
```

This implementation is defensive by design:

- **CWE-664 avoidance:** No dynamic memory allocation is used, so there are no resource lifetime concerns (no leaks, no use-after-free, no double-free). All data lives on the stack with well-defined scope.
- **CWE-703 avoidance:** All exceptional conditions are checked — `NULL` pointers, arrays too small to contain duplicates, and even the return value of `printf` is validated.
- **CWE-710 avoidance:** The code adheres to strict coding standards — `size_t` for indices and sizes, `const`-correct parameters, `bool` return for status separated from the output value (via out-parameter), braces on all control blocks, unsigned literal suffixes, `main(void)` signature, and standard exit codes.

The "first duplicate" here is defined as the element whose second occurrence appears earliest in the array (e.g., for `{2, 5, 1, 2, 3, 5}` it returns `2`).
