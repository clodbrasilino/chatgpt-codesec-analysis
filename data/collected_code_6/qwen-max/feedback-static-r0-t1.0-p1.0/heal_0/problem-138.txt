```c
#include <stdio.h>
#include <stdbool.h>

bool isSumOfPowersOfTwo(int n) {
    if (n == 0) return false;
    while (n > 0) {
        if (n % 2 != 0 && n / 2 > 0) return false;
        n /= 2;
    }
    return true;
}

int main() {
    int num;
    printf("Enter a number: ");
    scanf("%d", &num);
    if (isSumOfPowersOfTwo(num)) {
        printf("The number can be represented as sum of non-zero powers of 2.\n");
    } else {
        printf("The number cannot be represented as sum of non-zero powers of 2.\n");
    }
    return 0;
}
```
This code defines a function `isSumOfPowersOfTwo` that checks if the given number can be expressed as a sum of non-zero powers of 2. The `main` function reads an integer from the user, calls this function, and prints the result.
