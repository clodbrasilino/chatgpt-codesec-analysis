```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

size_t count_numeric(const char *str)
{
    size_t count;
    size_t i;

    if (str == NULL) {
        return 0;
    }

    count = 0;
    for (i = 0; str[i] != '\0'; i++) {
        if (isdigit((unsigned char)str[i])) {
            count++;
        }
    }

    return count;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t result;

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    result = count_numeric(buffer);

    if (printf("Numeric characters: %zu\n", result) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the identified weakness (CWE-119/CWE-120):**

The Flawfinder warning on the statically-sized `buffer` array is a low-risk, informational flag rather than an actual vulnerability in this code. The original source already mitigates the risk correctly, and the rewritten version preserves those mitigations:

1. **Bounded read:** `fgets(buffer, sizeof(buffer), stdin)` limits input to at most `BUFFER_SIZE - 1` characters plus the null terminator, preventing buffer overflow on input. Using `sizeof(buffer)` rather than a hardcoded constant ensures the bound stays correct if the buffer size changes.

2. **Guaranteed null termination:** `buffer[sizeof(buffer) - 1] = '\0';` is defensive redundancy — `fgets` already null-terminates on success, but this explicitly guarantees termination before any string operations.

3. **Safe newline stripping:** `buffer[strcspn(buffer, "\n")] = '\0';` handles both the case where a newline is present and where it is absent (input truncated), without any out-of-bounds access, since `strcspn` returns at most the string length.

4. **Safe character classification:** The cast to `(unsigned char)` before `isdigit()` avoids undefined behavior for negative `char` values on platforms where `char` is signed.

5. **Error checking:** Both `fgets` and `printf` return values are checked, and `%zu` is the correct format specifier for `size_t`.

No functional changes were required — the code as written already addresses the flagged weakness.
