#include <stdio.h>
#include <string.h>
#include <limits.h>

#define BUF_SIZE 256

void remove_chars(char *first, const char *second)
{
    int present[UCHAR_MAX + 1] = {0};
    size_t i;
    size_t j;

    if (first == NULL || second == NULL) {
        return;
    }

    for (i = 0; second[i] != '\0'; i++) {
        present[(unsigned char)second[i]] = 1;
    }

    j = 0;
    for (i = 0; first[i] != '\0'; i++) {
        if (!present[(unsigned char)first[i]]) {
            first[j] = first[i];
            j++;
        }
    }
    first[j] = '\0';
}

int main(void)
{
    char first[BUF_SIZE];
    char second[BUF_SIZE];

    if (fgets(first, sizeof(first), stdin) == NULL) {
        fprintf(stderr, "Failed to read first string\n");
        return 1;
    }
    first[strcspn(first, "\n")] = '\0';

    if (fgets(second, sizeof(second), stdin) == NULL) {
        fprintf(stderr, "Failed to read second string\n");
        return 1;
    }
    second[strcspn(second, "\n")] = '\0';

    remove_chars(first, second);

    if (printf("%s\n", first) < 0) {
        return 1;
    }

    return 0;
}

1. **Bounded input (CWE-120 mitigation):** Both reads use `fgets(buf, sizeof(buf), stdin)`, which guarantees at most `BUF_SIZE - 1` characters are written plus a NUL terminator. No overflow is possible.

2. **Safe newline stripping:** `buf[strcspn(buf, "\n")] = '\0'` is the idiomatic, bounds-safe way to remove the trailing newline. `strcspn` never returns an index past the terminating NUL that `fgets` guarantees, so the write is always in bounds. It also correctly handles the case where no newline is present (input truncated or EOF without newline).

3. **NULL guards:** `remove_chars` defensively checks both pointers before dereferencing.

4. **Signed-char safety (CWE-119 mitigation):** The casts to `(unsigned char)` before indexing `present[]` prevent negative array indices on platforms where `char` is signed — a subtle but real out-of-bounds read/write risk that the lookup-table pattern often introduces.

5. **In-place compaction is safe:** The write index `j` never exceeds the read index `i`, so `remove_chars` can never write past the original string length.

6. **I/O error handling:** Both `fgets` failures and `printf` failure are checked and reported via a nonzero exit status.
