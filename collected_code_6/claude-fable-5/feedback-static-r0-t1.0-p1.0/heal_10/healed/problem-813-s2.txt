```c
#include <stdio.h>
#include <stddef.h>

#define BUFFER_SIZE 256

size_t string_length(const char *str)
{
    size_t length = 0;

    if (str == NULL) {
        return 0;
    }

    while (str[length] != '\0') {
        length++;
    }

    return length;
}

static void flush_stdin(void)
{
    int ch;

    while ((ch = getchar()) != '\n' && ch != EOF) {
    }
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t length;
    size_t i;
    int newline_found = 0;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    i = 0;
    while (i < sizeof(buffer) && buffer[i] != '\0') {
        if (buffer[i] == '\n') {
            buffer[i] = '\0';
            newline_found = 1;
            break;
        }
        i++;
    }

    if (!newline_found && i == sizeof(buffer) - 1) {
        flush_stdin();
    }

    length = string_length(buffer);

    printf("Length of the string: %zu\n", length);

    return 0;
}
```

**Analysis of the original code and fixes applied:**

1. **`char buffer[BUFFER_SIZE]` (CWE-119/CWE-120, risk 2):** The original code was already largely safe — `fgets(buffer, sizeof(buffer), stdin)` correctly limits input to the buffer size and guarantees null termination. The defensive `buffer[sizeof(buffer) - 1] = '\0'` is retained as a belt-and-suspenders measure. Using `sizeof(buffer)` rather than the macro directly ensures the bound stays correct even if the declaration changes.

2. **`getchar()` in a loop (CWE-120/CWE-20, risk 1):** The drain loop never stores characters, so no overflow is possible. It was moved into a dedicated `flush_stdin()` helper for clarity, and it correctly checks for both `'\n'` and `EOF` to avoid an infinite loop on closed input streams.

3. **Logic improvement:** The original truncation-detection condition `if (i == sizeof(buffer) - 1 && buffer[i] == '\0')` was subtly fragile — a `newline_found` flag now makes the intent explicit: only flush leftover input when the line was actually truncated (no newline consumed).

4. **`string_length()`** safely handles `NULL` and only reads up to the terminator, which `fgets` guarantees exists — no out-of-bounds read is possible.
