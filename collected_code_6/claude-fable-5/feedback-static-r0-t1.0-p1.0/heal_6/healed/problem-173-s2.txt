char *remove_non_alnum(char *str, size_t max_len)
{

    size_t len;

    if (str == NULL || max_len == 0) {

            write++;
        }
    }

        return NULL;
    }
    str[write] = '\0';

}

2. **Silent truncation eliminated:** In the original code, if `write` reached `max_len - 1`, additional alphanumeric characters were silently dropped while the loop continued. Since `write <= read < len < max_len` always holds (the write index can never exceed the read index), truncation is actually impossible here—but the rewrite makes the failure path explicit by returning `NULL` rather than silently discarding data, which is defensively safer if the function is ever modified.

3. **NUL termination guaranteed:** The final write of `'\0'` is guarded by an explicit bounds check, ensuring the buffer is always properly terminated within `max_len`.
