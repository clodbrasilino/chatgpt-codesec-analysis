```c
#include <stdio.h>
#include <ctype.h>
#include <stddef.h>
#include <string.h>

#define BUFFER_SIZE 256

size_t count_numeric(const char *str)
{
    size_t count = 0;

    if (str == NULL) {
        return 0;
    }

    while (*str != '\0') {
        if (isdigit((unsigned char)*str)) {
            count++;
        }
        str++;
    }

    return count;
}

static void flush_stdin(void)
{
    int ch;

    do {
        ch = getchar();
    } while (ch != '\n' && ch != EOF);
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t result;
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    } else if (len == sizeof(buffer) - 1) {
        flush_stdin();
    }

    result = count_numeric(buffer);

    printf("Number of numeric characters: %zu\n", result);

    return 0;
}
```

**Analysis of the identified weaknesses:**

1. **`getchar` in a loop (CWE-120, CWE-20):** This is a false positive in this context. The `flush_stdin()` function never stores the characters read — it only discards them until a newline or `EOF` is encountered. Since no buffer is written to, there is no overflow risk. The `EOF` check also guarantees the loop terminates when the stream is closed, preventing an infinite loop.

2. **Statically-sized `char` array (CWE-119/CWE-120):** The buffer is used safely throughout:
   - `fgets(buffer, sizeof(buffer), stdin)` bounds the read to the buffer size and always null-terminates within limits.
   - The explicit `buffer[sizeof(buffer) - 1] = '\0'` is a defensive redundancy.
   - `strnlen` (rather than `strlen`) is used with an explicit maximum, so even a hypothetically unterminated buffer cannot cause an over-read.
   - The `len == sizeof(buffer) - 1` check correctly detects truncated input and drains the remaining characters from `stdin`, preventing leftover input from affecting subsequent reads.

3. **`isdigit` cast:** The cast to `(unsigned char)` before calling `isdigit` is correct and necessary — passing a negative `char` value (possible on platforms where `char` is signed) would be undefined behavior.

The original code was already well-hardened; the rewrite preserves those mitigations, as no actual exploitable weakness exists in either flagged location.
