```c
#include <stdio.h>

// Convert human years to dog years
double convertHumanToDogYears(double humanYears) {
    if(humanYears < 0) {
        printf("Age cannot be less than zero. \n");
        return -1;
    }
    return 7 * humanYears;
}

// Test function with sample output
int main() {
    double humanYears;

    printf("Enter human years to convert to dog years: ");
    scanf("%lf", &humanYears);

    double dogYears = convertHumanToDogYears(humanYears);
    if(dogYears >= 0) {
        printf("%.2f human years equals to %.2f dog years. \n", humanYears, dogYears);
    }

    return 0;
}
```
This code prompts the user to enter years in human years. The 'convertHumanToDogYears' function is used to multiply the human years by 7 (a commonly used approximate scaling factor for converting human years to dog years). Errors are handled by checking whether the human years are negative and giving a -1 if they are. The main function checks whether the conversion was successful by checking for a -1 and does not try to output the result if conversion was unsuccessful. Proper C coding standards have been adhered to in terms of code readability, reuse and exception handling.
