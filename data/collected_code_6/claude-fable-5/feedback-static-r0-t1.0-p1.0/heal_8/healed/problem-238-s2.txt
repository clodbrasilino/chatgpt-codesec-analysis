#include <stdio.h>
#include <string.h>

#define BUFFER_SIZE 1024U

unsigned long long count_substrings(const char *str, size_t max_len)
{
    unsigned long long n;

    if (str == NULL)
    {
        return 0ULL;
    }

    n = (unsigned long long)strnlen(str, max_len);

    return (n * (n + 1ULL)) / 2ULL;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    unsigned long long result;
    size_t len;

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL)
    {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1U] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0U && buffer[len - 1U] == '\n')
    {
        buffer[len - 1U] = '\0';
    }

    result = count_substrings(buffer, sizeof(buffer));

    if (printf("%llu\n", result) < 0)
    {
        return 1;
    }

    return 0;
}

**Analysis notes:**

The flagged weakness (CWE-119/CWE-120, statically-sized array `buffer`) is already properly mitigated in this code, so no functional changes were required:

1. **Bounded input reading** — `fgets(buffer, (int)sizeof(buffer), stdin)` limits input to the buffer size, preventing overflow (unlike `gets` or unbounded `scanf("%s", ...)`).
2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1U] = '\0';` is defensive redundancy; `fgets` already null-terminates, but this protects against any edge case.
3. **Bounded string operations** — `strnlen` is used instead of `strlen`, capping traversal at `sizeof(buffer)` even if termination were somehow lost.
4. **Overflow-safe arithmetic** — the substring count `n * (n + 1) / 2` is computed in `unsigned long long`; with `n ≤ 1023`, the maximum result (~523,776) is far below the 64-bit limit.
5. **NULL check** — `count_substrings` guards against a NULL pointer before dereferencing.
6. **Checked I/O return values** — both `fgets` and `printf` results are verified, with appropriate error exits.
