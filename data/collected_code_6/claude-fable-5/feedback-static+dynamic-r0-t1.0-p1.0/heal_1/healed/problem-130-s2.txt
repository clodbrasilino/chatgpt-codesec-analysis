```c
#include <stdio.h>
#include <stddef.h>

int find_max_frequency_item(const int *arr, size_t len, int *result)
{
    size_t i;
    size_t max_count = 0;
    int max_item = 0;

    if ((arr == NULL) || (result == NULL) || (len == 0U)) {
        return -1;
    }

    for (i = 0; i < len; i++) {
        size_t count = 0;
        size_t j;
        for (j = 0; j < len; j++) {
            if (arr[j] == arr[i]) {
                count++;
            }
        }
        if (count > max_count) {
            max_count = count;
            max_item = arr[i];
        }
    }

    *result = max_item;
    return 0;
}

int main(void)
{
    int data[] = { 2, 3, 8, 4, 7, 9, 8, 2, 6, 5, 1, 6, 1, 2, 3, 4, 6, 9, 1, 2 };
    size_t len = sizeof(data) / sizeof(data[0]);
    int result;
    int status;

    status = find_max_frequency_item(data, len, &result);
    if (status != 0) {
        if (fprintf(stderr, "Error: invalid input\n") < 0) {
            return 1;
        }
        return 1;
    }

    if (printf("Item with maximum frequency: %d\n", result) < 0) {
        return 1;
    }

    return 0;
}
```

**Analysis summary:**

The only weakness flagged by static analysis was the scope of `count` (and by extension `j`), which was declared at function scope but only used inside the outer loop. In the rewritten version, both `count` and `j` are declared inside the outer `for` loop body, minimizing their scope. This improves readability, reduces the risk of accidental reuse of stale values, and helps the compiler with register allocation.

The rest of the code is already defensively written:

- **NULL-pointer and empty-array checks** guard the function entry, returning `-1` on invalid input.
- **`size_t`** is correctly used for indices and counts, avoiding signed/unsigned mismatch.
- **Return values of `printf`/`fprintf` are checked**, satisfying strict coding standards (e.g., MISRA C).
- The algorithm is O(n²), which is acceptable for small inputs; for larger datasets, a hash table or sorting-based approach (O(n log n)) would be preferable. Note also that on ties, the first encountered item with the maximum frequency wins — here `2` (frequency 4) is found before other candidates.
