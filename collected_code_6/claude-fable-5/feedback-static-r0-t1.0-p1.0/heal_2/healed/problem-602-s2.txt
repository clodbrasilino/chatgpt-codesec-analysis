int find_first_repeated(const char *str, size_t max_len, char *result)
{
    int seen[256] = {0};

        if (seen[c]) {

    }

    return 1;
}

2. **Guaranteed null termination**: `buffer[sizeof(buffer) - 1] = '\0';` is a defensive measure ensuring the buffer is always a valid C string (fgets already guarantees this on success, but the explicit termination is harmless belt-and-suspenders).
