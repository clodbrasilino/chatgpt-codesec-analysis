```c
#include <stdio.h>
#include <stdlib.h>

double find_diameter(double radius)
{
    return 2.0 * radius;
}

int main(void)
{
    double radius;
    double diameter;
    int result;

    printf("Enter the radius of the circle: ");
    result = scanf("%lf", &radius);

    if (result != 1) {
        fprintf(stderr, "Error: invalid input.\n");
        return EXIT_FAILURE;
    }

    if (radius < 0.0) {
        fprintf(stderr, "Error: radius cannot be negative.\n");
        return EXIT_FAILURE;
    }

    diameter = find_diameter(radius);
    printf("The diameter of the circle is: %.2f\n", diameter);

    return EXIT_SUCCESS;
}
```

Key points about this implementation:

- **CWE-703 avoidance**: The return value of `scanf` is checked to ensure valid input was actually read, and negative radius values are rejected with an error message to `stderr`.
- **CWE-664 avoidance**: No dynamically allocated resources or file handles are used, so there is nothing to leak; all variables are stack-allocated with well-defined lifetimes.
- **CWE-710 avoidance**: The code adheres to standard C conventions — `main` is declared as `int main(void)`, it returns `EXIT_SUCCESS`/`EXIT_FAILURE` from `<stdlib.h>`, all functions have proper prototypes, and floating-point literals are used consistently (`2.0`, `0.0`).
