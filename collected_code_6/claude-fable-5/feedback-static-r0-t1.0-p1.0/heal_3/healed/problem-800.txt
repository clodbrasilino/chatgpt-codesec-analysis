```c
#include <stdio.h>
#include <ctype.h>
#include <stddef.h>

void remove_whitespace(char *str, size_t max_len)
{
    size_t read;
    size_t write;

    if (str == NULL || max_len == 0) {
        return;
    }

    read = 0;
    write = 0;

    while (read < max_len && str[read] != '\0') {
        if (!isspace((unsigned char)str[read])) {
            str[write] = str[read];
            write++;
        }
        read++;
    }

    if (write < max_len) {
        str[write] = '\0';
    } else {
        str[max_len - 1] = '\0';
    }
}

int main(void)
{
    char text[] = "  Hello,   World! \t This is a\ntest.  ";

    printf("Before: \"%s\"\n", text);
    remove_whitespace(text, sizeof(text));
    printf("After:  \"%s\"\n", text);

    return 0;
}
```

**Analysis notes:**

The Flawfinder warnings here are all risk-level 1 (informational) hits on array indexing patterns. Reviewing each one, the original code already mitigates them properly, and the rewrite preserves those mitigations:

1. **Bounded loop (CWE-120/CWE-20):** The loop condition `read < max_len && str[read] != '\0'` guarantees `read` never indexes past the caller-supplied buffer size, even if the string is not NUL-terminated. This is the correct defense against buffer over-read.

2. **Write index safety:** Since `write <= read` is an invariant (write only increments when read does), `str[write]` can never exceed a valid, already-read position. No overflow is possible on the compaction writes.

3. **Guaranteed termination:** The final block ensures the result is always NUL-terminated within bounds — `str[write] = '\0'` when space allows, falling back to `str[max_len - 1] = '\0'` otherwise. The `max_len == 0` guard prevents the `max_len - 1` underflow.

4. **`isspace` UB avoidance:** The cast to `unsigned char` before passing to `isspace()` is retained — passing a negative `char` value (other than EOF) to `<ctype.h>` functions is undefined behavior on platforms where `char` is signed.

5. **NULL check:** The `str == NULL` guard prevents dereferencing a null pointer.

6. **Caller correctness:** `main` passes `sizeof(text)`, which is the true buffer size (including the NUL) since `text` is a true array, not a decayed pointer — so the bound is accurate.
