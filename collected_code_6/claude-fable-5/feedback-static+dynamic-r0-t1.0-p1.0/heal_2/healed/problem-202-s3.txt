1. **Bounded input reading** — `fgets(buffer, (int)sizeof(buffer), stdin)` limits the read to the buffer size, preventing overflow; its return value is checked for read failure/EOF.

2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1U] = '\0';` is a belt-and-braces guarantee (fgets already null-terminates, but this is defense in depth).

3. **Bounded length computation** — `strnlen` is used instead of `strlen` in both `main` and `remove_even_chars`, so no unbounded scan can occur even on a malformed string.

4. **Truncation detection** — `remove_even_chars` rejects input where `len >= max_len`, treating a possibly-unterminated/truncated string as an error rather than processing it.

5. **Correct allocation and indexing** — `malloc(len + 1U)` always reserves room for the terminator; `j` can never exceed `len`, so `result[j] = '\0'` is in bounds. The malloc return is checked.

6. **No leaks or UB** — `free(output)` occurs on every exit path after allocation; `printf`'s return is checked; unused return values are explicitly cast to `(void)` (MISRA-style discipline).
