```c
#include <stdio.h>
#include <string.h>

#define BUFFER_SIZE 1024

unsigned long count_substrings(const char *str, size_t max_len)
{
    unsigned long freq[256] = {0};
    unsigned long total = 0;
    size_t i;
    size_t len;

    if (str == NULL)
    {
        return 0;
    }

    len = strnlen(str, max_len);

    for (i = 0; i < len; i++)
    {
        freq[(unsigned char)str[i]]++;
    }

    for (i = 0; i < 256; i++)
    {
        total += (freq[i] * (freq[i] + 1)) / 2;
    }

    return total;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    unsigned long result;
    size_t len;

    if (fgets(buffer, sizeof(buffer), stdin) == NULL)
    {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n')
    {
        buffer[len - 1] = '\0';
    }

    result = count_substrings(buffer, sizeof(buffer));

    if (printf("%lu\n", result) < 0)
    {
        return 1;
    }

    return 0;
}
```

**Analysis notes:**

The flagged weakness (CWE-119/CWE-120, statically-sized `buffer`) is already properly mitigated in the original code, so the rewrite preserves those defenses rather than changing logic:

1. **Bounded input read** — `fgets(buffer, sizeof(buffer), stdin)` limits input to the buffer size, preventing the classic `gets()`-style overflow. Using `sizeof(buffer)` rather than a repeated literal keeps the bound tied to the actual array.

2. **Guaranteed termination** — `buffer[sizeof(buffer) - 1] = '\0';` is defensive redundancy (fgets already null-terminates on success), but it costs nothing and protects against future refactoring mistakes.

3. **Bounded length calculation** — `strnlen(buffer, sizeof(buffer))` is used instead of `strlen`, so even a hypothetically unterminated buffer cannot cause an out-of-bounds read. The same discipline is applied inside `count_substrings` via its `max_len` parameter.

4. **Safe indexing** — the cast `(unsigned char)str[i]` prevents negative array indexing into `freq[256]` on platforms where `char` is signed, which would otherwise be an out-of-bounds write.

5. **Error handling** — return values of `fgets` and `printf` are checked, and `count_substrings` handles a `NULL` pointer gracefully.

One correctness observation: `freq[i] * (freq[i] + 1) / 2` can overflow `unsigned long` only for pathologically long inputs; with a 1024-byte buffer the maximum total is ~524,800, well within range, so no wider type is needed here.
