```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

double radians_to_degrees(double radians);

double radians_to_degrees(double radians)
{
    return radians * (180.0 / M_PI);
}

int main(void)
{
    double radians = 0.0;
    double degrees = 0.0;

    printf("Enter angle in radians: ");
    if (scanf("%lf", &radians) != 1)
    {
        fprintf(stderr, "Error: invalid input.\n");
        return EXIT_FAILURE;
    }

    degrees = radians_to_degrees(radians);

    if (printf("%f radians = %f degrees\n", radians, degrees) < 0)
    {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

A few notes on how this code addresses the specified weaknesses:

- **CWE-703 (Improper Check or Handling of Exceptional Conditions):** The return value of `scanf` is checked to ensure exactly one value was successfully read, and the program exits with an error status and message on failure. The return value of `printf` is also checked.

- **CWE-664 (Improper Control of a Resource Through its Lifetime):** No dynamic memory or file handles are allocated, so there are no resources to leak or misuse. All variables are initialized before use.

- **CWE-710 (Improper Adherence to Coding Standards):** The function has a proper prototype declared before use, `main` uses the standard `int main(void)` signature, all variables are explicitly initialized, `EXIT_SUCCESS`/`EXIT_FAILURE` are used instead of magic numbers, and errors are reported to `stderr`.

One portability note: `M_PI` is defined in POSIX but not strictly by the C standard. If you need strict ISO C compliance, replace it with a defined constant such as `3.14159265358979323846`, or compile with `-D_USE_MATH_DEFINES` on some platforms.
