Here is a C code of a function to calculate the n'th star number:

```C
#include<stdio.h>

long long calculateStarNumber(int n){
    if(n <= 0) {
        return -1;
    }

    return 6 * n * (n-1) + 1;
}

int main()
{
    int n;
    printf("Enter a number: ");
    scanf("%d",&n);
    long long result = calculateStarNumber(n);

    if(result < 0) {
       printf("Input must be a positive integer\n");
    }
    else {
       printf("The %d'th Star Number: %lld\n", n, result);
    }

    return 0;
}
```
In this code, `calculateStarNumber` function is used to calculate the n'th star number. This function takes an integer n as input and returns a long long integer as the nth star number. In case the input number is zero or negative, it returns -1 indicating an error.

In the `main` function, a number is requested from the user and is passed as argument to `calculateStarNumber` function. The resulting star number is then printed. If the return value is -1, an error message is printed indicating that the input must be a positive integer.
