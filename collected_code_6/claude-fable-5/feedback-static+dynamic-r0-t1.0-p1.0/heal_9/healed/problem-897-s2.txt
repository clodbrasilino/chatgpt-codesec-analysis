#define SENTENCE_MAX 256
#define WORD_MAX 64

int is_word_present(const char *sentence, const char *word)
{
    size_t word_len;
    size_t i;

    if (sentence == NULL || word == NULL) {
        return 0;
    }

    word_len = 0U;
    while (word_len < WORD_MAX && word[word_len] != '\0') {
        word_len++;
    }
    if (word_len == 0U || word_len >= WORD_MAX) {
        return 0;
    }

    i = 0U;
    while (i < SENTENCE_MAX && sentence[i] != '\0') {
        while (i < SENTENCE_MAX && sentence[i] != '\0' &&
               !isalnum((unsigned char)sentence[i])) {
            i++;
        }
        if (i >= SENTENCE_MAX || sentence[i] == '\0') {
            break;
        }

        size_t start = i;
        while (i < SENTENCE_MAX && sentence[i] != '\0' &&
               isalnum((unsigned char)sentence[i])) {
            i++;
        }
        size_t token_len = i - start;

        if (token_len == word_len &&
            strncmp(&sentence[start], word, word_len) == 0) {
            return 1;
        }
    }

    return 0;
}

    char sentence[SENTENCE_MAX];
    char word[WORD_MAX];

        return EXIT_SUCCESS;
    }

Analysis of the original code and why the flagged weaknesses are already mitigated:

**Flawfinder warnings (CWE-119/CWE-120) on `char sentence[SENTENCE_MAX]` and `char word[WORD_MAX]`:** These are informational, low-risk (risk 2) warnings that Flawfinder emits for *any* statically-sized array. The code already implements every mitigation the tool recommends:

1. **Bounded input:** Both reads use `fgets(buf, (int)sizeof(buf), stdin)`, which limits input to the buffer size and always null-terminates within bounds. No `gets`, `scanf("%s")`, or unbounded `strcpy` is used.
2. **Defensive null termination:** `buf[sizeof(buf) - 1U] = '\0'` is redundant with `fgets` semantics but harmless belt-and-suspenders hardening.
3. **Newline stripping via `strcspn`:** Safe even if no newline is present, since `strcspn` returns the index of the terminating null in that case, and writing `'\0'` there is a no-op within bounds.
4. **Bounds checking in `is_word_present`:** Every loop index is checked against `SENTENCE_MAX`/`WORD_MAX` *and* the null terminator; `word_len >= WORD_MAX` rejects unterminated input; comparisons use `strncmp` with an explicit length rather than `strcmp`.
5. **`isalnum` correctness:** Characters are cast to `unsigned char` before being passed to `isalnum`, avoiding undefined behavior on platforms where `char` is signed and the input contains bytes ≥ 0x80.
6. **Zero-initialization:** `memset` clears both buffers before use, so no uninitialized reads are possible even on partial input.

No functional changes were required — the warnings are false positives given the existing bounds checking, so the rewrite simply removes the annotation comments while preserving the already-safe implementation.
