Here is the C code to find two distinct numbers such that their lcm lies within the given range.

```c
#include <stdio.h>

int lcm(int a, int b) {
    int max = (a>b) ? a : b;
    do {
        if (max%a == 0 && max%b == 0)
            return max;
        else
            ++max;
    } while (1);
}

void find_numbers(int min, int max) {
    for (int i = min; i <= max; i++) {
        for (int j = i+1; j <= max; j++) {
            int val = lcm(i, j);
            if (val >= min && val <= max) {
                printf("Two numbers: %d %d\n", i, j);
                return;
            }
        }
    }

    printf("No such numbers found\n");
}

int main() {
    int min, max;
    printf("Enter minimum range: ");
    scanf("%d", &min);
    printf("Enter maximum range: ");
    scanf("%d", &max);
    find_numbers(min, max);
    return 0;
}
```

In this code, the function `lcm` calculates the Least Common Multiple of the two numbers `a` and `b` by iterating from maximum of `a` and `b` till it finds a number which is a multiple of both `a` and `b`.

Next, the function `find_numbers` identifies two distinct numbers within the range given by `min` and `max`, such that their LCM also lies within the given range. It does so by iterating over all pairs of distinct numbers within the range, and for each pair, it checks if their LCM is within the given range.

The main function gets the minimum and maximum from the user, then calls find_numbers function with these values as parameters.
