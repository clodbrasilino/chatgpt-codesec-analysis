```c
#include <stdio.h>

int product_of_unique(int arr[], int length) {
    int product = 1;
    for(int i = 0; i < length; i++) {
        int j;
        for(j = 0; j < i; j++)
           if(arr[i] == arr[j])
              break;
        if(i == j)
           product *= arr[i];
    }
    return product;
}

int main() {
    int array[] = {1, 2, 3, 4, 5, 2, 3, 1};
    int len = sizeof(array) / sizeof(array[0]);
    printf("The product of unique numbers is: %d\n", product_of_unique(array, len));
    return 0;
}
```
This code works by iterating over the array and checking each value against all previous values. If no match is found, then that value is unique, and the product gets updated to reflect that. If a match is found, however, it simply moves on to the next value. This way, each value in the array is only factored into the product once. The main function creates a test array and calls the product function on it. The result is then printed to the console.
