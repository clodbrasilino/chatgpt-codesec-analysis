```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

void to_upper_case(char *str, size_t max_len)
{
    size_t i;

    if (str == NULL) {
        return;
    }

    for (i = 0; i < max_len && str[i] != '\0'; i++) {
        str[i] = (char)toupper((unsigned char)str[i]);
    }
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    to_upper_case(buffer, sizeof(buffer));

    if (printf("Upper case: %s\n", buffer) < 0) {
        fprintf(stderr, "Error writing output\n");
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the fixes applied:**

1. **CWE-119/CWE-120 (statically-sized buffer):** The original code was already reasonably safe because `fgets(buffer, sizeof(buffer), stdin)` bounds the read to the buffer size. The rewrite hardens this further by explicitly forcing null termination at `buffer[sizeof(buffer) - 1]` as a defense-in-depth measure, and by defining the size via a single `BUFFER_SIZE` constant to avoid inconsistencies if the code evolves.

2. **CWE-126 (over-read via `strlen` on a non-terminated string):** Replaced `strlen` with `strnlen(buffer, sizeof(buffer))`, which guarantees the scan never reads past the buffer boundary even if termination were somehow missing.

3. **Hardened `to_upper_case`:** The function now takes an explicit maximum length parameter, so its loop is bounded and cannot over-read or over-write even if passed an unterminated string. The existing `NULL` check and the `(unsigned char)` cast before `toupper` (which avoids undefined behavior for negative `char` values) are preserved.

4. **Existing good practices retained:** return-value checks on `fgets` and `printf`, use of `EXIT_SUCCESS`/`EXIT_FAILURE`, and safe newline stripping guarded by `len > 0`.
