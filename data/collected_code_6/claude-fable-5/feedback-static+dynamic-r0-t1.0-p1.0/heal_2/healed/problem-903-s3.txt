## Analysis

The bit-counting logic itself (`countUnsetBits` / `totalUnsetBits`) is mathematically correct for the classic "count unset bits from 1 to n" problem (e.g., n=5 → 4, n=14 → 17). The fact that both test cases report **"got 1"** strongly suggests the tests never received a computed answer at all — `1` is the process exit code (`EXIT_FAILURE`). This happens because:

1. **Input mechanism mismatch** – the program only reads via `scanf` from stdin. If the test harness passes `n` as a command-line argument, `scanf` fails, and the program exits with `1`.
2. **Output format mismatch** – the program prints a verbose sentence (`"Total unset bits from 1 to %u: %llu"`), so even when it runs, a harness expecting the bare number (`4`, `17`) would fail comparison.
3. Minor issues: the redundant `if (i == n) break;` inside the loop (dead code, and the loop condition `i <= n` risks an infinite loop only at `n == UINT_MAX` — worth guarding), and no range validation on parsed input.

The fix: accept `n` from `argv[1]` (falling back to stdin), validate with `strtoul`, guard the loop termination explicitly, and print only the numeric result.

## Fixed Code

```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>
#include <errno.h>

static unsigned int countUnsetBits(unsigned int num)
{
    unsigned int count = 0U;
    while (num > 0U)
    {
        if ((num & 1U) == 0U)
        {
            count++;
        }
        num >>= 1U;
    }
    return count;
}

static unsigned long long totalUnsetBits(unsigned int n)
{
    unsigned long long total = 0ULL;
    unsigned int i = 1U;
    for (;;)
    {
        total += (unsigned long long)countUnsetBits(i);
        if (i == n)
        {
            break;
        }
        i++;
    }
    return total;
}

int main(int argc, char *argv[])
{
    unsigned long parsed = 0UL;
    unsigned int n = 0U;

    if (argc > 1)
    {
        char *end = NULL;
        errno = 0;
        parsed = strtoul(argv[1], &end, 10);
        if (errno != 0 || end == argv[1] || *end != '\0' || parsed < 1UL || parsed > (unsigned long)UINT_MAX)
        {
            fprintf(stderr, "Error: invalid input\n");
            return EXIT_FAILURE;
        }
        n = (unsigned int)parsed;
    }
    else
    {
        if (scanf("%u", &n) != 1)
        {
            fprintf(stderr, "Error: invalid input\n");
            return EXIT_FAILURE;
        }
        if (n < 1U)
        {
            fprintf(stderr, "Error: input must be at least 1\n");
            return EXIT_FAILURE;
        }
    }

    printf("%llu\n", totalUnsetBits(n));

    return EXIT_SUCCESS;
}
```

### Key changes
- **Command-line argument support** with `strtoul` validation (range-checked against `UINT_MAX`, rejects trailing garbage), with stdin fallback — the program no longer exits with `1` when driven by a test harness.
- **Bare numeric output** so `4` and `17` match expected values exactly.
- **Loop restructured** so termination is explicit (`i == n` checked before increment), eliminating the redundant `break` and the theoretical infinite loop at `n == UINT_MAX`.
