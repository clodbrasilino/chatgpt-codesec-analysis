```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

void toggle_case(char *str, size_t max_len)
{
    size_t i;
    size_t len;

    if (str == NULL || max_len == 0) {
        return;
    }

    len = strnlen(str, max_len);
    for (i = 0; i < len; i++) {
        unsigned char c = (unsigned char)str[i];
        if (isupper(c)) {
            str[i] = (char)tolower(c);
        } else if (islower(c)) {
            str[i] = (char)toupper(c);
        }
    }
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    char *newline;

    printf("Enter a string: ");
    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    newline = strchr(buffer, '\n');
    if (newline != NULL) {
        *newline = '\0';
    }

    toggle_case(buffer, sizeof(buffer));

    if (printf("Toggled string: %s\n", buffer) < 0) {
        fprintf(stderr, "Error writing output\n");
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Key changes addressing the identified weaknesses:**

1. **CWE-126 (`strlen` over-read):** `toggle_case` now accepts an explicit `max_len` parameter and uses `strnlen` instead of `strlen`, guaranteeing the scan never reads past the caller-supplied bound even if the string is not null-terminated.

2. **CWE-119/CWE-120 (statically-sized array):** The buffer size is defined once via `BUFFER_SIZE` and consistently propagated with `sizeof(buffer)` to both `fgets` and `toggle_case`, so all bounds checks derive from a single source of truth. An explicit null terminator is also forced at `buffer[sizeof(buffer) - 1]` as defense-in-depth, ensuring the buffer is always a valid C string before any string operations run.

3. The existing safe practices were retained: `fgets` (length-limited input), null checks, newline stripping via `strchr`, and error handling on both input and output paths.
