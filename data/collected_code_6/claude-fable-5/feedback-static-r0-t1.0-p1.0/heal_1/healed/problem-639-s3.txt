```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>
#include <stddef.h>

#define MAX_NAME_LEN 256

size_t sum_name_lengths(const char *const names[], size_t count)
{
    size_t total = 0;
    size_t i;

    if (names == NULL) {
        return 0;
    }

    for (i = 0; i < count; i++) {
        if (names[i] == NULL) {
            continue;
        }
        if (names[i][0] == '\0') {
            continue;
        }
        if (isupper((unsigned char)names[i][0])) {
            total += strnlen(names[i], MAX_NAME_LEN);
        }
    }

    return total;
}

int main(void)
{
    const char *const names[] = {
        "Alice",
        "bob",
        "Charlie",
        "dave",
        "Eve"
    };
    size_t count = sizeof(names) / sizeof(names[0]);
    size_t result;

    result = sum_name_lengths(names, count);

    if (printf("Total length: %zu\n", result) < 0) {
        return 1;
    }

    return 0;
}
```

**Analysis of the change:**

The original code used `strlen()`, which Flawfinder flagged (CWE-126, out-of-bounds read) because it will read indefinitely past the buffer if a string is not NUL-terminated. The fix replaces it with `strnlen()`, which takes an explicit upper bound (`MAX_NAME_LEN`). This guarantees the scan never reads more than 256 bytes, converting a potential unbounded over-read into a bounded, safe operation.

Additional defensive measures already present and preserved:

- **NULL pointer array check** (`names == NULL`) before iteration.
- **Per-element NULL check** (`names[i] == NULL`) to skip invalid entries.
- **Empty string check** before dereferencing `names[i][0]` for classification.
- **Cast to `unsigned char`** before passing to `isupper()`, avoiding undefined behavior when `char` is signed and holds a negative value.
- **Return value check on `printf()`**, propagating I/O failure via a nonzero exit code.

Note that `strnlen()` is POSIX (and C23); on strictly C89/C99 hosted environments without POSIX, a small manual bounded-length loop would be the portable equivalent.
