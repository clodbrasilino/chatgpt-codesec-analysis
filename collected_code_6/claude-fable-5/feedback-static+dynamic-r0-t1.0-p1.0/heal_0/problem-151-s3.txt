```c
#include <stdio.h>
#include <stdlib.h>

int gcd(int a, int b)
{
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int is_coprime(int a, int b)
{
    if (a <= 0 || b <= 0) {
        return -1;
    }
    if (gcd(a, b) == 1) {
        return 1;
    }
    return 0;
}

int main(void)
{
    int num1;
    int num2;
    int result;

    printf("Enter the first number: ");
    if (scanf("%d", &num1) != 1) {
        fprintf(stderr, "Invalid input.\n");
        return EXIT_FAILURE;
    }

    printf("Enter the second number: ");
    if (scanf("%d", &num2) != 1) {
        fprintf(stderr, "Invalid input.\n");
        return EXIT_FAILURE;
    }

    result = is_coprime(num1, num2);

    if (result == -1) {
        fprintf(stderr, "Numbers must be positive integers.\n");
        return EXIT_FAILURE;
    }

    if (result == 1) {
        printf("%d and %d are co-prime.\n", num1, num2);
    } else {
        printf("%d and %d are not co-prime.\n", num1, num2);
    }

    return EXIT_SUCCESS;
}
```

**Explanation of the approach:**

- **Co-prime check**: Two numbers are co-prime if their greatest common divisor (GCD) is 1. The `gcd` function uses the iterative Euclidean algorithm, which avoids recursion depth issues.

- **CWE-703 (Improper Check or Handling of Exceptional Conditions)**: The return value of `scanf` is checked to ensure valid integer input was actually read. Invalid or non-positive inputs produce error messages on `stderr` and a failure exit code.

- **CWE-664 (Improper Control of a Resource Through its Lifetime)**: No dynamic memory or file handles are used, so there are no resources that could leak or be misused across their lifetime.

- **CWE-710 (Improper Adherence to Coding Standards)**: The code uses `int main(void)`, returns `EXIT_SUCCESS`/`EXIT_FAILURE`, declares all functions with proper prototypes, and avoids undefined behavior such as modulo by zero (guarded by the positive-input check and the loop condition `b != 0`).
