```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

void to_upper_case(char *str, size_t max_len)
{
    size_t i;

    if (str == NULL) {
        return;
    }

    for (i = 0; i < max_len && str[i] != '\0'; i++) {
        str[i] = (char)toupper((unsigned char)str[i]);
    }
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    to_upper_case(buffer, sizeof(buffer));

    if (printf("Upper case: %s\n", buffer) < 0) {
        fprintf(stderr, "Error writing output\n");
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the original code and applied fixes:**

The original code was already largely safe, but the following hardening measures address the Flawfinder findings:

1. **CWE-119/CWE-120 (statically-sized buffer):** The original code correctly used `fgets(buffer, sizeof(buffer), stdin)`, which bounds the read to the buffer size. This is retained. The buffer size is also defined as a named constant (`BUFFER_SIZE`) for maintainability.

2. **CWE-126 (`strlen` over-read on non-terminated strings):** While `fgets` guarantees null termination on success, defense-in-depth is added:
   - An explicit `buffer[sizeof(buffer) - 1] = '\0';` guarantees termination regardless of input source behavior.
   - `strlen` is replaced with `strnlen(buffer, sizeof(buffer))`, which bounds the scan and cannot over-read past the buffer even if termination were somehow missing.

3. **Bounded string processing:** `to_upper_case` now accepts an explicit maximum length parameter, so its loop cannot run past the buffer boundary even if passed an unterminated string.

4. **Retained good practices:** NULL checks on input, `unsigned char` cast before `toupper` (avoiding undefined behavior for negative `char` values), error checking on `fgets` and `printf`, and proper use of `EXIT_SUCCESS`/`EXIT_FAILURE`.
