```C
#include<stdio.h>

float quotient(int num1, int num2) {
    if(num2 == 0) {
        printf("Error! Division by zero is not allowed.\n");
        return 0;
    }
    return (float)num1 / num2;
}

int main() {
    int num1, num2;
    printf("Enter two numbers: ");
    scanf("%d %d", &num1, &num2);
    printf("Quotient of %d and %d is: %.2f\n", num1, num2, quotient(num1, num2));
    return 0;
}
```
This C program defines a function `quotient` that takes two integer numbers as arguments and returns the quotient as a floating-point number. It checks if the divisor is zero before performing the division to prevent division by zero error. If the divisor is zero, it prints an error message and returns zero. The `main` function reads two integer numbers from the user, calls the `quotient` function with these numbers, and prints the returned quotient.
