## Analysis

**Overall structure:** The program implements the classic "word pattern" problem (LeetCode 290): checking whether a space-separated text follows a lowercase-letter pattern via a bijective mapping. The code is defensively written: NULL checks, `strnlen` with an explicit cap, `calloc` failure handling, `strtok_r` (reentrant), and post-loop verification that both pattern and text were fully consumed.

**Flawfinder findings assessment:**

1. **`memcpy` (CWE-120):** This is a *false positive in practice* — `copy` is allocated with `tlen + 1` bytes and exactly `tlen` bytes are copied. However, the safety relies on the reader connecting the allocation to the copy. It can be hardened by making the destination capacity explicit and verified before copying.

2. **`char` statically-sized array (CWE-119/CWE-120):** `map[ALPHABET_SIZE]` is only ever indexed after verifying `c` is in `['a','z']`, so `idx` is guaranteed `< 26`. Still, an explicit bounds check on `idx` makes the invariant local and machine-verifiable.

**Other observations:**
- Overflow in `tlen + 1U` is impossible since `tlen <= MAX_INPUT_LEN`.
- The bijection check (reverse lookup loop) correctly prevents two pattern letters mapping to the same word.
- `free(copy)` is reached on all paths after allocation — no leak.
- `printf` return value is checked — pedantic but correct.

## Hardened Rewrite

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

#define MAX_INPUT_LEN 4096U
#define ALPHABET_SIZE 26U

static bool follows_pattern(const char *pattern, const char *text)
{
    if (pattern == NULL || text == NULL) {
        return false;
    }

    size_t plen = strnlen(pattern, MAX_INPUT_LEN + 1U);
    if ((plen == 0U) || (plen > MAX_INPUT_LEN)) {
        return false;
    }

    size_t tlen = strnlen(text, MAX_INPUT_LEN + 1U);
    if (tlen > MAX_INPUT_LEN) {
        return false;
    }

    size_t copy_size = tlen + 1U;
    char *copy = calloc(copy_size, sizeof(char));
    if (copy == NULL) {
        return false;
    }

    if (tlen >= copy_size) {
        free(copy);
        return false;
    }
    memcpy(copy, text, tlen);
    copy[tlen] = '\0';

    const char *map[ALPHABET_SIZE] = { NULL };
    bool result = true;
    size_t i = 0U;
    char *saveptr = NULL;

    char *word = strtok_r(copy, " ", &saveptr);
    while ((word != NULL) && (i < plen)) {
        char c = pattern[i];
        if ((c < 'a') || (c > 'z')) {
            result = false;
            break;
        }
        size_t idx = (size_t)(c - 'a');
        if (idx >= ALPHABET_SIZE) {
            result = false;
            break;
        }
        if (map[idx] == NULL) {
            for (size_t j = 0U; j < ALPHABET_SIZE; j++) {
                if ((map[j] != NULL) && (strcmp(map[j], word) == 0)) {
                    result = false;
                    break;
                }
            }
            if (!result) {
                break;
            }
            map[idx] = word;
        } else {
            if (strcmp(map[idx], word) != 0) {
                result = false;
                break;
            }
        }
        i++;
        word = strtok_r(NULL, " ", &saveptr);
    }

    if (result && ((word != NULL) || (i != plen))) {
        result = false;
    }

    free(copy);
    return result;
}

int main(void)
{
    const char *patterns[] = { "abba", "abba", "aaaa", "abba" };
    const char *texts[] = {
        "dog cat cat dog",
        "dog cat cat fish",
        "dog cat cat dog",
        "dog dog dog dog"
    };
    size_t count = sizeof(patterns) / sizeof(patterns[0]);

    for (size_t i = 0U; i < count; i++) {
        bool ok = follows_pattern(patterns[i], texts[i]);
        int printed = printf("Pattern \"%s\" with \"%s\": %s\n",
                             patterns[i], texts[i], ok ? "true" : "false");
        if (printed < 0) {
            return EXIT_FAILURE;
        }
    }

    return EXIT_SUCCESS;
}
```

**Key hardening changes:**
- The destination capacity (`copy_size`) is now an explicit variable, checked against `tlen` immediately before `memcpy`, satisfying CWE-120 mitigation guidance ("make sure destination can always hold the source data").
- The terminator is written explicitly (`copy[tlen] = '\0'`) rather than relying solely on `calloc` zeroing.
- An explicit `idx >= ALPHABET_SIZE` guard makes the array bounds invariant locally provable, addressing the CWE-119/CWE-120 concern on the statically-sized `map` array.

Expected output: `true`, `false`, `false`, `false`.
