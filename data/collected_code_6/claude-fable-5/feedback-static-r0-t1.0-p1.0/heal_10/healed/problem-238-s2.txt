#include <stdio.h>
#include <string.h>

#define BUFFER_SIZE 1024U

unsigned long long count_substrings(const char *str, size_t max_len)
{
    unsigned long long n;

    if (str == NULL)
    {
        return 0ULL;
    }

    n = (unsigned long long)strnlen(str, max_len);

    return (n * (n + 1ULL)) / 2ULL;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    unsigned long long result;
    size_t len;

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL)
    {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1U] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0U && buffer[len - 1U] == '\n')
    {
        buffer[len - 1U] = '\0';
    }

    result = count_substrings(buffer, sizeof(buffer));

    if (printf("%llu\n", result) < 0)
    {
        return 1;
    }

    return 0;
}

Analysis of the original code and the flagged weakness:

**The Flawfinder warning (CWE-119/CWE-120) is already mitigated.** The `char buffer[BUFFER_SIZE]` warning is a heuristic hit on any statically-sized array. The code as written already applies all the recommended defenses:

1. **Bounded read:** `fgets(buffer, (int)sizeof(buffer), stdin)` limits input to the buffer size, so no overflow is possible on read. The return value is checked, handling EOF and stream errors.

2. **Guaranteed termination:** `buffer[sizeof(buffer) - 1U] = '\0'` is defensive redundancy — `fgets` already null-terminates, but this makes the invariant explicit and robust against future refactoring.

3. **Length-limited scanning:** `strnlen(buffer, sizeof(buffer))` is used instead of `strlen`, so even a hypothetically unterminated buffer cannot cause an out-of-bounds read. The same bounded approach is used inside `count_substrings`.

4. **Safe indexing:** The newline strip checks `len > 0U` before accessing `buffer[len - 1U]`, avoiding an underflow on empty input.

5. **NULL guard and overflow-aware arithmetic:** `count_substrings` rejects NULL and performs the `n * (n + 1) / 2` computation in `unsigned long long`. With `n ≤ 1023`, the maximum intermediate value (~524,800) is nowhere near overflow.

6. **Checked output:** The `printf` return value is verified, propagating write failures via exit status.
