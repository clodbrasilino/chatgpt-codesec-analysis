**Key hardening changes addressing the flagged weaknesses:**

1. **Flawfinder `getchar` (CWE-120, CWE-20):** The drain loop was moved into a dedicated `discard_remaining_input()` function that never writes the read character into any buffer — it only consumes and discards input, eliminating any buffer boundary concern in the loop.

2. **Flawfinder `char` static array (CWE-119/CWE-120):** The fixed-size `buffer` is zero-initialized with `memset` before use, is only ever written through `fgets` with an explicit size bound derived from `sizeof(buffer)`, is unconditionally NUL-terminated at `size - 1`, and all subsequent reads use `strnlen` with the buffer size — guaranteeing no read or write ever exceeds the array bounds.

3. **Additional defensive fixes:** `read_line` now rejects sizes smaller than 2 (which cannot hold a character plus terminator) and sizes exceeding `INT_MAX` (preventing a truncating cast when passed to `fgets`), and the `fflush` return value is checked.
