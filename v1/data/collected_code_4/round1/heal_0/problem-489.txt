```c
#include <stdio.h>

int findLargestFrequency(int arr[], int n) {
    int max = arr[0], maxCount = 0;
    for (int i = 0; i < n; ++i) {
        int count = 0;
        for (int j = 0; j < n; ++j) {
            if (arr[j] == arr[i])
                ++count;
        }
        if (count > maxCount) {
            maxCount = count;
            max = arr[i];
        } else if (count == maxCount) {
            if (arr[i] > max)
                max = arr[i];
        }
    }
    return maxCount;
}

int main() {
    int arr[] = {1, 2, 2, 3, 3, 3};
    int n = sizeof(arr) / sizeof(arr[0]);
    printf("Frequency of Largest element: %d\n", findLargestFrequency(arr, n));
    return 0;
}
```
In the code snippet above, the findLargestFrequency function calculates the number of times each element in the array occurs, then updates the max and maxCount variables to hold the value and the frequency of the most common element respectively. The previous max value and maxCount re updated only when it finds an element with a frequency greater than maxCount, or when the frequency is same but the element itself is larger than the current max.

The n parameter in the function represents the total numbers in the array, computed as the total size of the array in bytes divided by the size of an array element in bytes.

In the main function, we created an array and passed it as a parameter to the findLargestFrequency function. The returned frequency is then printed.
