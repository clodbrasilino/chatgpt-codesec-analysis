```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define MAX_INPUT_LEN 4096

char *remove_lowercase(const char *input)
{
    size_t len;
    size_t i;
    size_t j;
    char *result;

    if (input == NULL) {
        return NULL;
    }

    len = strnlen(input, MAX_INPUT_LEN);

    result = malloc(len + 1);
    if (result == NULL) {
        return NULL;
    }

    j = 0;
    for (i = 0; i < len; i++) {
        if (!islower((unsigned char)input[i])) {
            result[j] = input[i];
            j++;
        }
    }
    result[j] = '\0';

    return result;
}

int main(void)
{
    char buffer[MAX_INPUT_LEN];

    while (fgets(buffer, sizeof(buffer), stdin) != NULL) {
        size_t len = strnlen(buffer, sizeof(buffer));
        if (len > 0 && buffer[len - 1] == '\n') {
            buffer[len - 1] = '\0';
        }

        char *output = remove_lowercase(buffer);
        if (output == NULL) {
            fprintf(stderr, "Memory allocation failed\n");
            return EXIT_FAILURE;
        }

        printf("%s\n", output);
        free(output);
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the fixes applied:**

1. **CWE-119/CWE-120 (statically-sized buffer):** The buffer itself is safe as used — `fgets(buffer, sizeof(buffer), stdin)` performs proper bounds limiting and guarantees null-termination. No change to the buffer was required; the original flawfinder hit was a low-risk informational flag.

2. **CWE-126 (strlen over-read):** Replaced `strlen(buffer)` with `strnlen(buffer, sizeof(buffer))`. While `fgets` guarantees null-termination in practice, `strnlen` provides defense-in-depth by bounding the read to the buffer size, eliminating any possibility of an over-read.

3. **Variable scope reduction (cppcheck):** Both `output` and `len` are now declared inside the `while` loop body at the point of first use, minimizing their scope. This is valid C99+ and improves readability and maintainability, and prevents accidental use of stale values across iterations.

4. **Existing sound practices retained:** the `NULL` input check, `malloc` failure handling, the `(unsigned char)` cast before `islower()` (required to avoid undefined behavior with negative `char` values), and `free()` of the allocated result on every iteration to avoid leaks.
