```C
#include <stdio.h>

#define MAX_SIZE 100

int findMaxOcurring(int arr[], int n) {
    int count[MAX_SIZE] = {0};
    int max = 0;
    int result = -1;

    for(int i = 0; i < n; i++) {
        count[arr[i]]++;

        if(max < count[arr[i]]) {
            max = count[arr[i]];
            result = arr[i];
        } else if(max == count[arr[i]]) {
            if(result > arr[i])
                result = arr[i];
        }
    }
    return result;
}

int main() {
    int arr[] = {3,4,2,2,3,1,1,1,3,4,4,4};
    int n = sizeof(arr) / sizeof(arr[0]);

    printf("%d\n", findMaxOcurring(arr, n));

    return 0;
}
```
In this code, we first declare a count array with size MAX_SIZE and initialize it with 0. We initialize max to 0 and result to -1.

In the main for loop, we increment the count value for each array element. If max is less than the count of the current array element, we set max to this count and result to the array element. If max is equal to the count of the current array element but the result is larger than the array element, we set result to the array element to handle the case where we have multiple elements with the same max count - we choose the smallest one.

Finally, we print the result in the main function. The program finds and prints the smallest element with maximum count in the given array.
