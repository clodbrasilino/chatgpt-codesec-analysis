```c
#include <stdio.h>
#include <string.h>
#include <stdbool.h>

bool first_last_equal(const char *str)
{
    size_t len;

    if (str == NULL) {
        return false;
    }

    len = strlen(str);
    if (len == 0) {
        return false;
    }

    return str[0] == str[len - 1];
}

int main(void)
{
    char buffer[256];
    size_t len;

    printf("Enter a string: ");
    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    len = strlen(buffer);
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    if (buffer[0] == '\0') {
        printf("Empty string provided\n");
        return 1;
    }

    if (first_last_equal(buffer)) {
        printf("The first and last characters are equal\n");
    } else {
        printf("The first and last characters are not equal\n");
    }

    return 0;
}
```

**Key safety points in this implementation:**

- **CWE-664 (Resource lifetime):** No dynamic memory allocation is used, so there are no leaks or use-after-free risks. The buffer is stack-allocated with a fixed, known size, and `fgets` respects that bound.

- **CWE-703 (Exceptional conditions):** The return value of `fgets` is checked for `NULL` (EOF or read error), the function guards against `NULL` pointers and empty strings, and the program returns distinct exit codes on failure paths.

- **CWE-710 (Coding standards):** Uses `size_t` for lengths, `const` correctness on the function parameter, `bool` from `<stdbool.h>` for clarity, `main(void)` per the C standard, and bounded input via `fgets` instead of unsafe functions like `gets` or unbounded `scanf("%s", ...)`.
