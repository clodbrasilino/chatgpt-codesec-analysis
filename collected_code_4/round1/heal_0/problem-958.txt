```C
#include <stdio.h>
#include<string.h>

char* intToRoman(int num) {
    char roman[13][3] = {"M","CM","D","CD","C","XC","L","XL","X","IX","V","IV","I"};
    int decimal[13] = {1000,900,500,400,100,90,50,40,10,9,5,4,1}; 
    char *res = malloc(sizeof(char) * 16);
    memset(res, 0, sizeof(char) * 16);
    int i = 0;
    while(num){
      while(num >= decimal[i]){
         num -= decimal[i];
         strcat(res, roman[i]);
      }
      i++;
    }
    return res;
}

int main() {
    int number;
    printf("Enter a number: ");
    scanf("%d", &number);
    char *roman = intToRoman(number);
    if(roman) {
        printf("Roman numeral: %s\n", roman);
        free(roman);
    }
    return 0;
}
```
This code includes several key elements in a standard C programming code such as stdio.h and string.h headers, a main function and custom function definitions. The function `intToRoman` has an input parameter `num` which stands for the input integer to be converted. The `while` loop inside this function keeps subtracting the highest possible value from `num` and appending the corresponding Roman numeral to `res` until `num` has been reduced to zero. Proper memory management is done by deallocating the `roman` string after printing it.
