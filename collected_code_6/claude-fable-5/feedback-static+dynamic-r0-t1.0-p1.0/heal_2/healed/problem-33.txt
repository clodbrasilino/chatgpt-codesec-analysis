```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

static int decimal_to_binary(long decimal, char *buffer, size_t buffer_size);

static int decimal_to_binary(long decimal, char *buffer, size_t buffer_size)
{
    size_t index = 0;
    size_t start;
    size_t end;
    unsigned long value;

    if (buffer == NULL || buffer_size < 2) {
        return -1;
    }

    if (decimal < 0) {
        buffer[index] = '-';
        index++;
        value = (unsigned long)(-(decimal + 1)) + 1UL;
    } else {
        value = (unsigned long)decimal;
    }

    start = index;

    if (value == 0UL) {
        if (index >= buffer_size - 1) {
            return -1;
        }
        buffer[index] = '0';
        index++;
    } else {
        while (value > 0UL) {
            if (index >= buffer_size - 1) {
                return -1;
            }
            buffer[index] = (char)('0' + (char)(value % 2UL));
            index++;
            value /= 2UL;
        }
    }

    buffer[index] = '\0';

    end = index - 1;
    while (start < end) {
        char temp = buffer[start];
        buffer[start] = buffer[end];
        buffer[end] = temp;
        start++;
        end--;
    }

    return 0;
}

int main(void)
{
    long decimal = 0;
    char binary[CHAR_BIT * sizeof(long) + 2] = {0};
    int scan_result;

    printf("Enter a decimal number: ");

    scan_result = scanf("%ld", &decimal);
    if (scan_result != 1) {
        fprintf(stderr, "Error: invalid input.\n");
        return EXIT_FAILURE;
    }

    if (decimal_to_binary(decimal, binary, sizeof(binary)) != 0) {
        fprintf(stderr, "Error: conversion failed.\n");
        return EXIT_FAILURE;
    }

    printf("Binary representation: %s\n", binary);

    return EXIT_SUCCESS;
}
```

Key changes made to address the reported weaknesses:

1. **`Condition 'index+1>=buffer_size' is always false` (knownConditionTrueFalse):** The redundant bounds check before writing the `'-'` sign was removed. Since the function already guarantees `buffer_size >= 2` at entry and `index` is `0` at that point, the check could never trigger — the analyzer was correct. Writing the sign character at index `0` is always safe under the established precondition.

2. **Bounds-check expression rewritten:** The remaining guards now use `index >= buffer_size - 1` instead of `index + 1 >= buffer_size`. This is semantically identical (given `buffer_size >= 2`, no underflow is possible) but avoids the potential unsigned overflow pattern `index + 1` that static analyzers flag, and it makes clear that one slot is always reserved for the null terminator.

3. **`index == 0` post-check removed:** That branch was dead code — every path through the function writes at least one character (`'0'`, a digit, or `'-'` followed by digits), so `index` can never be `0` when reaching the terminator. Removing it eliminates another unreachable-condition warning and makes `end = index - 1` provably safe.

4. **Flawfinder CWE-119/CWE-120 (statically-sized buffer):** The buffer size `CHAR_BIT * sizeof(long) + 2` is provably sufficient for the worst case (`LONG_MIN`: sign + up to `CHAR_BIT * sizeof(long)` bits + null terminator), and the size is passed explicitly via `sizeof(binary)` with strict bounds checking inside the conversion function — this is the correct mitigation, so the array itself is retained.

5. **Negative-value negation kept as `-(decimal + 1) + 1UL`:** This idiom is preserved deliberately, since a naive `-decimal` invokes undefined behavior for `LONG_MIN`.

6. The conversion function was given a `static` linkage and a forward declaration for cleanliness; `scanf` results remain checked, satisfying input-validation requirements.
