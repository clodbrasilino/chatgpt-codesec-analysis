```c
#include <stdio.h>
#include <stdlib.h>

size_t find_insertion_point(const int *arr, size_t size, int value)
{
    size_t low = 0;
    size_t high = size;

    while (low < high) {
        size_t mid = low + (high - low) / 2;
        if (arr[mid] <= value) {
            low = mid + 1;
        } else {
            high = mid;
        }
    }
    return low;
}

int main(void)
{
    int sorted_array[] = {1, 3, 4, 4, 7, 9, 12};
    size_t size = sizeof(sorted_array) / sizeof(sorted_array[0]);
    int values_to_test[] = {4, 0, 15, 8};
    size_t num_tests = sizeof(values_to_test) / sizeof(values_to_test[0]);
    size_t i;

    for (i = 0; i < num_tests; i++) {
        size_t pos = find_insertion_point(sorted_array, size, values_to_test[i]);
        if (printf("Insertion point for %d is index %zu\n", values_to_test[i], pos) < 0) {
            return EXIT_FAILURE;
        }
    }

    return EXIT_SUCCESS;
}
```

This implementation uses a binary search (`bisect_right` semantics) to find the rightmost valid insertion index in O(log n) time. Key safety points:

- `size_t` is used for all indices and sizes, avoiding signed overflow and negative index issues.
- The midpoint is computed as `low + (high - low) / 2` to prevent integer overflow.
- The array is passed as `const` since the function never modifies it.
- The return value of `printf` is checked, and the program exits with `EXIT_FAILURE` on output errors.
- No dynamic memory is used, so there are no resource lifetime concerns.
