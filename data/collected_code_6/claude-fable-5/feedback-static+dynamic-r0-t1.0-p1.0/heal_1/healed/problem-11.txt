```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

void remove_first_last(char *str, char ch)
{
    size_t len;
    char *first;
    char *last;

    if (str == NULL || ch == '\0') {
        return;
    }

    len = strnlen(str, 256U);
    if (len == 0U) {
        return;
    }

    first = strchr(str, (int)ch);
    if (first == NULL) {
        return;
    }

    last = strrchr(str, (int)ch);

    if (last != NULL && last != first) {
        memmove(last, last + 1, strlen(last + 1) + 1U);
    }

    memmove(first, first + 1, strlen(first + 1) + 1U);
}

int main(void)
{
    char buffer[256];
    char target;
    int input_char;
    size_t len;

    printf("Enter a string: ");
    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input string\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1U] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0U && buffer[len - 1U] == '\n') {
        buffer[len - 1U] = '\0';
    }

    printf("Enter the character to remove: ");
    input_char = getchar();
    if (input_char == EOF) {
        fprintf(stderr, "Error reading character\n");
        return EXIT_FAILURE;
    }
    target = (char)input_char;

    remove_first_last(buffer, target);

    printf("Result: %s\n", buffer);

    return EXIT_SUCCESS;
}
```

**Analysis notes:**

- **CWE-126 (`strlen` over-read):** All `strlen` calls operate on buffers guaranteed to be NUL-terminated. `fgets` always terminates its output, and an explicit `buffer[sizeof(buffer) - 1] = '\0'` was added as defense-in-depth. Inside `remove_first_last`, `strnlen` with a bound is used for the initial length check, and the subsequent `strlen` calls operate on pointers derived from `strchr`/`strrchr`, which can only succeed on a terminated string.
- **CWE-119/CWE-120 (statically-sized array):** `fgets(buffer, sizeof(buffer), stdin)` strictly bounds the write to the array; no unbounded copy functions (`strcpy`, `gets`, `sprintf`) are used.
- **CWE-120/CWE-20 (`getchar`):** The single `getchar` call is not in a loop, its `EOF` return is checked before use, and the value is only used as a search character — never as an index or length.
- **Logic hardening:** A guard against `ch == '\0'` was added, since `strchr(str, '\0')` matches the terminator and the original code would have shifted memory past the string's logical end (removing the terminator itself).
- **Removal order preserved:** The last occurrence is removed before the first, which is required — removing the first occurrence first would invalidate the `last` pointer.
