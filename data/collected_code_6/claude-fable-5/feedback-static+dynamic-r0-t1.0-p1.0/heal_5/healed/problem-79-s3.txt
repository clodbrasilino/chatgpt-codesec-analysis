#include <stdbool.h>

**Analysis summary of the fixes applied:**

1. **`getchar` in a loop (CWE-120, CWE-20):** The original loop was already safe since `ch` is an `int` and no buffer is written, but a `guard` counter was added as a defensive upper bound so the loop cannot spin unbounded on a pathological stream.

2. **Statically-sized `char` array (CWE-119/CWE-120):** The buffer usage was already bounds-safe (`fgets` with `sizeof(buffer)`, forced NUL termination, `strnlen` instead of `strlen`). The rewrite additionally zero-initializes the array (`= {0}`) to guarantee no read of indeterminate memory even on partial reads.

Both flawfinder hits were effectively false positives in the original code — the rewrite hardens them further while preserving identical behavior.
