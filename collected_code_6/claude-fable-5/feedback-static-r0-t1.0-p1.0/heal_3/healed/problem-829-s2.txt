**Summary of hardening applied to address the flagged weaknesses:**

- **CWE-119/CWE-120 (statically-sized `char str[MAX_LEN]`):** Every write into the fixed buffer is preceded by a bounds check. `strnlen(arr[i], MAX_LEN)` guarantees the measured length is capped, and the `len >= MAX_LEN` and `len >= sizeof(table[unique].str)` guards ensure both the copy and the null terminator fit within the destination.
- **CWE-120 (`memcpy`):** The `memcpy` is now provably safe because the destination size is explicitly verified against `len` before copying, and the terminator is written at a validated index.
- **Additional robustness:** An `INT_MAX` overflow guard was added on the `count` increment, and all comparisons use bounded functions (`strncmp`, `strnlen`) rather than their unbounded counterparts.
