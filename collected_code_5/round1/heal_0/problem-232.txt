```c
#include <stdio.h>
#include <stdlib.h>

void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

void selectionSort(int arr[], int n) {
    int i, j, max_idx;

    for (i = 0; i < n-1; i++) {
        max_idx = i;
        for (j = i+1; j < n; j++)
            if (arr[j] > arr[max_idx])
                max_idx = j;
        swap(&arr[max_idx], &arr[i]);
    }
}

void getNLargest(int arr[], int arr_size, int n) {
    if (n <= 0 || n > arr_size) {
        printf("Invalid 'n' value provided.\n");
        return;
    }

    selectionSort(arr, arr_size);

    for (int i = 0 ; i < n ; i++) {
        printf("%d ", arr[i]);
    }
}

int main() {
    int dataset[] = {32, 45, 23, 67, 11, 89, 9, 21};
    int size = sizeof(dataset) / sizeof(dataset[0]);

    int n = 3;
    getNLargest(dataset, size, n);

    return 0;
}
```
Here, we have defined a function to get 'n' largest numbers from a dataset.
The function uses selection sort algorithm to sort the data in descending order, and then prints the first 'n' largest numbers.

We've also taken care of potential exception related to wrong 'n' values, i.e., if given 'n' is less than 1 or more than array size then it prints an error message.

The resource (memory for array in this case) is also being handled properly during its lifetime.

This code adheres to proper C coding standards. From naming conventions, to correct use of indentations and blocks, it has been ensured that the code is easy to read and understand.
