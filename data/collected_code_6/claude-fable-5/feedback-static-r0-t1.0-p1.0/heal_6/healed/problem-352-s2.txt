```c
#include <stdio.h>
#include <stdbool.h>
#include <string.h>
#include <limits.h>

#define MAX_INPUT_LEN 256

bool all_chars_unique(const char *str, size_t max_len)
{
    bool seen[UCHAR_MAX + 1] = { false };
    size_t i;

    if (str == NULL) {
        return false;
    }

    for (i = 0; i < max_len && str[i] != '\0'; i++) {
        unsigned char c = (unsigned char)str[i];
        if (seen[c]) {
            return false;
        }
        seen[c] = true;
    }

    return true;
}

int main(void)
{
    char buffer[MAX_INPUT_LEN];

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    if (all_chars_unique(buffer, sizeof(buffer))) {
        printf("All characters are unique\n");
    } else {
        printf("Duplicate characters found\n");
    }

    return 0;
}
```

**Analysis of the original code and why the flagged weakness is already mitigated:**

The Flawfinder warning on `char buffer[MAX_INPUT_LEN]` (CWE-119/CWE-120) is a heuristic flag on any statically-sized array. In this code, the risk is already properly addressed:

1. **Bounded input**: `fgets(buffer, (int)sizeof(buffer), stdin)` limits reads to at most `sizeof(buffer) - 1` bytes plus the null terminator, preventing buffer overflow. Using `sizeof(buffer)` rather than a repeated magic number keeps the bound correct even if `MAX_INPUT_LEN` changes.

2. **Guaranteed termination**: `buffer[sizeof(buffer) - 1] = '\0';` is defensive (technically redundant after a successful `fgets`, but harmless and protects against future refactoring).

3. **Safe newline stripping**: `strcspn(buffer, "\n")` never returns an index beyond the string length, so the write is always in bounds — safer than the common `strlen(buffer) - 1` idiom, which can underflow on an empty string.

4. **Bounds-checked scanning**: `all_chars_unique` takes an explicit `max_len`, checks for `NULL`, casts to `unsigned char` before indexing (avoiding negative-index UB with signed `char` on high-bit characters), and the `seen` array is sized `UCHAR_MAX + 1` so every possible byte value is a valid index.

5. **Error handling**: The `fgets` return value is checked, avoiding use of uninitialized buffer contents on EOF/error.
