The fixes applied:
- **Variable scope (cppcheck):** `written` is now declared inside the loop body, the narrowest scope where it is used.
- **CWE-134 (Flawfinder):** the ternary format string was replaced with constant format strings (`"%d %d"` and a separate `" "` separator write), so `snprintf` never receives a computed format argument.
- **Bonus hardening:** an overflow guard on the `buffer_size` multiplication was added before `malloc`.
