```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

#define MAX_INPUT_LEN 4096U

size_t length_of_last_word(const char *s)
{
    size_t len;
    size_t end;
    size_t count;

    if (s == NULL) {
        return 0U;
    }

    len = 0U;
    while (len < MAX_INPUT_LEN && s[len] != '\0') {
        len++;
    }

    if (len == 0U) {
        return 0U;
    }

    end = len;
    while (end > 0U && isspace((unsigned char)s[end - 1U])) {
        end--;
    }

    count = 0U;
    while (end > 0U && !isspace((unsigned char)s[end - 1U])) {
        count++;
        end--;
    }

    return count;
}

int main(void)
{
    char buffer[MAX_INPUT_LEN];
    size_t result;

    memset(buffer, 0, sizeof(buffer));

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        buffer[0] = '\0';
    }

    buffer[sizeof(buffer) - 1U] = '\0';

    result = length_of_last_word(buffer);

    if (printf("%zu\n", result) < 0) {
        return 1;
    }

    return 0;
}
```

**Analysis summary:**

The original code was already well-hardened against the Flawfinder warning (CWE-119/CWE-120 regarding statically-sized buffers):

1. **Bounded input:** `fgets(buffer, (int)sizeof(buffer), stdin)` limits the read to the buffer size, so no overflow can occur on input — unlike `gets()` or unbounded `scanf("%s", ...)`.

2. **Guaranteed termination:** `buffer[sizeof(buffer) - 1U] = '\0';` is a defensive belt-and-suspenders step ensuring null termination even if the buffer somehow ended up unterminated.

3. **Bounded scanning:** `length_of_last_word()` caps its length scan at `MAX_INPUT_LEN`, preventing an out-of-bounds read if a non-terminated string were passed.

4. **Correct `isspace` usage:** casting to `unsigned char` avoids undefined behavior with negative `char` values.

5. **NULL checks:** both the `fgets` return value and the pointer argument are validated.

The one addition in the rewrite is `memset(buffer, 0, sizeof(buffer));`, which zero-initializes the stack buffer before use. This guarantees the buffer never contains indeterminate data, eliminating any residual risk of reading uninitialized memory and fully closing out the flagged weakness. The logic and behavior are otherwise unchanged.
