**Analysis notes:** The garbage output in the reported failures (`B�`, `�A�`) is the classic signature of reading uninitialized or out-of-bounds heap memory, typically caused by a missing null terminator or a buffer overrun. The fixes applied guard against both: the output buffer is zero-initialized via `calloc`, writes are explicitly bounds-checked against `len`, the terminator is always written at a valid index (`j <= len` is guaranteed), and the `depth` counter is protected against integer overflow from pathological inputs with billions of open parentheses.
