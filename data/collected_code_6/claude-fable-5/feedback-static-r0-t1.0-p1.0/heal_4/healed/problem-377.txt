```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define BUFFER_SIZE 256

void remove_char(char *str, char ch)
{
    size_t i;
    size_t j;

    if (str == NULL) {
        return;
    }

    j = 0;
    for (i = 0; str[i] != '\0'; i++) {
        if (str[i] != ch) {
            str[j] = str[i];
            j++;
        }
    }
    str[j] = '\0';
}

static void flush_stdin(void)
{
    int discard;

    do {
        discard = getchar();
    } while (discard != '\n' && discard != EOF);
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    char target;
    int input;
    size_t len;
    int newline_found;

    printf("Enter a string: ");
    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading string input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strcspn(buffer, "\n");
    newline_found = (buffer[len] == '\n');
    buffer[len] = '\0';

    if (!newline_found) {
        flush_stdin();
    }

    printf("Enter the character to remove: ");
    input = getchar();
    if (input == EOF) {
        fprintf(stderr, "Error reading character input\n");
        return EXIT_FAILURE;
    }
    target = (char)input;

    remove_char(buffer, target);

    printf("Result: %s\n", buffer);

    return EXIT_SUCCESS;
}
```

**Analysis of the flagged weaknesses and why the code is already safe:**

1. **`char buffer[BUFFER_SIZE]` (CWE-119/CWE-120):** The statically-sized array is safely handled. Input is read with `fgets(buffer, sizeof(buffer), stdin)`, which enforces the buffer boundary, and `buffer[sizeof(buffer) - 1] = '\0'` guarantees null termination. No unbounded functions like `gets()` or `strcpy()` are used.

2. **`getchar()` in `flush_stdin()` loop (CWE-120/CWE-20):** The result is stored in an `int` (not `char`), which is required to correctly distinguish `EOF` from valid characters. The loop terminates on both `'\n'` and `EOF`, so it cannot spin forever on a closed stream, and no data is written to any buffer — it only discards input.

3. **`getchar()` for the target character (CWE-120/CWE-20):** The return value is stored in an `int` and explicitly checked against `EOF` before being narrowed to `char`, providing proper input validation.

Additional defensive measures already present: `remove_char()` guards against `NULL` pointers, `strcspn()` safely locates the newline within the terminated buffer, and leftover stdin data is flushed only when the input line was truncated, preventing stale input from corrupting the second prompt. The Flawfinder hits are informational (risk 1–2) and all are properly mitigated, so the code stands as-is with the comments removed.
