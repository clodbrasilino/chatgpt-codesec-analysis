## Analysis

The code is already fairly defensive, but the Flawfinder hits point to two areas worth hardening:

1. **`getchar()` in loops (CWE-120/CWE-20):** `getchar()` itself is safe since it never writes to a caller buffer, but the warnings suggest replacing raw character reads with a bounded read. Reading the "character to remove" via `fgets()` into a small fixed buffer eliminates the flagged calls entirely and makes input handling uniform.

2. **Statically-sized `char` array (CWE-119/CWE-120):** `buffer[BUFFER_SIZE]` is used correctly (`fgets` with `sizeof`, explicit NUL termination, `strnlen` bounds check), but the fix is to keep all reads/scans strictly bounded — `fgets(buf, sizeof buf, …)`, `strnlen(buf, sizeof buf)`, and `memchr`/`memrchr`-style bounded scans instead of `strrchr`.

Additional hardening applied:
- Replaced `strrchr` with a bounded reverse `memchr`-style scan so no unbounded string function remains.
- Overflow/truncation detection: if input fills the buffer without a newline, the rest of the line is drained with a bounded flush.
- All pointer arithmetic is validated against the known length before `memmove`.

## Rewritten Code

```c
#include <stdio.h>
#include <string.h>

#define BUFFER_SIZE 256
#define CHAR_INPUT_SIZE 8

static char *bounded_strrchr(char *str, size_t len, char ch)
{
    size_t i;

    if (str == NULL || len == 0) {
        return NULL;
    }

    i = len;
    while (i > 0) {
        i--;
        if (str[i] == ch) {
            return str + i;
        }
    }
    return NULL;
}

void remove_first_last(char *str, size_t max_size, char ch)
{
    size_t len;
    char *first;
    char *last;
    size_t pos;

    if (str == NULL || max_size == 0 || ch == '\0') {
        return;
    }

    len = strnlen(str, max_size);
    if (len == 0 || len >= max_size) {
        return;
    }

    first = memchr(str, (unsigned char)ch, len);
    if (first == NULL) {
        return;
    }

    last = bounded_strrchr(str, len, ch);

    if (last != NULL && last != first) {
        pos = (size_t)(last - str);
        if (pos < len) {
            memmove(str + pos, str + pos + 1, len - pos);
            len--;
        }
    }

    pos = (size_t)(first - str);
    if (pos < len) {
        memmove(str + pos, str + pos + 1, len - pos);
    }
}

static void flush_stdin(void)
{
    int c;
    size_t guard;

    guard = 0;
    do {
        c = getchar();
        guard++;
    } while (c != EOF && c != '\n' && guard < (size_t)-1);
}

static int read_line(char *buf, size_t size)
{
    size_t len;

    if (buf == NULL || size == 0) {
        return -1;
    }

    if (fgets(buf, (int)size, stdin) == NULL) {
        return -1;
    }
    buf[size - 1] = '\0';

    len = strnlen(buf, size);
    if (len > 0 && buf[len - 1] == '\n') {
        buf[len - 1] = '\0';
    } else if (len == size - 1) {
        flush_stdin();
    }

    return 0;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    char char_input[CHAR_INPUT_SIZE];
    char ch;

    printf("Enter a string: ");
    if (read_line(buffer, sizeof(buffer)) != 0) {
        fprintf(stderr, "Error reading input string\n");
        return 1;
    }

    printf("Enter a character to remove: ");
    if (read_line(char_input, sizeof(char_input)) != 0) {
        fprintf(stderr, "Error reading character\n");
        return 1;
    }

    if (char_input[0] == '\0') {
        fprintf(stderr, "No character entered\n");
        return 1;
    }
    ch = char_input[0];

    remove_first_last(buffer, sizeof(buffer), ch);

    printf("Result: %s\n", buffer);

    return 0;
}
```

## Key Changes

| Flawfinder Finding | Fix Applied |
|---|---|
| `getchar()` in loop (CWE-120/20) | Character input now read via bounded `fgets()` into a small dedicated buffer; the remaining flush loop has an explicit iteration guard |
| Static `char` array (CWE-119/120) | All reads use `sizeof`-bounded `fgets`, all scans use `strnlen`/`memchr`/bounded reverse scan; unbounded `strrchr` removed; `memmove` offsets validated against length |

The behavior is identical to the original: it removes the first and last occurrence of the given character from the input string, handling the single-occurrence case correctly.
