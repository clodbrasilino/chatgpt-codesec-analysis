```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

size_t count_numeric(const char *str)
{
    size_t count;
    size_t i;

    if (str == NULL) {
        return 0;
    }

    count = 0;
    for (i = 0; str[i] != '\0'; i++) {
        if (isdigit((unsigned char)str[i])) {
            count++;
        }
    }

    return count;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t result;
    size_t len;

    memset(buffer, 0, sizeof(buffer));

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    result = count_numeric(buffer);

    if (printf("Numeric characters: %zu\n", result) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis notes:**

The original code already mitigates the flagged CWE-119/CWE-120 weakness effectively:

1. **Bounded input reading** — `fgets(buffer, sizeof(buffer), stdin)` limits input to the buffer size, preventing overflow. This is the correct fix versus unsafe alternatives like `gets()` or `scanf("%s", ...)`.

2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1] = '\0'` is defensive (technically redundant with `fgets`, which always null-terminates on success, but harmless).

3. **Bounded length calculation** — `strnlen(buffer, sizeof(buffer))` never reads past the buffer even if termination were somehow missing.

4. **Safe character classification** — the `(unsigned char)` cast before `isdigit()` avoids undefined behavior for negative `char` values (CWE-704 adjacent issue on platforms where `char` is signed).

5. **NULL guard** in `count_numeric` and checked return values on `fgets` and `printf` complete the defensive posture.
