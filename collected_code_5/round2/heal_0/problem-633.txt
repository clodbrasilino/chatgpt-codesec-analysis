```C
#include <stdio.h>

int sumXOR(int arr[], int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            sum += arr[i] ^ arr[j];
        }
    }
    return sum;
}

int main() {
    int arr[] = {5, 9, 7, 6};
    int n = sizeof(arr) / sizeof(arr[0]);
    int sum = sumXOR(arr, n);
    printf("%d\n", sum);
    return 0;
}
```

The `sumXOR()` function takes an array and its size as arguments. It iterates over all possible pairs of elements in the array, computes the XOR of each pair, and adds the result to the `sum` variable. The function finally returns the sum.

In the `main()` function, an array `arr[]` of integers is initialized along with its size `n`. Then, the function `sumXOR()` is called with `arr[]` and `n` as arguments and the result is stored in `sum`. This result is then printed out. The `main()` function ends by returning 0, indicating successful termination of the program.
