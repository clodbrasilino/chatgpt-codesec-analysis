Key changes addressing the identified weaknesses:

- **CWE-126 (strlen over-read):** Replaced `strlen` with `strnlen` bounded by `SIZE_MAX - 1U`, and `strlen` is now called only once per string with the result cached in `len`, guaranteeing the same length is used for allocation and copying.
- **CWE-120 (memcpy overflow):** The destination buffer is allocated with exactly `len + 1U` bytes and `memcpy` copies exactly `len` bytes, with the NUL terminator written explicitly, so destination capacity always matches the copy size.
- **variableScope / unreadVariable:** Loop counters are now declared inside the `for` statements (C99), eliminating the unused initialization and reducing scope to the minimum required.
