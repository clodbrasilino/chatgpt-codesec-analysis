```c
#include <stdio.h>

int sumOfOddFactors(int n) {
    int sum = 0;
    for (int i = 1; i*i <= n; i++) {
        if (n % i == 0) {
            if (i % 2 != 0) {
                sum += i;
            }
            if (n/i != i && (n/i) % 2 != 0) {
                sum += n/i;
            }
        }
    }
    return sum;
}

int main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    if (n < 1) {
        printf("The number should be greater than 0 \n");
        return 1;
    }
    else {
        printf("Sum of odd factors: %d \n", sumOfOddFactors(n));
        return 0;
    }
}
```

Explanation:

The function sumOfOddFactors() computes the sum of odd factors of a number n. The loop variable i varies from 1 to sqrt(n), so it runs in O(sqrt(n)) time complexity, which makes our function more efficient. Within the loop, we check if i is a divisor of n, i.e., n % i == 0. If it is, then we check if i is odd (i % 2 != 0) and if it is, we add it to the sum. If the number n is not a perfect square, there is a possibility that n/i is also a factor, hence we add this to the sum too after ensuring that it is also odd.

In the main() function, we accept an integer input from the user and check if it is greater than 0. If it isn't, we output an error message and terminate the program. If it is, we call sumOfOddFactors() with n as the argument and print out the returned sum.
