```C
#include<stdio.h>
#include<string.h>

int findMaxDiff(char *str, int n) {
    int currentDifference = 0, maxDifference = 0;
    int zeroCount = 0, oneCount = 0;

    for (int i = 0; i < n; i++) {
        if (str[i] == '0')
            zeroCount = zeroCount + 1;
        else
            oneCount = oneCount + 1;

        currentDifference = abs(zeroCount - oneCount);

        if (currentDifference > maxDifference)
            maxDifference = currentDifference;
    }

    return maxDifference;
}

int main() {
    char str[] = "11000010001";
    int n = strlen(str);

    printf("%d", findMaxDiff(str, n));

    return 0;
}
```
In the above code, a C program is created to find the maximum difference between the number of 0’s and 1’s in any sub-string of the given binary string. The binary string is passed through the main() function in the program. The findMaxDiff function takes a binary string and its length as parameters, and it returns the maximum difference between the number of 0’s and 1’s. The function treats each character of the string as one bit of a binary number. The main() function calls the findMaxDiff() function and prints the result to the console.
