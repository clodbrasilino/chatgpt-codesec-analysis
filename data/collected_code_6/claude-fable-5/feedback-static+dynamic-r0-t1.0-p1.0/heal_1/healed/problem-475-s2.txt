**Summary of fixes applied:**

1. **CWE-126 (`strlen` over-read):** Replaced `strlen` with a `bounded_strlen` helper that never reads past `MAX_KEY_LEN` bytes, so a non-NUL-terminated input cannot cause an over-read.

2. **CWE-120 (`memcpy` overflow):** The copy is now performed only after the bounded length check guarantees `len < MAX_KEY_LEN`, copying exactly `len` bytes and explicitly writing the terminating `'\0'`, so the destination buffer can never overflow.

3. **CWE-119/CWE-120 (statically-sized `key` array):** All reads and comparisons on `key` are now bounded (`strncmp` with `MAX_KEY_LEN`), and `calloc` zero-initializes the buffers, guaranteeing NUL termination even in edge cases.

4. **Defensive extras:** Added an integer-overflow guard on the allocation size and switched from `malloc` to `calloc` for zero-initialized memory.
