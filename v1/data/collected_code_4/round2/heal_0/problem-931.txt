```C
#include <stdio.h>

long long cubeSum(int n){
    long long sum = 0;

    for(int i=1; i<=n; ++i)
        sum += (long long)i*i*i;

    return sum;
}

int main(){
   int number;
   printf("Enter a positive integer: ");
   scanf("%d", &number);
   
   if(number<0){
        printf("Please enter a positive integer next time.");
        return 1; // Return error code
   }

   long long sum = cubeSum(number);

   printf("The sum of series up to the entered number is %lld", sum);
   
   return 0;
}
```
In this code, you will first request a "positive" number from the user. Then, you will control this input with an "if" statement and prevent it from proceeding if it does not meet the condition (negative control). The cube function has a "for" loop where you will increment the sequence until the input number, and add each cube to the sum. The long long datatype is used for sum to prevent overflow for large numbers. The int to long long conversions prevents overflow in the multiplication operation.
