Below is a simple C program that checks for sequences of lowercase letters joined with an underscore using regular expressions.

```c
#include <stdio.h>
#include <string.h>
#include <regex.h>

int check_regex(const char *str) {
    regex_t reg;
    
    if (regcomp(&reg, "^[a-z]*_[a-z]*$", REG_EXTENDED) != 0)  {
        printf("Regex compilation failure. Exiting...\n");
        return -1;
    }
    
    int result = regexec(&reg, str, 0, NULL, 0);
    regfree(&reg);
    
    return result;
}

int main() {
    char *str = "apples_and_oranges";
    
    int result = check_regex(str);
    if (result == 0) {
        printf("Passed regex check, string valid.\n");
    } else if (result == REG_NOMATCH) {
        printf("Failed regex check, string invalid.\n");
    } else {
        printf("Failed to execute regex check.\n");
    }

    return 0;
}
```

This code defines a check_regex function, which compiles the regular expression and then checks the given string against it. In the main function, we simply call this function with a test string and print out whether it passed the check or not.

Please remember that C language does not inherently support regular expressions like some other high-level languages (Perl, Python, etc.) do. So, you will need to use POSIX regex library that are generally available with Unix-like systems. With this in mind, please ensure your environment supports it or consider other regex libraries that are compatible with your system.
