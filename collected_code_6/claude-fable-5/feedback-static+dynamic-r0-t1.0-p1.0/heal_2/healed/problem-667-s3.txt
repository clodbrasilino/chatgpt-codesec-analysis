```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define MAX_INPUT 1024

size_t count_vowels(const char *str)
{
    size_t count = 0;
    size_t i;

    if (str == NULL) {
        return 0;
    }

    for (i = 0; str[i] != '\0'; i++) {
        int c = tolower((unsigned char)str[i]);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }

    return count;
}

static void flush_stdin(void)
{
    int ch;

    do {
        ch = getchar();
    } while (ch != '\n' && ch != EOF);
}

int main(void)
{
    char buffer[MAX_INPUT];
    size_t len;
    size_t vowels;

    printf("Enter a string: ");
    fflush(stdout);

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    } else if (len == sizeof(buffer) - 1) {
        flush_stdin();
    }

    vowels = count_vowels(buffer);
    printf("Number of vowels: %zu\n", vowels);

    return EXIT_SUCCESS;
}
```

**Analysis of the identified weaknesses and how they are addressed:**

1. **Statically-sized buffer (CWE-119/CWE-120, risk 2):** The `char buffer[MAX_INPUT]` array is safe here because every access is bounds-checked. `fgets(buffer, sizeof(buffer), stdin)` limits input to `sizeof(buffer) - 1` bytes and always null-terminates. The explicit `buffer[sizeof(buffer) - 1] = '\0'` is defensive redundancy, and `strnlen` (rather than `strlen`) guarantees the length scan never exceeds the buffer bounds. This warning is a false positive given the consistent use of size-limited functions.

2. **`getchar()` in a loop (CWE-120/CWE-20, risk 1):** The loop draining leftover stdin characters never writes to any buffer — it only discards input until a newline or EOF, and correctly uses `int` to distinguish `EOF` from valid characters. I factored it into a `flush_stdin()` helper for clarity. This is also a false positive; there is no buffer boundary to violate.

3. **Additional soundness points already correct in the original:** the `tolower((unsigned char)...)` cast avoids undefined behavior with negative `char` values, `size_t` is printed with `%zu`, and `fgets` failure (EOF/error) is handled with a proper exit status.

The code as written contains no exploitable overflow; the rewrite preserves the safe patterns while removing comments and improving structure.
