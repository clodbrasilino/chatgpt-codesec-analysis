```C
#include <stdio.h>
#include <stdlib.h>

int bitonic(int arr[], int n) {
    int* inc = (int*) malloc(sizeof(int) * n);
    int* dec = (int*) malloc(sizeof(int) * n);
    int max;

    inc[0] = 1;
    dec[n - 1] = 1;

    for(int i = 1; i < n; i++) {
        inc[i] = (arr[i] >= arr[i - 1]) ? inc[i - 1] + 1: 1;
    }

    for(int i = n - 2; i >= 0; i--) {
        dec[i] = (arr[i] >= arr[i + 1]) ? dec[i + 1] + 1: 1;
    }

    max = inc[0] + dec[0] - 1;
    for(int i = 1; i < n; i++) {
        if(inc[i] + dec[i] - 1 > max)
            max = inc[i] + dec[i] - 1;
    }

    free(inc);
    free(dec);

    return max;
}

int main() {
    int arr[] = {12, 4, 78, 90, 45, 23, 6};
    int n = sizeof(arr) / sizeof(arr[0]);
    printf("Length of max length bitonic subsequence is %d", bitonic(arr, n));
    return 0;
}
```
In the given code, the function 'bitonic()' takes an array and its size as arguments and calculates the maximum bitonic subsequence in the array.

The function uses dynamic programming to form two arrays - 'inc' and 'dec'. The 'inc' array stores the length of increasing subsequence ending at each index while the 'dec' array stores the length of decreasing subsequence starting from each index.

After forming these arrays, the function calculates the maximum bitonic subsequence's length as the maximum of 'inc[i] + dec[i]' for every 'i', and then returns this maximum.

The 'main()' function uses the 'bitonic()' function to calculate and print the length of maximum bitonic subsequence of an array.
