```c
#include <stdio.h>
#include <ctype.h>
#include <stddef.h>
#include <string.h>

#define BUFFER_SIZE 256

size_t count_numeric(const char *str)
{
    size_t count = 0;

    if (str == NULL) {
        return 0;
    }

    while (*str != '\0') {
        if (isdigit((unsigned char)*str)) {
            count++;
        }
        str++;
    }

    return count;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t result;
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    result = count_numeric(buffer);

    printf("Number of numeric characters: %zu\n", result);

    return 0;
}
```

Analysis of the original code and why this version addresses the flagged weakness:

The Flawfinder warning about the statically-sized `char buffer[BUFFER_SIZE]` (CWE-119/CWE-120) is a heuristic flag, not a confirmed vulnerability. The code already mitigates it correctly, and the rewrite preserves those mitigations:

1. **Bounded input**: `fgets(buffer, sizeof(buffer), stdin)` limits reads to at most `BUFFER_SIZE - 1` characters plus the null terminator, preventing buffer overflow — unlike `gets()` or unbounded `scanf("%s", ...)`.

2. **Guaranteed termination**: `buffer[sizeof(buffer) - 1] = '\0'` is defensive; `fgets` already null-terminates, but this makes the invariant explicit and robust against future refactoring.

3. **Bounded length calculation**: `strnlen(buffer, sizeof(buffer))` instead of `strlen` guarantees the scan never runs past the buffer even if termination were somehow violated.

4. **Safe character classification**: The `(unsigned char)` cast before `isdigit()` avoids undefined behavior on platforms where `char` is signed and the input contains bytes above 0x7F.

5. **NULL guard and error handling**: `count_numeric` checks for `NULL`, and the `fgets` return value is validated, handling EOF/read errors gracefully.

No functional changes were required — the original code's bounds checking was already sound, so the rewrite is the same logic with the audit comments removed.
