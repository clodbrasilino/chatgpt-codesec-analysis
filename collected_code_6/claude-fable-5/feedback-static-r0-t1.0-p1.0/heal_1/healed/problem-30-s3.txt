```c
#include <stdio.h>
#include <string.h>

#define BUFFER_SIZE 1024

unsigned long count_substrings(const char *str, size_t max_len)
{
    unsigned long freq[256] = {0};
    unsigned long total = 0;
    size_t i;
    size_t len;

    if (str == NULL)
    {
        return 0;
    }

    len = strnlen(str, max_len);

    for (i = 0; i < len; i++)
    {
        freq[(unsigned char)str[i]]++;
    }

    for (i = 0; i < 256; i++)
    {
        total += (freq[i] * (freq[i] + 1)) / 2;
    }

    return total;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    unsigned long result;
    size_t len;

    if (fgets(buffer, sizeof(buffer), stdin) == NULL)
    {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n')
    {
        buffer[len - 1] = '\0';
    }

    result = count_substrings(buffer, sizeof(buffer));

    if (printf("%lu\n", result) < 0)
    {
        return 1;
    }

    return 0;
}
```

**Key changes addressing the flagged weaknesses:**

1. **CWE-126 (`strlen` over-read):** Both calls to `strlen` were replaced with `strnlen`, which takes an explicit maximum length. Even if a string were somehow not null-terminated, the read is bounded and cannot run past the buffer.

2. **CWE-119/CWE-120 (statically-sized buffer):** The buffer size is defined once via `BUFFER_SIZE` and consistently referenced through `sizeof(buffer)`. `fgets` already limits input to the buffer size, and an explicit `buffer[sizeof(buffer) - 1] = '\0';` guarantees null-termination defensively before any string operation.

3. **Defense in depth:** `count_substrings` now receives the maximum buffer length as a parameter, so it never assumes termination and cannot over-read regardless of caller behavior. The `NULL` check on `str` is retained.

Note: `strnlen` is POSIX (and C23 via `string.h`); if strict C89/C99 portability is required, a small bounded-scan helper loop can replace it with identical safety guarantees.
