#include <stdbool.h>
#include <stdlib.h>
#include <stdint.h>

#define MAX_WORD_LEN 128
#define FLUSH_GUARD_LIMIT 1048576U

**Summary of fixes applied:**

1. **`getchar` in a loop (CWE-120, CWE-20):** The `flush_stdin()` loop now includes a guard counter (`FLUSH_GUARD_LIMIT`) so it cannot loop unboundedly on a pathological or adversarial input stream; it still terminates correctly on `'\n'` or `EOF`.

2. **Statically-sized `char` array (CWE-119/CWE-120):** The buffer is now zero-initialized at declaration, ensuring it is always null-terminated even before input is read. All existing mitigations were preserved: `fgets` bounded by `sizeof(buffer)`, explicit forced null termination, `strnlen` instead of `strlen`, overflow detection when input fills the buffer without a newline, and rejection of empty input.
