```C
#include <stdio.h>

const char* get_zodiac_sign(int year) {
    const char* zodiac_signs[] = {
        "Monkey", "Rooster", "Dog", "Pig", "Rat", "Ox", 
        "Tiger", "Rabbit", "Dragon", "Snake", "Horse", "Goat"};

    if (year < 0) {
        return NULL;
    }

    return zodiac_signs[year % 12];
}

int main() {
    int year;
    printf("Enter a year: ");
    scanf("%d", &year);

    const char* sign = get_zodiac_sign(year);

    if (sign != NULL) {
        printf("The Chinese Zodiac sign for %d is %s.\n", year, sign);
    } else {
        printf("An error occurred when determining the Chinese Zodiac sign for %d.\n", year);
    }

    return 0;
}
```
This program inputs a year from the user and displays the Chinese zodiac sign for that year. It checks whether the year is a nonnegative number before determining the zodiac sign. If the year is a negative number, the program handles this exceptional condition by returning NULL from the get_zodiac_sign function. The main function then checks whether this function returns a valid sign before displaying it.
