```c
#include <stdio.h>
#include <string.h>

int match(const char *str) {
    const char *s = str;
    if (*s != 'a') return 0;
    s++;

    while (*s != '\0') {
        if (*s != 'b') return 0;
        s++;
    }
    return 1;
}

int main(int argc, char *argv[]) {
    if (argc != 2) {
        printf("Usage: %s <string>\n", argv[0]);
        return 1;
    }
    
    printf("Does the string follow the rules? %s\n", match(argv[1]) ? "Yes" : "No");
    return 0;
}
```
The main function of this simple code example accepts one argument, a string, and then checks if the string adheres to the "a followed by one or more b's" rule. If the first character of the string is not 'a', or if any of the subsequent characters is not 'b', the match function returns 0 (false). Else, it returns 1 (true).
