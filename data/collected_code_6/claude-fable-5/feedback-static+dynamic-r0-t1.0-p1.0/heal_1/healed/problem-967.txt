```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>
#include <stdlib.h>

#define MAX_LEN 256

static int contains_all_vowels(const char *str, size_t max_len)
{
    int found[5] = {0, 0, 0, 0, 0};
    size_t i;

    if (str == NULL) {
        return 0;
    }

    for (i = 0; i < max_len && str[i] != '\0'; i++) {
        int c = tolower((unsigned char)str[i]);
        switch (c) {
        case 'a':
            found[0] = 1;
            break;
        case 'e':
            found[1] = 1;
            break;
        case 'i':
            found[2] = 1;
            break;
        case 'o':
            found[3] = 1;
            break;
        case 'u':
            found[4] = 1;
            break;
        default:
            break;
        }
    }

    return found[0] && found[1] && found[2] && found[3] && found[4];
}

int main(void)
{
    char buffer[MAX_LEN];
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    if (contains_all_vowels(buffer, sizeof(buffer))) {
        printf("Accepted: the string contains all vowels\n");
    } else {
        printf("Rejected: the string does not contain all vowels\n");
    }

    return EXIT_SUCCESS;
}
```

**Key changes addressing the identified weaknesses:**

1. **CWE-126 (over-read via `strlen`)**: Replaced `strlen` with `strnlen(buffer, sizeof(buffer))` in `main`, and in `contains_all_vowels` the loop is now bounded by an explicit `max_len` parameter in addition to checking for the null terminator — so even a non-terminated buffer cannot cause an over-read.

2. **CWE-119/CWE-120 (statically-sized array)**: The buffer is still fixed-size (that's fine for `fgets`), but I added an explicit forced null-termination (`buffer[sizeof(buffer) - 1] = '\0';`) as defense-in-depth, guaranteeing the buffer is always a valid C string regardless of input behavior. `fgets` is already called with `sizeof(buffer)`, which prevents overflow.

3. **API hardening**: `contains_all_vowels` now takes a length bound, making it safe to call with any buffer whose capacity is known, and `static` limits its linkage scope.

Note: `strnlen` is POSIX / C23; if you must target strict C89/C99, replace it with a small bounded loop or `memchr(buffer, '\0', sizeof(buffer))`.
