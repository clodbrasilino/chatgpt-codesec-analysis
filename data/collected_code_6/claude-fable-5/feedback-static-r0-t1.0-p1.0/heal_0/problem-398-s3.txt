```c
#include <stdio.h>
#include <stdlib.h>

int sum_of_digits(int number)
{
    int sum = 0;
    unsigned int value;

    if (number < 0) {
        value = (unsigned int)(-(long)number);
    } else {
        value = (unsigned int)number;
    }

    while (value > 0U) {
        sum += (int)(value % 10U);
        value /= 10U;
    }

    return sum;
}

int main(void)
{
    int numbers[] = { 123, 456, 789, 0, -45, 9999 };
    size_t count = sizeof(numbers) / sizeof(numbers[0]);
    size_t i;

    for (i = 0U; i < count; i++) {
        int result = sum_of_digits(numbers[i]);
        if (printf("Sum of digits of %d is %d\n", numbers[i], result) < 0) {
            return EXIT_FAILURE;
        }
    }

    return EXIT_SUCCESS;
}
```

This implementation is careful in a few important ways:

1. **Negative number handling**: The negation is done through a `long` cast before converting to `unsigned int`, which safely handles `INT_MIN` without triggering signed integer overflow (undefined behavior).

2. **Unsigned arithmetic**: The digit extraction loop operates on an unsigned type, so the modulo and division operations are always well-defined.

3. **Checked I/O**: The return value of `printf` is checked, and the program exits with `EXIT_FAILURE` if output fails, rather than silently ignoring the error condition.

4. **No dynamic resources**: The program uses only automatic storage, so there are no allocation lifetime issues, leaks, or use-after-free possibilities.

5. **Standards adherence**: `main` uses the correct `int main(void)` signature, returns standard exit codes from `<stdlib.h>`, and the array size is computed with `sizeof` rather than a hardcoded constant, keeping the loop bound tied to the actual data.
