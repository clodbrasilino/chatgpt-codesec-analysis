```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

double lateral_surface_area(double radius, double height)
{
    return 2.0 * M_PI * radius * height;
}

int main(void)
{
    double radius;
    double height;
    double area;

    printf("Enter the radius of the cylinder: ");
    if (scanf("%lf", &radius) != 1) {
        fprintf(stderr, "Error: invalid input for radius.\n");
        return EXIT_FAILURE;
    }

    printf("Enter the height of the cylinder: ");
    if (scanf("%lf", &height) != 1) {
        fprintf(stderr, "Error: invalid input for height.\n");
        return EXIT_FAILURE;
    }

    if (radius < 0.0 || height < 0.0) {
        fprintf(stderr, "Error: radius and height must be non-negative.\n");
        return EXIT_FAILURE;
    }

    if (!isfinite(radius) || !isfinite(height)) {
        fprintf(stderr, "Error: radius and height must be finite values.\n");
        return EXIT_FAILURE;
    }

    area = lateral_surface_area(radius, height);

    if (!isfinite(area)) {
        fprintf(stderr, "Error: computation resulted in overflow.\n");
        return EXIT_FAILURE;
    }

    printf("Lateral surface area of the cylinder: %.6f\n", area);

    return EXIT_SUCCESS;
}
```

**Key safety measures in this implementation:**

- **CWE-703 avoidance:** Every `scanf` return value is checked to ensure input was successfully parsed before use. The result of the computation is validated with `isfinite()` to detect overflow to infinity.

- **CWE-664 avoidance:** No dynamically allocated resources are used, so there are no lifetime management issues. All variables are properly initialized before use through validated input.

- **CWE-710 avoidance:** The code adheres to standards by using `int main(void)`, returning `EXIT_SUCCESS`/`EXIT_FAILURE` from `<stdlib.h>`, validating domain constraints (non-negative dimensions), and writing error messages to `stderr` rather than `stdout`.

**Note:** If your compiler doesn't define `M_PI` (it's POSIX, not strictly ISO C), compile with `-D_USE_MATH_DEFINES` on MSVC or add `#define _GNU_SOURCE` before includes on some systems, or define the constant yourself as `3.14159265358979323846`.
