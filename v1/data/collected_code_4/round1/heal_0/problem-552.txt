```C
#include <stdbool.h>
#include <float.h>
#include <stdio.h>

bool checkIsLinear(float* arr, int numElements) {
    if(numElements <= 1){
        return true;
    }

    float ratio = arr[1] - arr[0];
    for(int idx = 2; idx < numElements; ++idx) {
        if(arr[idx] - arr[idx-1] != ratio) {
            return false;
        }
    }

    return true;
}

int main() {
    float array1[] = {1, 3, 5, 7};
    float array2[] = {1, 2, 4, 8};

    if (checkIsLinear(array1, sizeof(array1) / sizeof(array1[0]))) {
        printf("Array1 is linear.\n");
    } else {
        printf("Array1 is not linear.\n");
    }

    if (checkIsLinear(array2, sizeof(array2) / sizeof(array2[0]))) {
        printf("Array2 is linear.\n");
    } else {
        printf("Array2 is not linear.\n");
    }

    return 0;
}
```
Given function `checkIsLinear` checks whether a sequence (input as a float array) has constant differences between successive elements (i.e., follows a linear sequence). It uses an early return principle for efficiency and avoids improper use of memory resources. It properly handles edge cases such as sequences of length 0 or 1. The `main` function demonstrates the use of this function. Please note that it assumes `array1` and `array2` represent sequences of real numbers and not complex numbers. Also, it uses a simple floating-point comparison. Using a tolerance range instead of direct equality might be more accurate for real-world applications with floating-point numbers, as floating-point arithmetic is not precise due to rounding errors.
