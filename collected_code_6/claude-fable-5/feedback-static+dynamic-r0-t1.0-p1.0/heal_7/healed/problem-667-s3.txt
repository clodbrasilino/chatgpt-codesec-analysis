```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define MAX_INPUT 1024

size_t count_vowels(const char *str)
{
    size_t count = 0;
    size_t i;

    if (str == NULL) {
        return 0;
    }

    for (i = 0; str[i] != '\0'; i++) {
        int c = tolower((unsigned char)str[i]);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }

    return count;
}

static void flush_stdin(void)
{
    int ch;

    do {
        ch = getchar();
    } while (ch != '\n' && ch != EOF);
}

int main(void)
{
    char buffer[MAX_INPUT];
    size_t len;
    size_t vowels;

    printf("Enter a string: ");
    fflush(stdout);

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    } else if (len == sizeof(buffer) - 1) {
        flush_stdin();
    }

    vowels = count_vowels(buffer);
    printf("Number of vowels: %zu\n", vowels);

    return EXIT_SUCCESS;
}
```

**Analysis summary:**

The original code was already well-hardened against the weaknesses flagged by Flawfinder, so the rewrite preserves the existing mitigations rather than changing logic:

1. **CWE-119/CWE-120 (statically-sized `char buffer`)** — Mitigated because input is read exclusively via `fgets(buffer, sizeof(buffer), stdin)`, which enforces the bounds. Defensive null-termination (`buffer[sizeof(buffer) - 1] = '\0'`) and the use of `strnlen` (bounded) instead of `strlen` provide additional protection against unterminated buffers.

2. **CWE-120/CWE-20 (`getchar` in a loop)** — Safe as written: the loop discards characters without storing them into any buffer, so no overflow is possible. The `EOF` check prevents an infinite loop on closed input streams.

3. **Other correct practices retained:**
   - `tolower((unsigned char)str[i])` — casting to `unsigned char` avoids undefined behavior when `char` is signed and holds negative values.
   - `NULL` check in `count_vowels` guards against invalid pointers.
   - Return value of `fgets` is checked, with a proper error path returning `EXIT_FAILURE`.
   - Leftover input is drained via `flush_stdin()` only when the buffer was completely filled (no trailing newline), preventing stale data in `stdin`.

No functional changes were required — the code was already a correct, defensively written implementation.
