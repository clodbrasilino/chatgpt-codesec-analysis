Here is a C program that finds the largest subset of an array where each pair is divisible.

```c
#include <stdio.h>

void findLargestDivisibleSubset(int arr[], int n) {
    int largest = 0;
    int index = -1;
    int divCount[n];
    int previous[n];
    for (int i=0; i<n; i++) {
        divCount[i] = 1;
        previous[i] = -1;
        for (int j=0; j<i; j++) {
            if (arr[i] % arr[j] == 0) {
                if (1 + divCount[j] > divCount[i]) {
                    divCount[i] = 1 + divCount[j];
                    previous[i] = j;
                }
            }
        }
        if (divCount[i] > largest) {
            largest = divCount[i];
            index = i;
        }
    }
    while (index != -1) {
        printf("%d ", arr[index]);
        index = previous[index];
    }
}

int main() {
    int arr[] = {18, 1, 3, 6, 13, 17};
    int n = sizeof(arr)/sizeof(arr[0]);
    findLargestDivisibleSubset(arr, n);
    return 0;
}
```

In this program, we create two auxiliary arrays, `divCount[]` and `previous[]`. `divCount[i]` stores size of the largest divisible subset where `arr[i]` is the largest element. `previous[i]` stores the index of the previous number in the largest divisible subset for `arr[i]`.

Then we traverse through the `arr[]` using nested loops, if `arr[i]` is divisible by `arr[j]`, and updating `divCount[]` and `previous[]` if `&divCount[j] + 1 > divCount[i]`. After this, we update `largest` and `index` if `divCount[i] >largest`.

In the end, we print the largest divisible subset.
