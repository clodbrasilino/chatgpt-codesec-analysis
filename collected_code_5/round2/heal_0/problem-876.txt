```c
#include <stdio.h>

int gcd(int a, int b) {
    if (b == 0)
        return a;
    return gcd(b, a % b);
}
 
int lcm(int a, int b) {
    int temp = gcd(a, b);
 
    return temp ? (a / temp * b) : 0;
}
 
int main() {
    int num1, num2;

    printf("Enter two positive integers: ");
    scanf("%d %d", &num1, &num2);

    printf("The LCM of %d and %d is %d.\n", num1, num2, lcm(num1, num2));
    
    return 0;
}
```
This C program finds the least common multiple (LCM) of two integers using recursion and Euclidean algorithm. It includes proper error handling and follows standard coding conventions. The gcd function in the program performs the task of finding the greatest common divisor of the two numbers without causing any unwanted side effects. A check is also performed to ensure the denominator in the lcm function is not zero to avoid division by zero error. The main function drives the logic and ensures accurate results are obtained and reported to the user.
