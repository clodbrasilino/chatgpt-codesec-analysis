```c
#include <stdio.h>
#include <stdlib.h>

int last_two_digits_of_factorial(int n)
{
    int result = 1;
    int i;

    if (n < 0) {
        return -1;
    }

    if (n >= 10) {
        return 0;
    }

    for (i = 2; i <= n; i++) {
        result = (result * i) % 100;
    }

    return result;
}

int main(void)
{
    int number;
    int digits;

    printf("Enter a non-negative integer: ");

    if (scanf("%d", &number) != 1) {
        fprintf(stderr, "Error: invalid input.\n");
        return EXIT_FAILURE;
    }

    digits = last_two_digits_of_factorial(number);

    if (digits < 0) {
        fprintf(stderr, "Error: factorial is not defined for negative numbers.\n");
        return EXIT_FAILURE;
    }

    printf("Last two digits of %d! are: %02d\n", number, digits);

    return EXIT_SUCCESS;
}
```

A few notes on the design:

- **Modular arithmetic** is used (`% 100`) so the computation never overflows, regardless of how large `n` is — this addresses CWE-703 by preventing integer overflow.
- For any `n >= 10`, the factorial contains at least two factors of 2 and two factors of 5, so the last two digits are always `00`. The function short-circuits this case for correctness and efficiency.
- The return value of `scanf` is **checked** before using the input, and negative inputs are rejected with a proper error path (CWE-703).
- Resources are handled cleanly with standard exit codes and `stderr` for errors (CWE-664, CWE-710).
- The output uses `%02d` so results like `2` print correctly as `02` when appropriate.
