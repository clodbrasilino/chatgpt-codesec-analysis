int min_swaps(const char *s1, const char *s2)
{

    size_t len2;
    size_t i;

    }

    len2 = strlen(s2);

    if (len1 != len2) {
        return -1;
    }

    for (i = 0; i < len1; i++) {

            }

    }

    return count10;
}

**How the code addresses it:**

1. **Error translation layer** — `format_result()` acts as the boundary between the internal error convention (`-1`) and user-facing output. Any negative result from `min_swaps()` is converted to the string `"Not Possible"` before it ever reaches `printf`. The raw `-1` is never printed.

2. **Fallback in `main()`** — even if `format_result()` itself fails (e.g., truncation or `snprintf` error), `main()` prints `"Not Possible"` directly rather than exposing an error code.
