```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>

static long long count_triangles(long long n)
{
    long long result;

    if (n < 0)
    {
        return -1LL;
    }

    if (n > 1000000LL)
    {
        return -1LL;
    }

    result = (n * (n + 2LL) * (2LL * n + 1LL)) / 8LL;

    return result;
}

int main(void)
{
    long long n;
    long long total;
    int scanned;

    printf("Enter the side length of the equilateral triangle: ");

    scanned = scanf("%lld", &n);

    if (scanned != 1)
    {
        fprintf(stderr, "Error: invalid input.\n");
        return EXIT_FAILURE;
    }

    total = count_triangles(n);

    if (total < 0LL)
    {
        fprintf(stderr, "Error: input out of supported range.\n");
        return EXIT_FAILURE;
    }

    printf("Maximum number of equilateral triangles: %lld\n", total);

    return EXIT_SUCCESS;
}
```

This solves the classic problem of counting **all** equilateral triangles (both upward and downward pointing, of every size) inside an equilateral triangle of side length `n` subdivided into unit triangles.

**Key points regarding the CWEs avoided:**

- **CWE-703**: The return value of `scanf` is explicitly checked, and the function validates that `n` is non-negative before computing, returning an error sentinel handled by the caller.
- **CWE-664**: No dynamic resources (heap memory, file handles) are allocated, so there is nothing to leak or misuse across a lifetime; all data lives on the stack with well-defined scope.
- **CWE-710**: The code uses `EXIT_SUCCESS`/`EXIT_FAILURE`, `static` linkage for the helper, explicit `void` parameter lists, consistent `long long` arithmetic with `LL` suffixes to prevent silent integer overflow from `int` promotion, and an upper bound check (`n > 1000000`) guaranteeing the product `n * (n+2) * (2n+1)` stays well within `long long` range.

The closed-form formula used is `⌊n(n+2)(2n+1)/8⌋`, which counts upward triangles `n(n+1)(n+2)/6` plus downward triangles in a single expression.
