int min_swaps(const char *s1, const char *s2)

The fix reads both strings from `stdin` using `fgets` with bounded buffers, then strips trailing newline/carriage-return characters.

This explains the `<no output>` / expected-value mismatch even for the case that would have matched logically. The fix prints just the integer followed by a newline, and keeps the exact string `Not Possible` for the failure path.

The `min_swaps` function itself was left intact — its logic is sound: it validates for `NULL`, over-length inputs, unequal lengths, and non-binary characters, and correctly determines that a swap-based transformation is only possible when the `1→0` and `0→1` mismatch counts are equal (each swap resolves one of each), returning that count as the minimum.
