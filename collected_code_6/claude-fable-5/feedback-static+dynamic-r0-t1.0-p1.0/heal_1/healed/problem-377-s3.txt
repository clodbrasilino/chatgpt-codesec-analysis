```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define BUFFER_SIZE 256

void remove_char(char *str, char c)
{
    size_t read_idx = 0;
    size_t write_idx = 0;

    if (str == NULL) {
        return;
    }

    while (str[read_idx] != '\0') {
        if (str[read_idx] != c) {
            str[write_idx] = str[read_idx];
            write_idx++;
        }
        read_idx++;
    }
    str[write_idx] = '\0';
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    const char *source = "hello world, hello everyone";
    char target = 'l';
    size_t source_len;
    int written;

    source_len = strnlen(source, BUFFER_SIZE);
    if (source_len >= sizeof(buffer)) {
        fprintf(stderr, "Source string too long\n");
        return EXIT_FAILURE;
    }

    written = snprintf(buffer, sizeof(buffer), "%s", source);
    if (written < 0 || (size_t)written >= sizeof(buffer)) {
        fprintf(stderr, "Failed to copy source string\n");
        return EXIT_FAILURE;
    }

    printf("Original string: %s\n", buffer);
    remove_char(buffer, target);
    printf("After removing '%c': %s\n", target, buffer);

    return EXIT_SUCCESS;
}
```

**Key changes made to address the identified weaknesses:**

1. **CWE-126 (strlen over-read):** Replaced `strlen()` with `strnlen()`, which bounds the read to `BUFFER_SIZE` characters, preventing an over-read if the source string were ever not null-terminated.

2. **CWE-120 (strcpy buffer overflow):** Replaced `strcpy()` with `snprintf()`, which guarantees the destination is never overflowed and is always null-terminated. The return value is checked to detect truncation or encoding errors, providing a defense-in-depth safeguard on top of the length check.

3. **CWE-119/CWE-120 (statically-sized array):** The buffer size is now a named constant (`BUFFER_SIZE`), used consistently for both the bounds check and the copy operation, eliminating the risk of size mismatches if the code is later modified.

4. **remove_char remains safe as-is:** It already checks for `NULL`, only shrinks the string in place (write index never exceeds read index), and properly re-terminates the result, so no changes were needed there.
