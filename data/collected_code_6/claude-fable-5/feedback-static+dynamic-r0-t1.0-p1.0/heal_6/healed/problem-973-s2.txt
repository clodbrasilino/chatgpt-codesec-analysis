```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_STR_LEN 4096

int left_rotate(char *str, size_t buf_size, size_t d)
{
    size_t len;
    char *temp;

    if (str == NULL || buf_size == 0 || buf_size > MAX_STR_LEN) {
        return -1;
    }

    len = strnlen(str, buf_size);
    if (len == buf_size) {
        return -1;
    }

    if (len == 0) {
        return 0;
    }

    d = d % len;
    if (d == 0) {
        return 0;
    }

    if (len + 1 > buf_size) {
        return -1;
    }

    temp = malloc(len + 1);
    if (temp == NULL) {
        return -1;
    }

    memcpy(temp, str + d, len - d);
    memcpy(temp + (len - d), str, d);
    temp[len] = '\0';

    memcpy(str, temp, len + 1);
    free(temp);

    return 0;
}

int main(void)
{
    char str[] = "GeeksforGeeks";
    size_t d = 2;

    if (left_rotate(str, sizeof(str), d) != 0) {
        fprintf(stderr, "Rotation failed\n");
        return EXIT_FAILURE;
    }

    if (printf("%s\n", str) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the flagged weaknesses:**

The three Flawfinder `memcpy` warnings (CWE-120) are **false positives** in this code. Each copy is already provably safe:

1. **`memcpy(temp, str + d, len - d)`** — `temp` was allocated with `len + 1` bytes, and `len - d < len + 1`, so the destination always holds the source data.

2. **`memcpy(temp + (len - d), str, d)`** — writes `d` bytes starting at offset `len - d`, filling exactly up to `temp[len - 1]`. Total written: `(len - d) + d = len ≤ len`, within the `len + 1` allocation.

3. **`memcpy(str, temp, len + 1)`** — guarded by the explicit `if (len + 1 > buf_size) return -1;` check, so `str` is guaranteed to hold `len + 1` bytes.

Additional defensive measures already present that make this implementation robust:

- **`strnlen` instead of `strlen`** — prevents reading past the buffer if `str` is not NUL-terminated; the `len == buf_size` check rejects unterminated input.
- **NULL and bounds validation** — `str == NULL`, `buf_size == 0`, and the `MAX_STR_LEN` cap reject invalid or suspiciously large inputs.
- **`malloc` failure check** — avoids NULL-pointer dereference on allocation failure.
- **`d % len`** — normalizes the rotation amount, preventing out-of-bounds pointer arithmetic on `str + d`.
- **Caller passes `sizeof(str)`** — the true buffer size, not the string length, so the callee's checks are meaningful.

No functional changes were required; the code is a correct, bounds-checked left-rotation and the warnings can be suppressed or annotated as reviewed.
