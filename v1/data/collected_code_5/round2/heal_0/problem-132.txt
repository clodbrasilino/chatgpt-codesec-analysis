```C
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int x;
    int y;
} Tuple;

char* convertTupleToString(Tuple* t){
    char* result;
    if(t != NULL){
        result = (char*) malloc(1000 * sizeof(char));
        if(result != NULL){
            sprintf(result, "(%d, %d)", t->x, t->y);
        }else{
            printf("Memory allocation failed.\n");
            return NULL;
        }
    }else{
        printf("Tuple is NULL.\n");
        return NULL;
    }
    return result;
}

int main(){
    Tuple t = {5, 10};
    char* tupleStr = convertTupleToString(&t);
    if(tupleStr != NULL){
        printf("Tuple as string : %s\n", tupleStr);
        free(tupleStr);
    }
    return 0;
}
```
1) The function 'convertTupleToString' has a pointer to Tuple as input. This function returns a pointer to a string that represents the tuple.

2) Inside this function, checks are made to ensure that the pointer is not NULL and that memory allocation for the string is successful.

3) The main function creates a Tuple, converts it to a string using 'convertTupleToString',  prints the string, and then frees the memory. It ensures the proper management of resources.

4) This code adheres to coding standards, has correct indentation, and no wastage of resources. It also handles exceptions (null pointers and failed memory allocations) properly.
