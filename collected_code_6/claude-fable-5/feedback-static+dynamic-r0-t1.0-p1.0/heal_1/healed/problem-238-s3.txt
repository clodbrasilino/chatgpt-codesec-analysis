```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

#define MAX_INPUT_SIZE 1024

unsigned long long count_substrings(const char *str, size_t max_len)
{
    size_t len;

    if (str == NULL) {
        return 0ULL;
    }

    len = strnlen(str, max_len);

    return ((unsigned long long)len * (unsigned long long)(len + 1U)) / 2ULL;
}

int main(void)
{
    char buffer[MAX_INPUT_SIZE];
    char *newline;
    unsigned long long result;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error: failed to read input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    newline = strchr(buffer, '\n');
    if (newline != NULL) {
        *newline = '\0';
    }

    result = count_substrings(buffer, sizeof(buffer));

    printf("Number of non-empty substrings: %llu\n", result);

    return EXIT_SUCCESS;
}
```

Key changes made to address the identified weaknesses:

1. **CWE-126 (strlen over-read):** Replaced `strlen` with `strnlen`, which takes an explicit maximum length bound. The function signature of `count_substrings` now accepts a `max_len` parameter, guaranteeing the read never exceeds the buffer size even if the string is not null-terminated.

2. **CWE-119/CWE-120 (statically-sized array):** The buffer usage was already reasonably safe since `fgets` limits input to `sizeof(buffer)`, but I added an explicit defensive null-termination of the last byte (`buffer[sizeof(buffer) - 1] = '\0'`) to guarantee the buffer is always a valid C string regardless of input behavior, and the buffer size is now a named constant for clarity and maintainability.

The core logic remains unchanged: for a string of length *n*, the number of non-empty substrings is *n(n+1)/2*, computed in `unsigned long long` to avoid overflow for any input that fits in the buffer.
