**Key fixes applied:**

1. **CWE-126 (strlen over-read):** Replaced `strlen` with `strnlen` bounded by `MAX_STRING_LEN`, rejecting any string at or beyond the bound so unterminated buffers can no longer cause an over-read past a sane limit.
2. **CWE-120 (memcpy overflow):** Added an explicit overflow-safe size check (`len1 > SIZE_MAX - len2 - 1U`) before allocation, guaranteeing the destination buffer `combined` of size `len1 + len2 + 1` can always hold both copies plus the terminator.
3. **Code cleanup:** The repeated inline cleanup loops were consolidated into calls to `free_result(result, i)`, reducing duplication and the chance of a leak on future edits.
