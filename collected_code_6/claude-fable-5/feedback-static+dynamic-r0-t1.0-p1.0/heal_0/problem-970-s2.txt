```c
#include <stdio.h>
#include <stdlib.h>

int min(int a, int b);

int min(int a, int b)
{
    return (a < b) ? a : b;
}

int main(void)
{
    int x;
    int y;

    printf("Enter two integers: ");
    if (scanf("%d %d", &x, &y) != 2) {
        fprintf(stderr, "Error: invalid input.\n");
        return EXIT_FAILURE;
    }

    printf("Minimum: %d\n", min(x, y));

    return EXIT_SUCCESS;
}
```

Key points on how this avoids the listed weaknesses:

- **CWE-703 (Improper Check or Handling of Exceptional Conditions):** The return value of `scanf` is checked to ensure both integers were successfully read; on failure, an error is reported to `stderr` and the program exits with a failure status.
- **CWE-664 (Improper Control of a Resource Through its Lifetime):** No dynamic memory, file handles, or other resources are allocated, so there is nothing to leak or misuse; all variables are stack-local with well-defined lifetimes.
- **CWE-710 (Improper Adherence to Coding Standards):** The code uses `int main(void)`, explicit function prototypes, `EXIT_SUCCESS`/`EXIT_FAILURE` return codes, and avoids implicit declarations or undefined behavior.
