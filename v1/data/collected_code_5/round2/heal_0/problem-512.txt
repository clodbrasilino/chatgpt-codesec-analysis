Sure, but please note that in C, there are no built-in tuples or nested tuples like in Python. However, one way to solve the problem is by using structures and array of structures to simulate tuples. I'll write a simple solution to count the frequency of an integer in an array of structures where each structure represents a tuple. It's a simplified example but hopefully it makes the idea clear.

```c
#include <stdio.h>

#define SIZE 10

// Define structure (tuple) to hold two elements
struct Tuple {
    int a;
    int b;
};

// Function to count frequency
int countFrequency(struct Tuple arr[], int num) {
    int count = 0;
    for (int i = 0; i < SIZE; ++i) {
        if (arr[i].a == num || arr[i].b == num) {
            count++;
        }
    }
    return count;
}

// Main function
int main(void) {
    struct Tuple arr[SIZE] = {{1, 2}, {3, 4}, {5, 2}, {1, 6}, {7, 4}, {1, 8}, {3, 1}, {9, 4}, {1, 2}, {5, 2}};

    int num = 1;
    printf("Frequency of %d is %d\n", num, countFrequency(arr, num));

    return 0;
}
```
In the above C program, Tuple is a structure with two integer data types a and b. `countFrequency` function is used to count the frequency of an element in the given array. The `main` function creates an array of Tuples and calls `countFrequency` function to count the frequency of number 1. Note that this is a simplification. If you want to have an arbitrary number of elements in a tuple or have different types of elements in a tuple (as in Python), it would be more complicated in C and you would probably have to implement your own data structures or use the ones from a library.
