```c
#include <stdio.h>
#include <stdlib.h>

int count_divisors(int n);

int count_divisors(int n)
{
    int count = 0;
    int i;

    if (n == 0) {
        return 0;
    }

    if (n < 0) {
        if (n == -2147483647 - 1) {
            return 0;
        }
        n = -n;
    }

    for (i = 1; (long long)i * i <= (long long)n; i++) {
        if (n % i == 0) {
            count++;
            if (i != n / i) {
                count++;
            }
        }
    }

    return count;
}

int main(void)
{
    int n;
    int result;

    printf("Enter an integer: ");
    if (scanf("%d", &n) != 1) {
        fprintf(stderr, "Error: invalid input\n");
        return EXIT_FAILURE;
    }

    result = count_divisors(n);

    if (result == 0) {
        fprintf(stderr, "Error: divisor count is undefined for this input\n");
        return EXIT_FAILURE;
    }

    printf("Number of divisors of %d: %d\n", n, result);

    return EXIT_SUCCESS;
}
```

**Key design decisions:**

1. **CWE-703 (Improper Check or Handling of Exceptional Conditions):** The return value of `scanf` is checked to ensure valid input was actually read. Edge cases like `0` (infinite divisors, undefined) and `INT_MIN` (whose negation overflows) are explicitly handled rather than allowed to produce undefined behavior.

2. **CWE-664 (Improper Control of a Resource Through its Lifetime):** No dynamic memory or file handles are used, so there are no resources to leak; `stdin`/`stdout`/`stderr` are managed by the runtime.

3. **CWE-710 (Improper Adherence to Coding Standards):** The function is declared before use, `main` uses the standard `int main(void)` signature, `EXIT_SUCCESS`/`EXIT_FAILURE` are used for portable exit codes, and the loop condition uses `(long long)i * i` to prevent signed integer overflow when `i * i` approaches `INT_MAX`.

The algorithm runs in O(√n) time by counting divisor pairs: for each divisor `i` found up to √n, its complement `n / i` is also counted, with care taken not to double-count perfect square roots.
