```C
#include <stdio.h>

int sumRepeatedElements(int arr[], int size) {
    int sum = 0;
    for (int i = 0; i < size; i++) {
        for (int j = i + 1; j < size; j++) {
            if (arr[i] == arr[j]) {
                sum += arr[i];
                break;
            }
        }
    }
    return sum;
}

int main() {
    int arr[] = {1, 2, 2, 3, 4, 4, 4};
    int size = sizeof(arr) / sizeof(arr[0]);
    int sum = sumRepeatedElements(arr, size);
    printf("Sum of repeated elements: %d\n", sum);
    return 0;
}
```
The integer array `arr[]` is passed to function `sumRepeatedElements()`, along with its size. The function proceeds to traverse the array, comparing each value with every other value in the array. If a match is found, the value is added to the `sum` and the inner loop is terminated using `break`. The final `sum` is returned and then printed in the `main()` function.
