```c
#include <stdio.h>

int find_last_index(int arr[], int len, int num) {
    int index = -1;
    for (int i = 0; i < len; i++) {
        if (arr[i] == num) {
            index = i;
        }
    }
    return index;
}

int main() {
    int arr[] = {1, 2, 3, 3, 5, 6, 7};
    int num = 3;
    int len = sizeof(arr) / sizeof(arr[0]);
    int result = find_last_index(arr, len, num);
    if (result != -1)
        printf("Last occurrence of %d is at index %d\n", num, result);
    else
        printf("Element not found in array\n");
}
```
In the above code, the function `find_last_index` iterates through the array and saves the last occurrence of the given number in the `index` variable. If the given number is not found in the array, the function returns `-1`. The `main` function then tests `find_last_index` with an array and a number, and prints the returned index.
