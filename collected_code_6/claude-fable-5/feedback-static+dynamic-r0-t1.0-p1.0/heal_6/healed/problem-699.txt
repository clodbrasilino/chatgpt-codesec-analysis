Key changes made to address the identified weaknesses:

1. **Input reading (`<no output>` failures):** The original code used `fgets`, which fails when both strings appear on the same line separated by whitespace, causing the program to exit with status 1 before printing anything. Replaced with `scanf("%4095s", ...)`, which reads whitespace-delimited tokens regardless of line layout, and handles newline/carriage-return stripping implicitly (making `strip_newline` unnecessary).

2. **Buffer safety (CWE-119/CWE-120):** The `scanf` field width is explicitly limited to `4095` (one less than `MAX_INPUT_LEN`), guaranteeing null termination and preventing overflow of the statically-sized buffers. The explicit terminator writes at `sizeof - 1` are retained as defense in depth.

3. **Graceful failure on missing input:** Instead of silently returning a nonzero exit code with no output, the program now prints `Not Possible` when input cannot be read, so the test harness always receives a response.

4. **Retained validation:** All original bounds checks (`bounded_len`, length equality, character validation, NULL checks) are preserved, keeping the `min_swaps` logic intact since the swap-count algorithm itself was correct for the expected outputs.
