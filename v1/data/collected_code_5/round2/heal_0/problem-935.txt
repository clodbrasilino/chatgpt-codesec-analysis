```c
#include <stdio.h>

long long int squareSum(int num) {
    long long int sum = 0;
    for(int i = 1; i <= num; i++) {
        sum += i * i;
    }
    return sum;
}

int main() {
    int num;
    printf("Enter a number: ");
    scanf("%d", &num);

    if(num < 1) {
        printf("Number must be greater than 0.\n");
        return -1;
    }

    long long int sum = squareSum(num);
    printf("Sum of square series till %d is %lld\n", num, sum);

    return 0;
}
```
This C program calculates the sum of square series till a given number. The sum is calculated using a for loop in the "squareSum" function. The "main" function gets the input from the user, checks if it is valid, and then calls the "squareSum" function to get the sum. It then prints the result. If the input is not valid (less than 1), it prints an error message and the program terminates with a return value of -1.
