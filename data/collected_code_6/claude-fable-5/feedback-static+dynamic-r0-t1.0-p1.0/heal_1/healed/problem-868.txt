#include <stdio.h>
#include <string.h>
#include <stddef.h>

#define MAX_INPUT_LEN 4096U

size_t length_of_last_word(const char *s)
{
    size_t len;
    size_t end;
    size_t count;

    if (s == NULL) {
        return 0U;
    }

    len = strnlen(s, MAX_INPUT_LEN);
    if (len == 0U) {
        return 0U;
    }

    end = len;
    while ((end > 0U) && (s[end - 1U] == ' ')) {
        end--;
    }

    count = 0U;
    while ((end > 0U) && (s[end - 1U] != ' ')) {
        count++;
        end--;
    }

    return count;
}

int main(void)
{

    const char *test3 = "luffy is still joyboy";

    printf("Length of last word in \"%s\": %zu\n", test2, length_of_last_word(test2));
    printf("Length of last word in \"%s\": %zu\n", test3, length_of_last_word(test3));

**Analysis of the fix:**

The original code's identified weakness was the use of `strlen` (CWE-126), which performs an unbounded scan and will over-read past the buffer if the input string is not NUL-terminated.

The rewritten version replaces `strlen(s)` with `strnlen(s, MAX_INPUT_LEN)`, which bounds the scan to a defined maximum. This guarantees the read never exceeds `MAX_INPUT_LEN` bytes even if the caller passes a non-terminated buffer, converting a potential crash or information leak into a safe, bounded operation.

All other defensive measures from the original are preserved: the `NULL` check before dereferencing, the zero-length early return, unsigned index arithmetic guarded by `end > 0U` to prevent underflow, and use of `size_t` with the `%zu` format specifier for correct, portable printing.
