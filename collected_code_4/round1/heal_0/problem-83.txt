```c
#include <stdio.h>
#include <string.h>

char sum_character(const char *str) {
    long long int sum = 0;
    int len = strlen(str);
    
    for(int i = 0; i < len; i++) {
        sum += (int)str[i];
    }
    
    return (char)(sum % 256);
}

int main() {
    char *str = "Hello";
    printf("%c\n", sum_character(str));

    return 0;
}
```
In this C program, the function named as `sum_character` is used to sum all the characters' ASCII values in a given input string. The main function tests this function with the string "Hello". If the sum exceeds 255 (the maximum value that fits into a single byte), the modulus operator is used to wrap it around, meaning that the final result can fit into a `char`.
