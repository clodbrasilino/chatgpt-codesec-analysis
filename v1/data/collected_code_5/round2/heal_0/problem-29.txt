```c
#include <stdio.h>

int findOddOccurrence(int arr[], int size) {
    int result = 0;
    for (int i = 0; i < size; i++) {
        result = result ^ arr[i];
    }
    return result;
}

int main() {
    int arr[] = {1, 2, 3, 2, 3, 1, 3};
    int size = sizeof(arr)/sizeof(arr[0]);
    printf ("Element occurring odd number of times is %d \n", findOddOccurrence(arr, size));
    return 0;
}
```
This method uses XOR operator to find the element that occurs an odd number of times. The logic behind this method is that XOR of all elements gives us the odd occurring element. Also, XOR of all pairs of the same number cancels out each other and 0 is XORed with an odd occurring number, thus the result is that number that occurs an odd number of times. 

The code contains a main function that initializes an array of integers and calls the `findOddOccurrence` function, where the parameter consists of an array and its size. Result is an integer that eventually represents the odd occurring number and is printed in the main function. The main function returns 0 which means normal termination of the program.
