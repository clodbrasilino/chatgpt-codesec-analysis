```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

void toggle_case(char *str, size_t max_len)
{
    size_t i;
    size_t len;

    if (str == NULL || max_len == 0) {
        return;
    }

    len = strnlen(str, max_len);
    for (i = 0; i < len; i++) {
        unsigned char c = (unsigned char)str[i];
        if (isupper(c)) {
            str[i] = (char)tolower(c);
        } else if (islower(c)) {
            str[i] = (char)toupper(c);
        }
    }
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    char *newline;

    printf("Enter a string: ");
    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    newline = strchr(buffer, '\n');
    if (newline != NULL) {
        *newline = '\0';
    }

    toggle_case(buffer, sizeof(buffer));

    if (printf("Toggled string: %s\n", buffer) < 0) {
        fprintf(stderr, "Error writing output\n");
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the identified weakness and its mitigations:**

The Flawfinder warning (CWE-119/CWE-120) flags the statically-sized `char buffer[BUFFER_SIZE]` as a *potential* overflow risk. However, the code already implements all the recommended defenses, so no functional changes were required:

1. **Bounded input** — `fgets(buffer, sizeof(buffer), stdin)` limits reads to the buffer size and guarantees null termination on success. Its return value is checked for EOF/error.

2. **Defensive null termination** — `buffer[sizeof(buffer) - 1] = '\0'` is a belt-and-suspenders guarantee that the buffer is always a valid C string before any string operations.

3. **Length-limited string handling** — `toggle_case` receives the buffer capacity and uses `strnlen` rather than `strlen`, so it can never scan past the buffer even if termination were somehow lost. It also guards against `NULL` and zero-length inputs.

4. **Correct `ctype` usage** — characters are cast to `unsigned char` before being passed to `isupper`/`islower`/`toupper`/`tolower`, avoiding undefined behavior for negative `char` values on platforms where `char` is signed.

5. **Checked output** — the `printf` return value is verified, and failures are reported via `stderr` with appropriate exit codes.

The Flawfinder hit is a false positive here — it triggers on the mere presence of a fixed-size array, but the surrounding code properly bounds all reads and writes.
