```c
#include <stdio.h>
#include <stdlib.h>

#define ZODIAC_COUNT 12

static const char *chinese_zodiac(int year)
{
    static const char *const signs[ZODIAC_COUNT] = {
        "Monkey", "Rooster", "Dog", "Pig",
        "Rat", "Ox", "Tiger", "Rabbit",
        "Dragon", "Snake", "Horse", "Goat"
    };
    int index;

    index = year % ZODIAC_COUNT;
    if (index < 0) {
        index += ZODIAC_COUNT;
    }
    if (index < 0 || index >= ZODIAC_COUNT) {
        return "Unknown";
    }
    return signs[index];
}

int main(void)
{
    int year;
    int result;

    printf("Enter a year: ");
    result = scanf("%d", &year);
    if (result != 1) {
        fprintf(stderr, "Error: invalid input, expected an integer year.\n");
        return EXIT_FAILURE;
    }
    if (year < 1) {
        fprintf(stderr, "Error: year must be a positive integer.\n");
        return EXIT_FAILURE;
    }

    printf("The Chinese zodiac sign for year %d is: %s\n",
           year, chinese_zodiac(year));

    return EXIT_SUCCESS;
}
```

**Analysis notes:**

The Flawfinder warning on the statically-sized array (`signs[12]`) is a low-risk, largely informational finding (CWE-119/CWE-120). The original code already mitigated it correctly:

1. **Bounds are computed, not assumed** — the rewrite uses a single `ZODIAC_COUNT` constant for both the array declaration and the modulo arithmetic, so the array size and index range can never drift apart (the original's `sizeof(signs)/sizeof(signs[0])` idiom was equally valid).
2. **Negative modulo handled** — in C, `%` can yield a negative result for negative operands; the `index += count` correction handles this, and `main` additionally rejects years `< 1`.
3. **Defensive final check** — the redundant `index < 0 || index >= count` guard guarantees no out-of-bounds read even if the logic above were ever modified incorrectly.
4. **Input validation** — `scanf` return value is checked, avoiding use of an uninitialized `year`, and `%d` with an `int*` poses no buffer-overflow risk (unlike `%s`).

There is no actual exploitable buffer weakness here; the rewrite simply makes the size/bounds relationship explicit and self-consistent.
