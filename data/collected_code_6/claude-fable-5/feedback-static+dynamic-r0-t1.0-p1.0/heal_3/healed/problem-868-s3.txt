```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

#define MAX_INPUT_LEN 4096U

size_t length_of_last_word(const char *s)
{
    size_t len;
    size_t end;
    size_t count;

    if (s == NULL) {
        return 0U;
    }

    len = 0U;
    while (len < MAX_INPUT_LEN && s[len] != '\0') {
        len++;
    }

    if (len == 0U) {
        return 0U;
    }

    end = len;
    while (end > 0U && isspace((unsigned char)s[end - 1U])) {
        end--;
    }

    count = 0U;
    while (end > 0U && !isspace((unsigned char)s[end - 1U])) {
        count++;
        end--;
    }

    return count;
}

int main(void)
{
    char buffer[MAX_INPUT_LEN];
    size_t result;

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        buffer[0] = '\0';
    }

    buffer[sizeof(buffer) - 1U] = '\0';

    result = length_of_last_word(buffer);

    if (printf("%zu\n", result) < 0) {
        return 1;
    }

    return 0;
}
```

**Analysis notes:**

The most likely cause of the reported failures (`<no output>` on every test case) is a **compilation or portability failure**, not a logic bug. The word-counting logic itself is correct.

1. **`strnlen` portability (root cause of the failures):** `strnlen` is POSIX / C11 Annex K, not guaranteed in strict C90/C99 environments. If the test harness compiles with `-std=c99` (or on a platform lacking the extension), the build fails and the program produces no output at all — which matches "expected 3, got `<no output>`" across *all* test cases. The rewrite replaces it with an explicit bounded scan, which is fully portable and preserves the bounds-checking intent.

2. **CWE-119/CWE-120 (Flawfinder warning on `buffer`):** The original code was already safe here — `fgets(buffer, sizeof(buffer), stdin)` limits the read and null-terminates. I added an explicit terminating write at `buffer[sizeof(buffer) - 1]` as defense-in-depth to guarantee termination regardless of stream state, silencing the static-analysis concern.

3. **Retained correct practices:** the `(unsigned char)` cast before `isspace` (avoids UB for negative `char` values), the `NULL` guard, the `fgets` failure path, and checking `printf`'s return value.
