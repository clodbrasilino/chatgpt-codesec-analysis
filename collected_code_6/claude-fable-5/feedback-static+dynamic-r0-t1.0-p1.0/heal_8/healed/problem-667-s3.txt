```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define MAX_INPUT 1024

size_t count_vowels(const char *str)
{
    size_t count = 0;
    size_t i;

    if (str == NULL) {
        return 0;
    }

    for (i = 0; str[i] != '\0'; i++) {
        int c = tolower((unsigned char)str[i]);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }

    return count;
}

static void flush_stdin(void)
{
    int ch;

    do {
        ch = getchar();
    } while (ch != '\n' && ch != EOF);
}

int main(void)
{
    char buffer[MAX_INPUT];
    size_t len;
    size_t vowels;

    printf("Enter a string: ");
    fflush(stdout);

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    } else if (len == sizeof(buffer) - 1) {
        flush_stdin();
    }

    vowels = count_vowels(buffer);
    printf("Number of vowels: %zu\n", vowels);

    return EXIT_SUCCESS;
}
```

**Analysis notes:**

The original code was already well-defended against the flagged weaknesses, so the rewrite preserves those mitigations rather than changing logic:

1. **`char buffer[MAX_INPUT]` (CWE-119/CWE-120, statically-sized array):** Mitigated because input is read exclusively via `fgets(buffer, sizeof(buffer), stdin)`, which enforces the buffer bound. The explicit `buffer[sizeof(buffer) - 1] = '\0'` guarantees null-termination, and `strnlen` (rather than `strlen`) bounds the length scan to the buffer size.

2. **`getchar` in a loop (CWE-120/CWE-20):** Safe as used — `flush_stdin` discards characters without storing them into any buffer, so no overflow is possible. The loop correctly terminates on both `'\n'` and `EOF`, avoiding an infinite loop on closed/truncated input streams.

3. **Other correct practices retained:**
   - `tolower((unsigned char)str[i])` avoids undefined behavior when `char` is signed and holds negative values.
   - The `NULL` check in `count_vowels` guards against misuse.
   - The `fgets` return value is checked, and failure exits with `EXIT_FAILURE`.
   - Overlong input lines are drained via `flush_stdin` so stale characters don't linger in `stdin`.

The Flawfinder hits are risk-level 1–2 informational findings; both were already properly bounded, so no functional changes were required — only comment removal per the request.
