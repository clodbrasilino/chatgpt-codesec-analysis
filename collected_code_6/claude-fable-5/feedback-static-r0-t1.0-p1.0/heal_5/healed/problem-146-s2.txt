```c
#define _POSIX_C_SOURCE 200809L

#include <stdio.h>
#include <string.h>
#include <stdlib.h>

#define BUFFER_SIZE 256

long ascii_sum(const char *str, size_t max_len)
{
    long sum = 0;
    size_t i;
    size_t len;

    if (str == NULL) {
        return -1;
    }

    len = strnlen(str, max_len);
    for (i = 0; i < len; i++) {
        sum += (long)(unsigned char)str[i];
    }

    return sum;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    long result;
    size_t len;

    printf("Enter a string: ");
    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    result = ascii_sum(buffer, sizeof(buffer));
    if (result < 0) {
        fprintf(stderr, "Invalid string\n");
        return EXIT_FAILURE;
    }

    printf("Sum of ASCII values: %ld\n", result);

    return EXIT_SUCCESS;
}
```

**Analysis summary:**

The flagged weakness (CWE-119/CWE-120, statically-sized buffer) was already properly mitigated in the original code, so the rewrite preserves those defenses:

1. **Bounded input reading** — `fgets(buffer, sizeof(buffer), stdin)` limits input to the buffer size, preventing the classic `gets()`-style overflow.
2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1] = '\0'` is a defensive belt-and-braces measure (though `fgets` already null-terminates on success).
3. **Bounded string operations** — `strnlen()` is used instead of `strlen()`, both in `main` and inside `ascii_sum`, so even a non-terminated buffer cannot cause an out-of-bounds read.
4. **NULL-pointer check** — `ascii_sum` validates its input and signals an error via a negative return value, which the caller checks.
5. **Sign-safety** — the cast chain `(long)(unsigned char)str[i]` avoids undefined/negative results on platforms where `char` is signed.

The only change worth noting: I added `#define _POSIX_C_SOURCE 200809L` before the includes, since `strnlen()` is POSIX.1-2008 rather than ISO C, ensuring the prototype is visible when compiling with strict flags like `-std=c99`.
