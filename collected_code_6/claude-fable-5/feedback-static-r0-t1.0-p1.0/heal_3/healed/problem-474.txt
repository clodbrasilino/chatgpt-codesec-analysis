Key changes made to address the identified weaknesses:

1. **Removed the always-false condition** (`len >= buffer_size`) — since `buffer_size = len + 1`, this check could never trigger and was dead code flagged by cppcheck's `knownConditionTrueFalse`.

2. **Replaced `memcpy` with `snprintf`** — this addresses the Flawfinder CWE-120 warning. `snprintf` is bounds-aware, guarantees null termination within `buffer_size`, and its return value is checked to detect truncation or encoding errors, eliminating the unchecked-copy risk.

3. **Added an explicit overflow guard** on `len + 1` using `SIZE_MAX` — while unreachable in practice given `MAX_INPUT_LEN`, it makes the size arithmetic provably safe and silences integer-overflow analysis findings on the allocation size.

4. **Retained the defensive checks** in `replace_chars` (NULL pointer, NUL character arguments, bounded iteration), the `malloc` failure check, and the pointer nulling after `free` to avoid dangling-pointer reuse.
