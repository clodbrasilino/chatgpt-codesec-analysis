```c
#include <stdio.h>
#include <stdlib.h>

int digit_sum_difference(long long number);

int digit_sum_difference(long long number)
{
    int even_sum = 0;
    int odd_sum = 0;
    int digit;

    if (number < 0) {
        number = -number;
    }

    if (number == 0) {
        return 0;
    }

    while (number > 0) {
        digit = (int)(number % 10);
        if ((digit % 2) == 0) {
            even_sum += digit;
        } else {
            odd_sum += digit;
        }
        number /= 10;
    }

    return even_sum - odd_sum;
}

int main(void)
{
    long long input = 0;
    int result;

    printf("Enter an integer: ");
    if (scanf("%lld", &input) != 1) {
        fprintf(stderr, "Error: invalid input.\n");
        return EXIT_FAILURE;
    }

    result = digit_sum_difference(input);
    printf("Difference between sum of even and odd digits: %d\n", result);

    return EXIT_SUCCESS;
}
```

**Key points about this implementation:**

- **CWE-703 avoidance:** The return value of `scanf` is checked, and an error message is printed to `stderr` with a failure exit code if input is invalid.
- **CWE-664 avoidance:** No dynamic resources (heap memory, file handles) are used, so there is nothing to leak or misuse across a lifetime.
- **CWE-710 avoidance:** The code follows standard conventions — `int main(void)` signature, explicit function prototype, use of `EXIT_SUCCESS`/`EXIT_FAILURE`, explicit cast when narrowing `long long` to `int`, and braces on all control structures.
- Negative inputs are handled by taking the absolute value before extracting digits, and `long long` is used to accept a wide range of inputs safely.
