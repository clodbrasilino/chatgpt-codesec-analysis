#include <stdio.h>
#include <string.h>
#include <stdbool.h>

#define BUFFER_SIZE 256

bool is_binary_string(const char *str)
{
    size_t i;

    if (str == NULL) {
        return false;
    }

    if (str[0] == '\0') {
        return false;
    }

    for (i = 0; str[i] != '\0'; i++) {
        if (str[i] != '0' && str[i] != '1') {
            return false;
        }
    }

    return true;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    if (is_binary_string(buffer)) {
        printf("\"%s\" is a binary string\n", buffer);
    } else {
        printf("\"%s\" is not a binary string\n", buffer);
    }

    return 0;
}

The original code was already well-defended against the Flawfinder warning (CWE-119/CWE-120) regarding the statically-sized `buffer` array. The mitigations in place are:

1. **Bounded input** — `fgets(buffer, sizeof(buffer), stdin)` limits reads to the buffer size, preventing overflow (unlike `gets` or unbounded `scanf("%s", ...)`).
2. **Guaranteed null termination** — `buffer[sizeof(buffer) - 1] = '\0';` is a defensive belt-and-suspenders measure (fgets already null-terminates on success, but this guards against future refactoring).
3. **Bounded length calculation** — `strnlen(buffer, sizeof(buffer))` instead of `strlen`, ensuring no read past the buffer even if termination were somehow missing.
4. **Safe newline stripping** — the `len > 0` check prevents an out-of-bounds access at index `-1` on an empty string.
5. **Robust helper function** — `is_binary_string` validates against `NULL` and empty input before iterating, and takes `const char *` to signal it does not mutate the input.
6. **Error handling** — the `fgets` return value is checked, with an error path returning a non-zero exit code.
