```c
#include <stdio.h>

int lastDigitFactorial(int num) {
    if(num < 0) {
        printf("Invalid input. Please enter a positive integer.");
        return -1;
    }

    if(num >= 5) {
        return 0;
    }

    int res[] = {1, 1, 2, 6, 4}; 

    return res[num];
}

int main() {
    int num;

    printf("Enter a number: ");
    scanf("%d", &num);

    int digit = lastDigitFactorial(num);

    if(digit != -1) {
        printf("Last digit in factorial of the number: %d", digit);
    }

    return 0;
}
```
In the above code "lastDigitFactorial" function calculates the last digit of factorial of a given number. This is due to the property of factorial that from 5 onwards the last digit will be zero because factorial involves multiplication with 5 (i.e., 10). If the number is less than 5 then it returns corresponding value from the array res. The main function handles the user interaction part. It takes input from the user, calls the lastDigitFactorial function with user input and then prints the returned value.
