## Analysis

The code is already largely defensive, and the Flawfinder hits are informational rather than actual vulnerabilities:

1. **`getchar()` in `flush_stdin()` (CWE-120/CWE-20, risk 1):** False positive — the return value is stored in an `int` (correctly, so `EOF` is distinguishable) and nothing is written to a buffer. No fix needed beyond keeping it as-is.

2. **Statically-sized `char buffer[MAX_INPUT]` (CWE-119/CWE-120, risk 2):** Mitigated correctly — `fgets()` is bounded by `sizeof(buffer)`, a defensive NUL terminator is added, and truncation is detected and the remaining input is drained. The only real improvements possible are minor hardening: avoid the redundant `(int)` cast pitfall by using `sizeof` directly (safe here since `MAX_INPUT` fits in `int`), and ensure `string_length` never runs past the buffer by giving it an explicit bound (`strnlen`-style), removing any theoretical unbounded scan.

Below is the hardened rewrite with a bounded length function and identical observable behavior:

```c
#include <stdio.h>
#include <stdlib.h>

#define MAX_INPUT 256

static size_t string_length(const char *str, size_t max_len)
{
    size_t length = 0;

    if (str == NULL) {
        return 0;
    }

    while (length < max_len && str[length] != '\0') {
        length++;
    }

    return length;
}

static void flush_stdin(void)
{
    int ch;

    do {
        ch = getchar();
    } while (ch != '\n' && ch != EOF);
}

int main(void)
{
    char buffer[MAX_INPUT];
    size_t length;

    printf("Enter a string: ");

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    length = string_length(buffer, sizeof(buffer));

    if (length > 0 && buffer[length - 1] == '\n') {
        buffer[length - 1] = '\0';
        length--;
        printf("You entered: %s\n", buffer);
    } else if (length == sizeof(buffer) - 1) {
        flush_stdin();
        printf("You entered (truncated): %s\n", buffer);
    } else {
        printf("You entered: %s\n", buffer);
    }

    printf("Length of the string: %zu\n", length);

    return EXIT_SUCCESS;
}
```

### Summary of changes
- `string_length()` now takes an explicit `max_len` bound, eliminating any possibility of reading past the buffer even if the terminator were somehow missing (defense in depth against CWE-119/CWE-120).
- `string_length()` made `static` for internal linkage consistency.
- All existing mitigations retained: bounded `fgets()`, forced NUL termination, truncation detection with `flush_stdin()` draining leftover input, and `int`-typed `getchar()` result with proper `EOF` handling.
