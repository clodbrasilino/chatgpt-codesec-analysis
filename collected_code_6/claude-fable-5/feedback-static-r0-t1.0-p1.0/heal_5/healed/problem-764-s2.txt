```c
#include <stdio.h>
#include <ctype.h>
#include <stddef.h>
#include <string.h>

#define BUFFER_SIZE 256

size_t count_numeric(const char *str)
{
    size_t count = 0;

    if (str == NULL) {
        return 0;
    }

    while (*str != '\0') {
        if (isdigit((unsigned char)*str)) {
            count++;
        }
        str++;
    }

    return count;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t result;
    size_t len;

    printf("Enter a string: ");

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';

    len = strnlen(buffer, sizeof(buffer));
    if (len > 0 && buffer[len - 1] == '\n') {
        buffer[len - 1] = '\0';
    }

    result = count_numeric(buffer);

    printf("Number of numeric characters: %zu\n", result);

    return 0;
}
```

**Analysis notes:**

The Flawfinder warning about the statically-sized `buffer` array (CWE-119/CWE-120) is a low-risk, informational flag rather than an actual vulnerability in this code. The original source already mitigates it correctly, so the rewritten code preserves those defenses:

1. **Bounded input:** `fgets(buffer, sizeof(buffer), stdin)` limits reads to at most `BUFFER_SIZE - 1` characters plus the null terminator, preventing buffer overflow. Using `sizeof(buffer)` rather than a hardcoded constant keeps the bound correct if `BUFFER_SIZE` changes.

2. **Guaranteed termination:** `buffer[sizeof(buffer) - 1] = '\0';` is defensive belt-and-suspenders — `fgets` already null-terminates, but this makes termination explicit and robust.

3. **Safe length calculation:** `strnlen(buffer, sizeof(buffer))` bounds the scan, avoiding any read past the array even if termination were somehow missing (unlike plain `strlen`).

4. **Safe character classification:** the cast `(unsigned char)*str` before `isdigit()` avoids undefined behavior on platforms where `char` is signed and the input contains bytes above 0x7F.

5. **NULL check** in `count_numeric` guards against invalid pointer dereference, and the `fgets` return value is checked for I/O errors/EOF.

No functional changes were required — the identified weakness was already properly addressed.
