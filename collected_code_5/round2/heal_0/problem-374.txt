```C
#include <stdio.h>
#include <string.h>

void swap(char *x, char *y) {
    char temp;
    temp = *x;
    *x = *y;
    *y = temp;
}

void permute(char *str, int start, int end) {
    int i;
    if (start == end)
        printf("%s\n", str);
    else {
        for (i = start; i <= end; i++) { 
            swap((str + start), (str + i)); 
            permute(str, start + 1, end); 
            swap((str + start), (str + i));
        } 
    }
}

int main() {
    char str[] = "ABC";
    permute(str, 0, strlen(str) - 1);
    return 0;
}
```
The main function calls `permute(...)`, passing an array of characters (c-string), and the starting and ending indices. The `permute(...)`, function, receives there parameters, and processes them to generate all the possible permutations. It does so by first checking if the starting index is equal to the end (base case), meaning that it has reached the end of the string, in which case it prints the permutation. If not, it enters a loop where it constantly swaps the current character with the next, generates the combinations starting from that state, and then swaps them back. The base case acts as the stopping condition, preventing any out-of-bound accesses or infinite executions.
