Here is a simple implementation of a C program that finds the difference between the sum of even and odd digits of an input number.

```c
#include <stdio.h>
#include <stdlib.h>

int diffEvenOddDigits(int num) {
    int diff, sumEvens = 0, sumOdds = 0, digit;

    while (num > 0) {
        digit = num % 10;
        if (digit % 2 == 0)
            sumEvens += digit;
        else
            sumOdds += digit;

        num /= 10;
    }

    diff = abs(sumEvens - sumOdds);

    return diff;
}

int main() {
    int num;

    printf("Enter a number: ");
    scanf("%d", &num);
    
    if(num < 0){
        printf("Enter a positive number\n");
        return 1;
    }

    printf("Difference between sum of even and odd digits: %d\n", diffEvenOddDigits(num));

    return 0;
}
```
This program calculates the difference between the sum of even and odd digits of an integer by retrieving each digit from the integer, checking whether it is even or odd, and summing it into the appropriate sum. It uses the abs function to ensure that the difference is always reported as a positive value. 

The main function verifies that the input is a positive integer. Invalid (negative) input results in a warning message and the program returns 1 (indicating an error condition). Valid input is processed and the resulting difference is displayed.
