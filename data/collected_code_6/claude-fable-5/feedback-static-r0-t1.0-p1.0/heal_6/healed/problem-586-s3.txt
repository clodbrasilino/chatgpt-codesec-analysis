## Analysis

The code performs a left-rotation of an array by `k` positions using a temporary buffer. Overall it is defensively written:

- **NULL / zero-length guards** — handled correctly.
- **Integer overflow** — `n > SIZE_MAX / sizeof(int)` prevents overflow in the byte-size calculations, and `k = k % n` bounds `k` before computing `head_bytes`/`tail_bytes`.
- **The Flawfinder `memcpy` warnings are false positives in context**: `temp` is allocated with exactly `head_bytes`, and both `arr + k` (source of `tail_bytes`) and `arr + (n - k)` (destination of `head_bytes`) stay within the `n * sizeof(int)` bounds because `k < n` is guaranteed after the modulo. The redundant checks (`k > n`, `head_bytes > n * sizeof(int)`, etc.) can never fire but do no harm.

To silence the CWE-120 findings cleanly, the rewrite below replaces the raw `memcpy`/`memmove` calls with explicitly bounds-checked element-wise copies, making the destination-capacity guarantee visible to static analyzers, while preserving identical behavior (output: `5 6 52 36 12 10`).

## Rewritten Code

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

static int checked_copy(int *dst, size_t dst_count,
                        const int *src, size_t src_count)
{
    size_t i;

    if (dst == NULL || src == NULL) {
        return -1;
    }
    if (src_count > dst_count) {
        return -1;
    }
    for (i = 0; i < src_count; i++) {
        dst[i] = src[i];
    }
    return 0;
}

static int checked_move(int *dst, size_t dst_count,
                        const int *src, size_t src_count)
{
    size_t i;

    if (dst == NULL || src == NULL) {
        return -1;
    }
    if (src_count > dst_count) {
        return -1;
    }
    if (dst <= src) {
        for (i = 0; i < src_count; i++) {
            dst[i] = src[i];
        }
    } else {
        for (i = src_count; i > 0; i--) {
            dst[i - 1] = src[i - 1];
        }
    }
    return 0;
}

int split_and_rotate(int *arr, size_t n, size_t k)
{
    int *temp;

    if (arr == NULL || n == 0) {
        return -1;
    }

    if (n > SIZE_MAX / sizeof(int)) {
        return -1;
    }

    k = k % n;
    if (k == 0) {
        return 0;
    }

    temp = malloc(k * sizeof(int));
    if (temp == NULL) {
        return -1;
    }

    if (checked_copy(temp, k, arr, k) != 0) {
        free(temp);
        return -1;
    }

    if (checked_move(arr, n, arr + k, n - k) != 0) {
        free(temp);
        return -1;
    }

    if (checked_copy(arr + (n - k), k, temp, k) != 0) {
        free(temp);
        return -1;
    }

    free(temp);
    return 0;
}

int main(void)
{
    int arr[] = {12, 10, 5, 6, 52, 36};
    size_t n = sizeof(arr) / sizeof(arr[0]);
    size_t k = 2;
    size_t i;

    if (split_and_rotate(arr, n, k) != 0) {
        fprintf(stderr, "Rotation failed\n");
        return EXIT_FAILURE;
    }

    for (i = 0; i < n; i++) {
        if (printf("%d ", arr[i]) < 0) {
            return EXIT_FAILURE;
        }
    }

    if (printf("\n") < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

### Key changes

1. **`checked_copy` / `checked_move` wrappers** — every copy now explicitly verifies the destination capacity (`src_count > dst_count`) before writing, directly addressing the CWE-120 pattern Flawfinder flagged.
2. **Removed dead checks** — `k > n`, `(n - k) > n`, and the `head_bytes`/`tail_bytes` comparisons were unreachable after `k = k % n` with `k != 0`, so they were dropped; bounds enforcement now lives in the wrappers where analyzers can see it.
3. **Consistent cleanup** — `temp` is freed on every failure path, so no leak is possible even if a copy check fails.
4. **Overlap-safe move** — `checked_move` copies in the correct direction depending on pointer order, replicating `memmove` semantics for the overlapping shift.
