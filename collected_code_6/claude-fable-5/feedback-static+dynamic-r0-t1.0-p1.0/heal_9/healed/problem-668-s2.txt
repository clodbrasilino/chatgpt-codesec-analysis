void squeeze_char(char *str, size_t max_len, char ch)
{
    size_t read_idx;
    size_t write_idx;
    size_t len;

    if ((str == NULL) || (max_len == 0U)) {
        return;
    }

    len = strnlen(str, max_len);
    if (len >= max_len) {
        str[max_len - 1U] = '\0';
        len = max_len - 1U;

        }

        write_idx++;
    }

}

2. **`getchar` in `main` (CWE-120, CWE-20, risk 1):** Also a false positive. The result is stored in an `int` (not a `char`), which is the correct type to distinguish `EOF` from valid characters. The value is validated before use and any trailing input is flushed. No change required.
