```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int* extract_elements(int* source_array, int num_elements, int start_element, int source_length) {
    if(start_element < 0 || start_element >= source_length || 
       num_elements <= 0 || start_element+num_elements > source_length) {
        return NULL;
    }
    int* extracted_elements = malloc(num_elements*sizeof(int));

    if(extracted_elements == NULL) {
        return NULL;
    }

    memcpy(extracted_elements, source_array + start_element, num_elements*sizeof(int));
    return extracted_elements;
}

int main() {
    int num_elements = 3;
    int start_element = 2;
    int source_length = 6;

    int source_array[6] = {1, 2, 3, 4, 5, 6};

    int* extracted_elements = extract_elements(source_array, num_elements, 
                                               start_element, source_length);
    
    if(extracted_elements == NULL) {
        printf("Invalid input or memory allocation error.\n");
        return 1;
    }

    for(int i = 0; i < num_elements; i++) {
        printf("%d ", extracted_elements[i]);
    }

    free(extracted_elements);
    return 0;
}
```
Here is a simple C function to extract a given number of elements from a given list which follow each other continuously. It first checks if the starting element and the number of elements to be extracted are valid. If they are, it allocates memory to store the extracted elements. After the memory is allocated successfully, it copies the specified elements from the source array to the newly allocated memory. Finally, the function returns a pointer to the extracted elements. In the main function, the source array, number of elements to extract, and starting element are defined. Then the function extract_elements() is called with these parameters. The resulted extracted elements are printed out. If the function returns NULL, an error message is printed and 1 is returned.
