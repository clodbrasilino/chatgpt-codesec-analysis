```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

#define BUFFER_SIZE 256

size_t count_numeric(const char *str)
{
    size_t count;
    size_t i;

    if (str == NULL) {
        return 0;
    }

    count = 0;
    for (i = 0; str[i] != '\0'; i++) {
        if (isdigit((unsigned char)str[i])) {
            count++;
        }
    }

    return count;
}

int main(void)
{
    char buffer[BUFFER_SIZE];
    size_t result;

    if (fgets(buffer, sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return EXIT_FAILURE;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    result = count_numeric(buffer);

    if (printf("Numeric characters: %zu\n", result) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Analysis of the original code and fixes applied:**

The original code was already in good shape regarding the flagged weakness. Here's my assessment:

1. **CWE-119/CWE-120 (buffer overflow via statically-sized array):** The flagged `char buffer[BUFFER_SIZE]` risk was already mitigated because `fgets(buffer, sizeof(buffer), stdin)` performs bounds-limited reading. `fgets` never writes more than `sizeof(buffer) - 1` characters plus the null terminator, so no overflow is possible.

2. **Defensive null termination:** `buffer[sizeof(buffer) - 1] = '\0'` is technically redundant after a successful `fgets`, but it's harmless defense-in-depth and I retained it.

3. **Improvement made — newline stripping:** I replaced the `memchr(buffer, '\n', sizeof(buffer))` call with `strcspn(buffer, "\n")`. The original `memchr` scanned the *entire* buffer, including bytes beyond the null terminator that `fgets` never initialized. While not exploitable, reading uninitialized memory is undefined-behavior-adjacent and flagged by tools like Valgrind/MSan. `strcspn` stops at the null terminator, only touches initialized data, and handles the no-newline case cleanly (it writes the null terminator over the existing one).

4. **Other good practices already present and preserved:** the `(unsigned char)` cast before `isdigit` (avoids UB for negative `char` values), the `NULL` guard in `count_numeric`, checking the return values of `fgets` and `printf`, and the correct `%zu` format specifier for `size_t`.
