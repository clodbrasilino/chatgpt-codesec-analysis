```c
#include <stdio.h>
#include <stdbool.h>
#include <string.h>
#include <limits.h>

#define MAX_INPUT_LEN 256

bool all_chars_unique(const char *str, size_t max_len)
{
    bool seen[UCHAR_MAX + 1] = { false };
    size_t i;

    if (str == NULL) {
        return false;
    }

    for (i = 0; i < max_len && str[i] != '\0'; i++) {
        unsigned char c = (unsigned char)str[i];
        if (seen[c]) {
            return false;
        }
        seen[c] = true;
    }

    return true;
}

int main(void)
{
    char buffer[MAX_INPUT_LEN];

    if (fgets(buffer, (int)sizeof(buffer), stdin) == NULL) {
        fprintf(stderr, "Error reading input\n");
        return 1;
    }

    buffer[sizeof(buffer) - 1] = '\0';
    buffer[strcspn(buffer, "\n")] = '\0';

    if (all_chars_unique(buffer, sizeof(buffer))) {
        printf("All characters are unique\n");
    } else {
        printf("Duplicate characters found\n");
    }

    return 0;
}
```

**Analysis of the original code and the flagged weakness:**

The Flawfinder warning (CWE-119/CWE-120) about the statically-sized `char buffer[MAX_INPUT_LEN]` is a low-risk, largely informational finding, and the original code already mitigates it correctly:

1. **Bounded input** — `fgets(buffer, (int)sizeof(buffer), stdin)` limits the read to `sizeof(buffer) - 1` characters plus the null terminator, so no overflow can occur. Using `sizeof(buffer)` rather than a repeated macro/literal keeps the size expression tied to the actual array, preventing mismatch bugs if the size ever changes.

2. **Guaranteed termination** — `buffer[sizeof(buffer) - 1] = '\0';` is defensive (technically redundant after a successful `fgets`, which always null-terminates) but harmless and protects against future refactoring to non-terminating read functions.

3. **Newline stripping** — `buffer[strcspn(buffer, "\n")] = '\0';` safely removes the trailing newline without risking out-of-bounds access, since `strcspn` returns the index of the terminator if no newline exists.

4. **Safe scanning** — `all_chars_unique` performs its own bounds checking (`i < max_len && str[i] != '\0'`), checks for `NULL`, and casts to `unsigned char` before indexing the `seen` table, avoiding undefined behavior from negative `char` values on platforms where `char` is signed. The table is sized `UCHAR_MAX + 1`, so every possible byte value is a valid index.

5. **Error handling** — the `fgets` return value is checked, and failure is reported to `stderr` with a nonzero exit code.

No functional changes were required; the code as written is already free of the buffer-overflow risk the static analyzer flagged.
