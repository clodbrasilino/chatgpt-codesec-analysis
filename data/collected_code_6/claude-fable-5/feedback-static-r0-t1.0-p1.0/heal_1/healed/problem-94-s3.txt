```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define NAME_LEN 64

typedef struct {
    char name[NAME_LEN];
    int value;
} Record;

int index_minimum(const Record *records, size_t count, char *out, size_t out_size)
{
    size_t i;
    size_t min_idx = 0;
    size_t name_len;

    if (records == NULL || out == NULL || count == 0U || out_size == 0U) {
        return -1;
    }

    for (i = 1U; i < count; i++) {
        if (records[i].value < records[min_idx].value) {
            min_idx = i;
        }
    }

    name_len = strnlen(records[min_idx].name, NAME_LEN);

    if (name_len >= NAME_LEN || name_len >= out_size) {
        return -1;
    }

    memcpy(out, records[min_idx].name, name_len);
    out[name_len] = '\0';

    return 0;
}

int main(void)
{
    Record records[] = {
        {"Rash", 143},
        {"Manjeet", 200},
        {"Varsha", 100}
    };
    size_t count = sizeof(records) / sizeof(records[0]);
    char result[NAME_LEN];

    if (index_minimum(records, count, result, sizeof(result)) != 0) {
        (void)fprintf(stderr, "Error: could not extract minimum record\n");
        return EXIT_FAILURE;
    }

    if (printf("Record with minimum value: %s\n", result) < 0) {
        return EXIT_FAILURE;
    }

    return EXIT_SUCCESS;
}
```

**Key changes made to address the identified weaknesses:**

1. **`strlen` → `strnlen`** (CWE-126): The original `strlen` could over-read if a `name` field were ever not NUL-terminated. `strnlen(name, NAME_LEN)` bounds the scan to the buffer size, and the added `name_len >= NAME_LEN` check rejects unterminated strings safely instead of crashing.

2. **`strncpy` → `memcpy` + explicit terminator** (CWE-120): `strncpy` is error-prone — it doesn't guarantee NUL-termination and zero-pads unnecessarily. Since the length is now validated against `out_size` beforehand, `memcpy` of exactly `name_len` bytes followed by an explicit `out[name_len] = '\0'` guarantees a correctly terminated result with no possibility of overflow.

3. **Statically-sized `char` arrays** (CWE-119/CWE-120): The fixed-size buffers remain, but they are now safe because every read is bounded (`strnlen`) and every write is length-checked before copying (`name_len >= out_size` guard, `sizeof(result)` passed explicitly). This satisfies the "perform bounds checking" mitigation recommended by the analyzer.

The original null-pointer/zero-size guards and error handling in `main` were already sound and are preserved.
